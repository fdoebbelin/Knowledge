## Worum es geht

Ein Einsteigerkurs Python in 20 Modulen, von der ersten Installation bis zum Arbeiten mit Git und GitHub. Jedes Modul ist in Lerneinheiten mit Aufgaben und Musterlösungen gegliedert, gearbeitet wird überwiegend in JupyterLab. Dazu kommen Kursorganisation (Modulübersicht, Projektthemen, Zertifikatsvorlage) und Beispielprojekte.

## Kernaussagen

- Funktionen ziehen sich von Anfang an durch den Kurs: Schon die Grundlagen (Datentypen, Ein- und Ausgabe, Bedingungen, Schleifen) werden in Funktionen geübt, nicht als lose Skriptzeilen.
- Der Aufbau folgt vier Blöcken: Einstieg (M01–M05), Kontrollstrukturen und Fehlerbehandlung (M06–M08), Funktionen und Datenstrukturen (M09–M15), Codeorganisation und Versionskontrolle (M16–M20).
- Fortgeschrittene Funktionskonzepte bekommen ein eigenes, breites Modul: Default- und Schlüsselwortparameter, variable Argumentlisten, Funktionen höherer Ordnung, Lambdas, Rekursion, Closures und Dekoratoren.
- Daten werden schrittweise dauerhaft gespeichert: Text, CSV, JSON und zuletzt SQLite, auch direkt in JupyterLab.
- Sauberer Code ist eigener Lernstoff: PEP 8, Docstrings, Namenswahl, Kohäsion, Kopplung und Testbarkeit.
- Zum Schluss stehen Git-Grundlagen, Branching, Remote-Repositories und die Abläufe Git Flow und GitHub Flow.
