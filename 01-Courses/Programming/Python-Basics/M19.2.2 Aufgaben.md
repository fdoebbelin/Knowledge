## 💡 Lösungshinweise

### Git-Repository Management:
- `git init` für Repository-Erstellung
- Aussagekräftige Commit-Messages wie "Add book search functionality"
- Regelmäßige `git status` Checks vor Commits

### Branch-Workflow:
- `git branch feature/name` für neue Feature-Branches
- `git checkout branch-name` für Branch-Wechsel
- `git checkout -b name` für schnelles Erstellen und Wechseln

### Merge-Vorbereitung:
- Immer zu main wechseln vor dem Mergen
- `git merge feature-branch` für Zusammenführung
- `git branch -d branch-name` für Cleanup nach erfolgreichem Merge

### Projekthistorie-Analyse:
- `git log --oneline` für kompakte Übersicht
- `git log --graph` für Branch-Visualisierung
- `git diff` für Änderungsvergleiche
