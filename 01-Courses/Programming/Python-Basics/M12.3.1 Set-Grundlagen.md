## 3.1 Was sind Sets?

Sets sind **ungeordnete Sammlungen eindeutiger Elemente**. Sie entfernen automatisch Duplikate und eignen sich perfekt für schnelle Membership-Tests.

```python
# Einfaches Set erstellen
farben = {"rot", "grün", "blau", "gelb"}
print(f"Farben-Set: {farben}")

# Sets entfernen automatisch Duplikate
zahlen = {1, 2, 3, 2, 4, 1, 5}
print(f"Zahlen ohne Duplikate: {zahlen}")  # {1, 2, 3, 4, 5}
```

## 3.2 Set erstellen - Verschiedene Methoden

### Methode 1: Direkte Erstellung mit {}

```python
# Direkt mit geschweiften Klammern
programmiersprachen = {"Python", "Java", "JavaScript"}
print(programmiersprachen)
```

### Methode 2: Aus Listen (Duplikate werden entfernt)

```python
# Set aus Liste - entfernt Duplikate automatisch
namen_liste = ["Anna", "Bob", "Charlie", "Anna", "Diana", "Bob"]
eindeutige_namen = set(namen_liste)

print(f"Original Liste: {namen_liste}")
print(f"Als Set: {eindeutige_namen}")        # {'Anna', 'Bob', 'Charlie', 'Diana'}

# Zurück zur Liste
namen_ohne_duplikate = list(eindeutige_namen)
print(f"Liste ohne Duplikate: {namen_ohne_duplikate}")
```

### Methode 3: Leeres Set

```python
# WICHTIG: Leeres Set mit set(), nicht {}
leeres_set = set()     # ✅ Das ist ein Set
leeres_dict = {}       # ❌ Das ist ein Dictionary!

print(f"Leeres Set: {leeres_set}, Typ: {type(leeres_set)}")
print(f"Leeres Dict: {leeres_dict}, Typ: {type(leeres_dict)}")
```

### Methode 4: Aus Strings und anderen Objekten

```python
# Set aus String - jeder Buchstabe wird ein Element
buchstaben = set("Python")
print(f"Buchstaben in 'Python': {buchstaben}")  # {'P', 'y', 't', 'h', 'o', 'n'}

# Set aus range
zahlen = set(range(1, 6))
print(f"Zahlen 1-5: {zahlen}")  # {1, 2, 3, 4, 5}
```

## 3.3 Elemente hinzufügen und entfernen

```python
# Set mit Programmiersprachen
sprachen = {"Python", "Java"}
print(f"Original: {sprachen}")

# Einzelnes Element hinzufügen
sprachen.add("JavaScript")
print(f"Nach add(): {sprachen}")

# Mehrere Elemente hinzufügen
sprachen.update(["C++", "Go", "Rust"])
print(f"Nach update(): {sprachen}")
```

```python
# Elemente entfernen - verschiedene Methoden
test_set = {"a", "b", "c", "d"}

# remove() - Fehler wenn Element nicht existiert
test_set.remove("a")
print(f"Nach remove('a'): {test_set}")

# discard() - KEIN Fehler wenn Element nicht existiert
test_set.discard("b")     # Element existiert - wird entfernt
test_set.discard("xyz")   # Element existiert nicht - kein Fehler!
print(f"Nach discard(): {test_set}")

# pop() - entfernt beliebiges Element
entfernt = test_set.pop()
print(f"Entferntes Element: {entfernt}")
print(f"Nach pop(): {test_set}")

# clear() - alles löschen
test_set.clear()
print(f"Nach clear(): {test_set}")  # set()
```

## 3.4 Membership-Tests (sehr schnell!)

```python
# Sets sind extrem schnell beim Prüfen ob Element vorhanden ist
farben = {"rot", "grün", "blau", "gelb", "orange", "lila"}

# Prüfen ob Element im Set ist
print(f"'rot' in Set: {'rot' in farben}")          # True
print(f"'schwarz' in Set: {'schwarz' in farben}")  # False

# Vergleich: Set vs. Liste für große Datenmengen
große_liste = list(range(100000))
großes_set = set(range(100000))

# Set-Suche ist viel schneller als Listen-Suche!
print(f"99999 in Liste: {99999 in große_liste}")   # Langsam
print(f"99999 in Set: {99999 in großes_set}")      # Sehr schnell
```

## 3.5 Praktische Anwendungen

### Duplikate aus Listen entfernen

```python
# E-Mail-Liste mit Duplikaten bereinigen
emails = [
    "anna@test.de", 
    "bob@web.com", 
    "anna@test.de",      # Duplikat
    "charlie@mail.org",
    "bob@web.com"        # Duplikat
]

# Duplikate entfernen
eindeutige_emails = set(emails)
bereinigte_liste = list(eindeutige_emails)

print(f"Original ({len(emails)}): {emails}")
print(f"Bereinigt ({len(bereinigte_liste)}): {bereinigte_liste}")
```

### Wörter in Text analysieren

```python
# Eindeutige Wörter in einem Text finden
text = "Python ist toll Python macht Spaß Python ist einfach"
alle_woerter = text.lower().split()
eindeutige_woerter = set(alle_woerter)

print(f"Alle Wörter: {alle_woerter}")
print(f"Eindeutige Wörter: {eindeutige_woerter}")
print(f"Anzahl eindeutige Wörter: {len(eindeutige_woerter)}")
```

### Berechtigungssystem

```python
# Sets für Benutzerberechtigungen
admin_rechte = {"lesen", "schreiben", "löschen", "admin"}
editor_rechte = {"lesen", "schreiben", "bearbeiten"}
viewer_rechte = {"lesen"}

# Benutzer und ihre Rechte
benutzer_rechte = {
    "alice": admin_rechte,
    "bob": editor_rechte,
    "charlie": viewer_rechte
}

def hat_berechtigung(benutzer, berechtigung):
    """Prüft ob Benutzer eine Berechtigung hat"""
    rechte = benutzer_rechte.get(benutzer, set())
    return berechtigung in rechte

# Tests
print(f"Alice kann löschen: {hat_berechtigung('alice', 'löschen')}")    # True
print(f"Bob kann löschen: {hat_berechtigung('bob', 'löschen')}")        # False
print(f"Charlie kann lesen: {hat_berechtigung('charlie', 'lesen')}")    # True
```

## 3.6 frozenset - Unveränderliche Sets

```python
# frozenset ist unveränderlich (wie Tupel vs. Liste)
normales_set = {1, 2, 3}
unveränderliches_set = frozenset([1, 2, 3])

print(f"Normales Set: {normales_set}")
print(f"Frozen Set: {unveränderliches_set}")

# frozenset kann als Dictionary-Schlüssel verwendet werden
gruppen = {
    frozenset([1, 2]): "Gruppe A",
    frozenset([3, 4]): "Gruppe B"
}
print(f"frozenset als Schlüssel: {gruppen}")

# Normale Sets können NICHT als Schlüssel verwendet werden
# {normales_set: "Fehler"}  # TypeError!
```

## 3.7 Wann Sets verwenden?

**Sets verwenden wenn Sie:**
- Duplikate automatisch entfernen wollen
- Schnell prüfen müssen ob Element vorhanden ist
- Eindeutige Elemente sammeln
- Membership-Tests häufig durchführen

**Nicht verwenden wenn:**
- Reihenfolge wichtig ist
- Duplikate erlaubt sein sollen
- Numerische Indizes benötigt werden

```python
# Entscheidungshilfe
verwendung = {
    "Set verwenden": [
        "Duplikate entfernen",
        "Schnelle Membership-Tests", 
        "Eindeutige Sammlung",
        "Berechtigungen verwalten"
    ],
    "Liste verwenden": [
        "Reihenfolge wichtig",
        "Duplikate erlaubt",
        "Indexzugriff nötig"
    ],
    "Dictionary verwenden": [
        "Schlüssel-Wert-Paare",
        "Benannte Zugriffe"
    ]
}

for struktur, anwendungen in verwendung.items():
    print(f"\n{struktur}:")
    for anwendung in anwendungen:
        print(f"  • {anwendung}")
```
