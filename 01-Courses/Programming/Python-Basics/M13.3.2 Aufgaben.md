## Aufgaben

### Aufgabe 1: Persönlicher Datenreport

Erstellen Sie einen formatierten Report mit persönlichen Daten.

**Was Sie tun sollen:**
```python
# Zelle 1: Persönlicher Datenreport
person_daten = {
    "name": "Max Mustermann",
    "alter": 28,
    "gehalt": 3750.80,
    "arbeitszeit": 0.8,  # 80% Stelle
    "urlaub_tage": 25,
    "verbrauchte_urlaub_tage": 18
}

# TODO: Erstellen Sie einen schön formatierten Report mit:
# - Jahresgehalt (Monatsgehalt * 12)
# - Arbeitszeit in Prozent
# - Verbleibende Urlaubstage
# - Alles mit passender Formatierung (Geld mit 2 Nachkommastellen, etc.)
```

**💡 Lösungshinweise:**
- Verwenden Sie f-Strings für alle Ausgaben
- `{betrag:.2f}` für 2 Nachkommastellen
- `{prozent:.0%}` für Prozentangaben
- `{zahl:,}` für Tausender-Kommas (funktioniert im englischen Format)
- Berechnen Sie verbleibende Urlaubstage: `urlaub_tage - verbrauchte_urlaub_tage`

**Erwartete Ausgabe:**
```
PERSONAL-DATENREPORT
====================
Name: Max Mustermann
Alter: 28 Jahre
Monatsgehalt: 3,750.80 €
Jahresgehalt: 45,009.60 €
Arbeitszeit: 80%
Urlaubstage: 7 von 25 Tagen verbleibend
```

### Aufgabe 4: Fortschritts-Dashboard

Erstellen Sie ein Dashboard mit verschiedenen Fortschrittsanzeigen.

**Was Sie tun sollen:**
```python

projekte = [
    ("Website Redesign", 75, 100),     # (Name, Erledigt, Gesamt)
    ("Mobile App", 23, 50),
    ("Datenbank Migration", 45, 45),
    ("User Testing", 12, 30),
    ("Documentation", 8, 25)
]

# TODO: Erstellen Sie ein Dashboard mit:
# 1. Titel "PROJEKT-DASHBOARD"
# 2. Für jedes Projekt: Name, Fortschrittsbalken, Prozent
# 3. Fortschrittsbalken mit █ (erledigt) und ░ (offen) 
# 4. Balken soll 20 Zeichen breit sein
# 5. Gesamtfortschritt aller Projekte
```

**💡 Lösungshinweise:**
- Prozent berechnen: `erledigt / gesamt` (aufpassen bei Division durch 0)

- Gesamtfortschritt: Alle erledigten Aufgaben / alle Aufgaben

**Erwartetes Format:**
```

=================

Mobile App           █████████░░░░░░░░░░░░  46%
...
```

## 💡 Hilfreiche Formatierungs-Codes

```python
# Zahlenformatierung
{zahl:.2f}          # 2 Nachkommastellen: 12.34
{zahl:.0f}          # Keine Nachkommastellen: 12
{zahl:,.2f}         # Mit Tausender-Komma: 1,234.56
{zahl:>8.2f}        # Rechtsbündig, 8 Zeichen breit: "   12.34"
{zahl:08.2f}        # Mit Nullen aufgefüllt: "00012.34"

# Prozente
{anteil:.1%}        # Als Prozent: 75.0%
{anteil:.0%}        # Ohne Nachkommastellen: 75%

# Text-Ausrichtung
{text:<10}          # Linksbündig, 10 Zeichen: "Text      "
{text:>10}          # Rechtsbündig: "      Text"
{text:^10}          # Zentriert: "   Text   "
{text:*^10}         # Mit Füllzeichen: "***Text***"

# Debugging
{variable=}         # Zeigt: variable=wert
{ausdruck=:.2f}     # Zeigt: ausdruck=12.34
```
