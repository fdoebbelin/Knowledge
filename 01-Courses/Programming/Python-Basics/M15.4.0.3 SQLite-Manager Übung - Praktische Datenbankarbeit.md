## Übungsziel

In dieser Übung erstellen Sie eine vollständige Datenbank für ein **Bibliothekssystem** mit mehreren verknüpften Tabellen. Sie lernen dabei die wichtigsten Funktionen des DB Browser for SQLite kennen und führen typische Datenbankoperationen durch.

## Vorbereitung

1. DB Browser for SQLite starten: `sqlitebrowser` in PowerShell eingeben
2. Neue Datenbank erstellen: **File → New Database**
3. Dateiname: `bibliothek.db` 
4. Speicherort wählen (z.B. Desktop oder Kursmaterialien-Ordner)

| Field Name | Type | PK | AI | U | NN | Default |
|------------|------|----|----|---|----|---------| 
| id | INTEGER | ✓ | ✓ | | ✓ | |
| vorname | TEXT | | | | ✓ | |
| nachname | TEXT | | | | ✓ | |

## Teil 2: Daten mit SQL-INSERT-Befehlen einfügen

### Schritt 2.1: Execute SQL Tab öffnen

1. **Execute SQL** Tab klicken
2. Hier werden wir alle Daten mit SQL-INSERT-Befehlen einfügen
3. Nach jedem SQL-Block auf **Execute** (F5) klicken

### Schritt 2.2: Autoren hinzufügen

Folgenden SQL-Code eingeben und ausführen:

```sql
-- Autoren einfügen
INSERT INTO autoren (vorname, nachname, geburtsjahr, nationalitaet) VALUES 
    ('Hermann', 'Hesse', 1877, 'Deutschland'),
    ('Agatha', 'Christie', 1890, 'England'),
    ('George', 'Orwell', 1903, 'England'),
    ('Paulo', 'Coelho', 1947, 'Brasilien');
```

**Prüfung:** 
```sql
SELECT * FROM autoren;
```

### Schritt 2.3: Bücher hinzufügen

```sql
-- Bücher einfügen
INSERT INTO buecher (titel, isbn, erscheinungsjahr, seitenzahl, kategorie, autor_id, verfuegbar) VALUES 
    ('Der Steppenwolf', '978-3-518-36675-8', 1927, 288, 'Roman', 1, 1),
    ('Mord im Orient-Express', '978-3-596-21200-4', 1934, 256, 'Krimi', 2, 1),
    ('1984', '978-3-548-23414-9', 1949, 416, 'Dystopie', 3, 1),
    ('Der Alchimist', '978-3-257-23045-1', 1988, 176, 'Roman', 4, 1);
```

**Prüfung mit JOIN:**
```sql
-- Bücher mit Autorennamen anzeigen
SELECT b.titel, a.vorname, a.nachname, b.kategorie 
FROM buecher b 
JOIN autoren a ON b.autor_id = a.id;
```

### Schritt 2.4: Mitglieder hinzufügen

```sql
-- Mitglieder einfügen
INSERT INTO mitglieder (vorname, nachname, email, telefon, anmeldedatum, aktiv) VALUES 
    ('Max', 'Mustermann', 'max.mustermann@email.com', '0151-12345678', '2024-01-15', 1),
    ('Anna', 'Schmidt', 'anna.schmidt@email.com', NULL, '2024-02-20', 1),
    ('Tom', 'Weber', 'tom.weber@email.com', '0176-98765432', '2024-03-10', 1);
```

**Prüfung:**
```sql
SELECT vorname, nachname, email, anmeldedatum FROM mitglieder WHERE aktiv = 1;
```

### Schritt 2.5: Ausleihen hinzufügen

```sql
-- Ausleihen einfügen
INSERT INTO ausleihen (buch_id, mitglied_id, ausleihdatum, rueckgabedatum, zurueckgegeben) VALUES 
    (1, 1, '2024-07-01', NULL, 0),
    (2, 2, '2024-07-10', '2024-07-20', 1);
```

**Prüfung mit komplexem JOIN:**
```sql
-- Alle Ausleihen mit Details anzeigen
SELECT 
    m.vorname || ' ' || m.nachname AS mitglied,
    b.titel AS buch,
    a.nachname AS autor,
    au.ausleihdatum,
    au.rueckgabedatum,
    CASE 
        WHEN au.zurueckgegeben = 1 THEN 'Zurückgegeben'
        ELSE 'Ausgeliehen'
    END AS status
FROM ausleihen au
JOIN mitglieder m ON au.mitglied_id = m.id
JOIN buecher b ON au.buch_id = b.id
JOIN autoren a ON b.autor_id = a.id
ORDER BY au.ausleihdatum DESC;
```

## Teil 3: Daten mit SQL-UPDATE und INSERT bearbeiten

### Schritt 3.1: Verfügbarkeit eines Buchs ändern (UPDATE)

```sql
-- Buch als ausgeliehen markieren
UPDATE buecher 
SET verfuegbar = 0 
WHERE titel = 'Der Steppenwolf';
```

**Prüfung:**
```sql
SELECT titel, verfuegbar FROM buecher WHERE titel = 'Der Steppenwolf';
```

### Schritt 3.2: Neuen Autor hinzufügen (INSERT)

```sql
-- Neuen Autor einfügen
INSERT INTO autoren (vorname, nachname, geburtsjahr, nationalitaet) 
VALUES ('Jane', 'Austen', 1775, 'England');
```

**Prüfung:**
```sql
SELECT * FROM autoren WHERE nachname = 'Austen';
```

### Schritt 3.3: Ausleihe als zurückgegeben markieren (UPDATE)

```sql
-- Erste Ausleihe als zurückgegeben markieren
UPDATE ausleihen 
SET rueckgabedatum = '2024-07-15', zurueckgegeben = 1 
WHERE id = 1;

-- Entsprechendes Buch wieder als verfügbar markieren
UPDATE buecher 
SET verfuegbar = 1 
WHERE id = 1;
```

**Prüfung:**
```sql
-- Status der Ausleihe prüfen
SELECT 
    au.id,
    b.titel,
    au.ausleihdatum,
    au.rueckgabedatum,
    au.zurueckgegeben,
    b.verfuegbar
FROM ausleihen au
JOIN buecher b ON au.buch_id = b.id
WHERE au.id = 1;
```

### Schritt 3.4: Weitere Übungsbeispiele für UPDATE

```sql
-- E-Mail-Adresse eines Mitglieds ändern
UPDATE mitglieder 
SET email = 'max.mustermann.neu@email.com' 
WHERE vorname = 'Max' AND nachname = 'Mustermann';

-- Telefonnummer für Anna Schmidt hinzufügen
UPDATE mitglieder 
SET telefon = '0172-55555555' 
WHERE email = 'anna.schmidt@email.com';

-- Kategorie eines Buchs korrigieren
UPDATE buecher 
SET kategorie = 'Science Fiction' 
WHERE titel = '1984';
```

## Teil 4: SQL-Abfragen ausführen

### Schritt 4.1: Execute SQL Tab öffnen

1. **Execute SQL** Tab klicken
2. Hier können Sie eigene SQL-Befehle eingeben

### Schritt 4.2: Einfache Abfragen

**Alle Bücher anzeigen:**
```sql
SELECT * FROM buecher;
```

**Nur verfügbare Bücher:**
```sql
SELECT titel, autor_id FROM buecher WHERE verfuegbar = 1;
```

**Bücher nach Erscheinungsjahr sortiert:**
```sql
SELECT titel, erscheinungsjahr FROM buecher ORDER BY erscheinungsjahr;
```

### Schritt 4.3: Erweiterte Abfragen mit Joins

**Bücher mit Autorennamen:**
```sql
SELECT b.titel, a.vorname, a.nachname, b.erscheinungsjahr
FROM buecher b
JOIN autoren a ON b.autor_id = a.id;
```

**Aktuelle Ausleihen mit Details:**
```sql
SELECT 
    m.vorname || ' ' || m.nachname AS mitglied_name,
    b.titel,
    a.nachname AS autor,
    au.ausleihdatum
FROM ausleihen au
JOIN mitglieder m ON au.mitglied_id = m.id
JOIN buecher b ON au.buch_id = b.id
JOIN autoren a ON b.autor_id = a.id
WHERE au.zurueckgegeben = 0;
```

**Statistik: Bücher pro Kategorie:**
```sql
SELECT kategorie, COUNT(*) as anzahl_buecher
FROM buecher
GROUP BY kategorie
ORDER BY anzahl_buecher DESC;
```

## Tipps für die Praxis

1. **Regelmäßig speichern** - DB Browser speichert automatisch, aber sicherheitshalber Strg+S
2. **SQL-History nutzen** - Im Execute SQL Tab werden vorherige Abfragen gespeichert
3. **Tabellen-Ansicht anpassen** - Spaltenbreite durch Ziehen ändern
4. **Filter verwenden** - In Browse Data Tab oben Filter eingeben
5. **Backup erstellen** - Datenbank-Datei regelmäßig kopieren
