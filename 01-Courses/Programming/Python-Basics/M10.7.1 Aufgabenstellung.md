### Schritt 4: Metadaten erhalten mit functools.wraps (2 Minuten)

**Aufgabe:** Verbessern Sie die Dekoratoren um Funktionsmetadaten zu erhalten:

```python
# Zelle 4: Verbesserte Dekoratoren mit functools.wraps
import functools
import time

def verbesserter_performance_monitor(func):
    """
    Verbesserter Performance-Dekorator mit erhaltenen Metadaten.
    """
    cache = {}
    
    @functools.wraps(func)  # TODO: Verstehen Sie was das macht
    def wrapper(*args, **kwargs):
        key = (args, tuple(kwargs.items()))
        start_zeit = time.time()
        
        if key in cache:
            result = cache[key]
            dauer = time.time() - start_zeit
            print(f"💾 {func.__name__}: Cache-Hit in {dauer:.6f}s")
        else:
            result = func(*args, **kwargs)
            cache[key] = result
            dauer = time.time() - start_zeit
            print(f"🔄 {func.__name__}: Berechnung in {dauer:.4f}s")
        
        return result
    
    return wrapper

@verbesserter_performance_monitor
def komplexe_berechnung(x, y):
    """Führt eine komplexe mathematische Berechnung durch."""
    import time
    time.sleep(0.1)
    return x ** y + x * y

# TODO: Testen Sie komplexe_berechnung(2, 3) mehrfach
# TODO: Prüfen Sie: print(komplexe_berechnung.__name__)
# TODO: Prüfen Sie: print(komplexe_berechnung.__doc__)
```

**💡 Lösungshinweise:**

- **functools.wraps**: Erhält `__name__`, `__doc__` und andere Metadaten
- **Import**: `import functools` am Anfang
- **Anwendung**: `@functools.wraps(func)` direkt vor der wrapper-Definition
- **Ohne wraps**: `print(funktion.__name__)` würde "wrapper" zeigen
- **Mit wraps**: `print(funktion.__name__)` zeigt den ursprünglichen Namen

## 💡 Dekoratoren Kurzreferenz

```python
# Einfacher Dekorator
def mein_dekorator(func):
    def wrapper(*args, **kwargs):
        # Code vor Funktionsaufruf
        result = func(*args, **kwargs)
        # Code nach Funktionsaufruf
        return result
    return wrapper

# Anwendung
@mein_dekorator
def meine_funktion():
    pass

# Entspricht:
# meine_funktion = mein_dekorator(meine_funktion)

# Mit functools.wraps
import functools

def verbesserter_dekorator(func):
    @functools.wraps(func)  # Erhält Metadaten
    def wrapper(*args, **kwargs):
        return func(*args, **kwargs)
    return wrapper
```

## 🧩 Warum Dekoratoren?

**Vorteile:**

- **Wiederverwendbarkeit:** Ein Dekorator für viele Funktionen
- **Separation of Concerns:** Geschäftslogik von Cross-Cutting Concerns trennen
- **Sauberer Code:** Keine Wiederholung von Logging/Timing/Cache-Code
- **Flexibilität:** Funktionalität kann einfach aktiviert/deaktiviert werden

**Typische Anwendungen:**

- Performance-Monitoring (wie in dieser Übung)
- Logging und Debugging
- Authentifizierung und Autorisierung
- Input-Validierung
- Rate-Limiting
- Retry-Mechanismen
