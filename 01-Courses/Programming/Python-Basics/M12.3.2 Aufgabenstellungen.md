## Aufgabe 1: Erstes Set erstellen

Erstellen Sie Sets für folgende Daten:
1. Ihre Lieblingsfarben (mindestens 4)
2. Ziffern von 0-9 
3. Ein Set aus dem Wort "Programmierung"
4. Ein leeres Set

Geben Sie alle Sets aus und zeigen Sie ihre Größe mit `len()`.

**Lösungshinweise:**
- Set direkt: `{"rot", "blau", "grün"}`
- Aus String: `set("Programmierung")`
- Leeres Set: `set()`
- Größe: `len(mein_set)`

## Aufgabe 3: Set-Operationen üben

Erstellen Sie ein Set mit Programmiersprachen und führen Sie folgende Operationen durch:
1. Starten Sie mit: `{"Python", "Java", "JavaScript"}`
2. Fügen Sie "C++" hinzu
3. Fügen Sie mehrere Sprachen hinzu: "Go", "Rust", "TypeScript"
4. Entfernen Sie "Java" (mit `remove()`)
5. Versuchen Sie "PHP" zu entfernen (mit `discard()` - soll keinen Fehler geben)
6. Entfernen Sie ein beliebiges Element mit `pop()`

**Lösungshinweise:**
- Hinzufügen: `set.add(element)` und `set.update(liste)`
- Entfernen: `set.remove(element)` und `set.discard(element)`
- Beliebiges entfernen: `set.pop()`

## Aufgabe 5: E-Mail-Bereinigung

Sie haben eine E-Mail-Liste mit Duplikaten und ungültigen Adressen:
```python
emails = [
    "anna@test.de", "bob@web.com", "anna@test.de", 
    "invalid-email", "charlie@mail.org", "bob@web.com",
    "@invalid.com", "diana@shop.de", "invalid-email"
]
```

1. Entfernen Sie Duplikate
2. Filtern Sie ungültige E-Mails heraus (müssen "@" enthalten)
3. Sortieren Sie das Ergebnis alphabetisch
4. Zeigen Sie Statistiken (ursprünglich vs. bereinigt)

**Lösungshinweise:**
- Duplikate: `set(emails)`
- Filtern: `{email for email in emails if "@" in email}`
- Sortieren: `sorted(set)`

## Aufgabe 7: Wortanalyse

Analysieren Sie folgenden Text:
```python
text = "Python ist eine tolle Programmiersprache Python macht Spaß Programmieren mit Python ist einfach"
```

1. Finden Sie alle eindeutigen Wörter (ignorieren Sie Groß-/Kleinschreibung)
2. Entfernen Sie Stopwörter: "ist", "eine", "mit", "macht"
3. Finden Sie Wörter, die länger als 4 Zeichen sind
4. Zeigen Sie Statistiken: Gesamtwörter vs. eindeutige Wörter

**Lösungshinweise:**
- Text aufteilen: `text.lower().split()`
- Stopwörter entfernen: `woerter_set - stopwoerter_set`
- Filtern: `{wort for wort in woerter if len(wort) > 4}`
