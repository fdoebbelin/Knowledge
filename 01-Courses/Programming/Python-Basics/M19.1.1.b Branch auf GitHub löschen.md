Es gibt mehrere Wege, um einen Branch auf GitHub zu löschen:

## 1. Über die GitHub Web-Oberfläche

### Nach einem Pull Request:

- Wenn ein Pull Request gemerged wird, erscheint automatisch ein **"Delete branch"** Button
- Einfach klicken und der Branch wird gelöscht

### Manuell über die Branch-Übersicht:

1. Gehe zu deinem Repository
2. Klicke auf **"branches"** (neben der Branch-Auswahl)
3. Finde den Branch, den du löschen möchtest
4. Klicke auf das **Papierkorb-Symbol** 🗑️ rechts neben dem Branch-Namen

## 2. Über die Kommandozeile

### Remote Branch löschen:

```bash
git push origin --delete branch-name
```

oder die kürzere Syntax:

```bash
git push origin :branch-name
```

### Lokalen Branch löschen:

```bash
# Branch löschen (nur wenn gemerged)
git branch -d branch-name

# Branch forciert löschen (auch wenn nicht gemerged)
git branch -D branch-name
```

### Komplette Aufräumung:

```bash
# Alle lokalen References zu gelöschten Remote-Branches entfernen
git remote prune origin

# Oder beim nächsten fetch automatisch
git fetch --prune
```

## 3. Über GitHub CLI

```bash
# Branch lokal und remote löschen
gh repo delete-branch branch-name

# Nur remote löschen
gh api repos/:owner/:repo/git/refs/heads/branch-name -X DELETE
```

## Wichtige Hinweise:

⚠️ **Default Branch** kann nicht gelöscht werden ⚠️ **Protected Branches** benötigen erst das Entfernen des Schutzes ⚠️ **Lokale Kopien** bleiben bestehen, bis du sie manuell löschst

**Tipp**: Nach dem Löschen eines Remote-Branches solltest du auch deine lokale Kopie aufräumen, um Verwirrung zu vermeiden!
