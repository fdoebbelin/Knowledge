## 🔧 Musterlösung - Schritt für Schritt

### Schritt 1: Formatierungsfunktionen erstellen

```python
# Zelle 1: Einfache Formatierungsfunktionen
def gross_schreibung(text):
    """Wandelt Text in Großbuchstaben um."""
    return text.upper()

def klein_schreibung(text):
    """Wandelt Text in Kleinbuchstaben um."""
    return text.lower()

def leerzeichen_entfernen(text):
    """Entfernt Leerzeichen am Anfang und Ende."""
    return text.strip()

# Test der Funktionen
test_text = "  Hallo Welt  "
print(f"🧪 TEST DER FORMATIERUNGSFUNKTIONEN")
print(f"Original: '{test_text}'")
print(f"Groß: '{gross_schreibung(test_text)}'")
print(f"Klein: '{klein_schreibung(test_text)}'")
print(f"Ohne Leerzeichen: '{leerzeichen_entfernen(test_text)}'")

print(f"\n✅ Alle drei Grundfunktionen funktionieren!")
```

### Schritt 2: Formatierungsfunktion mit Callback

```python
# Zelle 2: Hauptfunktion die andere Funktionen verwendet
def formatiere_text(text, formatierungs_funktion):
    """
    Wendet eine Formatierungsfunktion auf einen Text an.
    
    Parameter:
    - text: Der zu formatierende Text
    - formatierungs_funktion: Die Funktion, die angewendet werden soll
    
    Rückgabe:
    - Der formatierte Text
    """
    # Die übergebene Funktion aufrufen
    return formatierungs_funktion(text)

# Test mit verschiedenen Funktionen
test_text = "  Python IST toll  "
print(f"🧪 TEST DES CALLBACK-PRINZIPS")
print(f"Original: '{test_text}'")
print(f"Mit Groß: '{formatiere_text(test_text, gross_schreibung)}'")
print(f"Mit Klein: '{formatiere_text(test_text, klein_schreibung)}'")
print(f"Ohne Leerzeichen: '{formatiere_text(test_text, leerzeichen_entfernen)}'")

print(f"\n✅ Callback-Funktion funktioniert! Eine Funktion ruft eine andere auf.")
```

### Schritt 3: Mehrere Texte formatieren

```python
# Zelle 3: Liste von Texten formatieren
def formatiere_text_liste(text_liste, formatierungs_funktion):
    """
    Wendet eine Formatierung auf alle Texte in einer Liste an.
    
    Parameter:
    - text_liste: Liste von Texten
    - formatierungs_funktion: Die Formatierungsfunktion
    
    Rückgabe:
    - Liste mit formatierten Texten
    """
    ergebnis = []
    for text in text_liste:
        # Für jeden Text die Formatierungsfunktion anwenden
        formatierter_text = formatierungs_funktion(text)
        ergebnis.append(formatierter_text)
    return ergebnis

# Test mit Testdaten
print("🧪 TEST MIT MEHREREN TEXTEN")
print("Original-Texte:")
for i, text in enumerate(test_texte, 1):
    print(f"  {i}. '{text}'")

print("\n📝 Groß formatiert:")
gross_texte = formatiere_text_liste(test_texte, gross_schreibung)
for i, text in enumerate(gross_texte, 1):
    print(f"  {i}. '{text}'")

print("\n📝 Klein formatiert:")
klein_texte = formatiere_text_liste(test_texte, klein_schreibung)
for i, text in enumerate(klein_texte, 1):
    print(f"  {i}. '{text}'")

print("\n📝 Leerzeichen entfernt:")
sauber_texte = formatiere_text_liste(test_texte, leerzeichen_entfernen)
for i, text in enumerate(sauber_texte, 1):
    print(f"  {i}. '{text}'")

print(f"\n✅ Listen-Formatierung funktioniert! Gleiche Funktion auf alle Texte angewendet.")
```

### Schritt 4: Kombination von Formatierungen

```python
# Zelle 4: Mehrere Formatierungen nacheinander anwenden
def mehrfach_formatieren(text, *formatierungs_funktionen):
    """
    Wendet mehrere Formatierungsfunktionen nacheinander an.
    
    Parameter:
    - text: Der ursprüngliche Text
    - formatierungs_funktionen: Beliebig viele Formatierungsfunktionen
    
    Rückgabe:
    - Der mehrfach formatierte Text
    """
    ergebnis = text
    print(f"  Start: '{ergebnis}'")
    
    # Jede Formatierungsfunktion nacheinander anwenden
    for i, funktion in enumerate(formatierungs_funktionen, 1):
        ergebnis = funktion(ergebnis)
        print(f"  Schritt {i}: '{ergebnis}' (mit {funktion.__name__})")
    
    return ergebnis

# Test der Mehrfach-Formatierung
test_text = "  PYTHON ist TOLL  "
print(f"🧪 TEST DER MEHRFACH-FORMATIERUNG")
print(f"Original: '{test_text}'")

print(f"\n📝 Formatierung 1: Leerzeichen weg + Klein")
formatiert1 = mehrfach_formatieren(test_text, leerzeichen_entfernen, klein_schreibung)
print(f"Endergebnis: '{formatiert1}'")

print(f"\n📝 Formatierung 2: Alle drei Schritte")
formatiert2 = mehrfach_formatieren(test_text, leerzeichen_entfernen, klein_schreibung, gross_schreibung)
print(f"Endergebnis: '{formatiert2}'")

print(f"\n✅ Mehrfach-Formatierung funktioniert! Funktionen werden der Reihe nach ausgeführt.")
```

## 🎓 Zusammenfassung der Lösung

### Was haben wir implementiert?

1. **Grundfunktionen**: Drei einfache Formatierungsfunktionen
   - `gross_schreibung()` - macht Text groß
   - `klein_schreibung()` - macht Text klein  
   - `leerzeichen_entfernen()` - entfernt Leerzeichen

2. **Callback-Funktion**: `formatiere_text(text, funktion)`
   - Nimmt eine Funktion als Parameter entgegen
   - Ruft diese Funktion mit dem Text auf
   - **Das ist das Herzstück der Higher-order Functions!**

3. **Listen-Verarbeitung**: `formatiere_text_liste(liste, funktion)`
   - Wendet die gleiche Formatierung auf alle Texte an
   - Zeigt, wie Callbacks bei der Datenverarbeitung helfen

4. **Mehrfach-Anwendung**: `mehrfach_formatieren(text, *funktionen)`
   - Kombiniert beliebig viele Formatierungen
   - Nutzt `*args` für variable Anzahl von Funktionen

### Wichtige Konzepte verstanden:

- **Funktionen sind Objekte**: Sie können wie Variablen übergeben werden
- **Callback-Prinzip**: Eine Funktion ruft eine andere, übergebene Funktion auf
- **Flexibilität**: Das gleiche System funktioniert mit verschiedenen Funktionen
- **Erweiterbarkeit**: Neue Formatierungsfunktionen lassen sich einfach hinzufügen

### Praktischer Nutzen:

- **Event-Handler** in grafischen Oberflächen
- **Datenverarbeitung** mit verschiedenen Algorithmen
- **Konfigurierbare Systeme** die verschiedene Strategien nutzen können
