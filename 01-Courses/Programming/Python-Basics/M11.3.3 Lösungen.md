### Schritt 1: Tupel erstellen

```python
# 1. Erstellen Sie ein leeres Tupel
```

### Schritt 2: Tupel vs Listen testen

### Schritt 3: Tupel-Methoden
```python
# Gegeben ist dieses Tupel:
buchstaben = ('a', 'b', 'c', 'b', 'd', 'b', 'e')

# Zählen Sie, wie oft 'b' vorkommt
anzahl_b = buchstaben.count('b')  # count() Methode

# Finden Sie die Position des ersten 'b'
position_b = buchstaben.index('b')  # index() Methode

print(f"Buchstaben: {buchstaben}")
print(f"Anzahl 'b': {anzahl_b}")
print(f"Position erstes 'b': {position_b}")

# Ausgabe:
# Buchstaben: ('a', 'b', 'c', 'b', 'd', 'b', 'e')
# Anzahl 'b': 3
# Position erstes 'b': 1
```

**💡 Erklärung:**
- Leeres Tupel: `()` 
- Ein-Element-Tupel: `(42,)` - das Komma ist entscheidend!
- Tupel sind unveränderlich → `TypeError` beim Änderungsversuch
- Nur zwei Methoden: `count()` und `index()`
## Aufgabe 2: Tuple Unpacking
### Schritt 1: Einfaches Unpacking
```python
# Gegeben sind diese Tupel:
punkt_2d = (15, 25)
person = ("Anna", 22, "Studentin", "Berlin")

# Entpacken Sie den 2D-Punkt
x, y = punkt_2d  # Tupel in einzelne Variablen entpacken
print(f"Punkt: x={x}, y={y}")

# Entpacken Sie die Person-Informationen
name, alter, beruf, stadt = person  # Alle vier Werte entpacken
print(f"Person: {name}, {alter} Jahre, {beruf} aus {stadt}")

# Ausgabe:
# Punkt: x=15, y=25
# Person: Anna, 22 Jahre, Studentin aus Berlin
```

### Schritt 2: Variablen tauschen
```python
# Gegeben sind diese Variablen:
a = 100
b = 200
c = 300

print(f"Vorher: a={a}, b={b}, c={c}")

# Tauschen Sie a und b (ohne Hilfsvariable!)
a, b = b, a  # Eleganter Python-Weg zum Tauschen

# Rotieren Sie alle drei Variablen: a→b, b→c, c→a
a, b, c = c, a, b  # Alle drei gleichzeitig rotieren

print(f"Nach Tausch: a={a}, b={b}, c={c}")

# Ausgabe:
# Vorher: a=100, b=200, c=300
# Nach Tausch: a=300, b=100, c=200
```

### Schritt 3: Funktionen mit Tupel-Rückgabe
```python
def get_name_age():
    """Gibt Name und Alter als Tupel zurück"""
    return "Bob", 25  # Tupel ohne Klammern

def berechne_rechteck(laenge, breite):
    """Berechnet Umfang und Fläche eines Rechtecks"""
    umfang = 2 * (laenge + breite)
    flaeche = laenge * breite
    return umfang, flaeche  # Tupel mit beiden Werten zurückgeben

# Entpacken Sie die Rückgabewerte
name, alter = get_name_age()  # Tupel-Rückgabe entpacken
print(f"Name: {name}, Alter: {alter}")

u, f = berechne_rechteck(5, 3)  # Funktions-Rückgabe entpacken
print(f"Rechteck 5x3: Umfang={u}, Fläche={f}")

# Ausgabe:
# Name: Bob, Alter: 25
# Rechteck 5x3: Umfang=16, Fläche=15
```

**💡 Erklärung:**
- Unpacking: `x, y = tupel` weist die Tupel-Elemente einzelnen Variablen zu
- Tauschen: `a, b = b, a` ist der elegante Python-Weg
- Funktionen können Tupel zurückgeben: `return wert1, wert2`
## Aufgabe 3: Erweiterte Unpacking-Patterns

```python
# Gegeben sind diese Tupel:
zahlen = (1, 2, 3, 4, 5, 6, 7, 8)
alphabet = ('a', 'b', 'c', 'd', 'e', 'f')

# 1. Erstes Element, alles andere in 'rest'
erste, *rest = zahlen  # * sammelt den Rest in eine Liste
print(f"Erste: {erste}, Rest: {rest}")
# Ausgabe: Erste: 1, Rest: [2, 3, 4, 5, 6, 7, 8]

# 2. Erstes, letztes Element, alles andere in 'mitte'
erste, *mitte, letzte = zahlen  # * sammelt die Mitte
print(f"Erste: {erste}, Mitte: {mitte}, Letzte: {letzte}")
# Ausgabe: Erste: 1, Mitte: [2, 3, 4, 5, 6, 7], Letzte: 8

# 3. Erste zwei Elemente, dann Rest
erste, zweite, *rest = zahlen  # Erste zwei einzeln, Rest gesammelt
print(f"Erste zwei: {erste}, {zweite}, Rest: {rest}")
# Ausgabe: Erste zwei: 1, 2, Rest: [3, 4, 5, 6, 7, 8]

# 4. Alle außer den letzten zwei
*anfang, vorletzte, letzte = zahlen  # * am Anfang für den Anfang
print(f"Anfang: {anfang}, Letzte zwei: {vorletzte}, {letzte}")
# Ausgabe: Anfang: [1, 2, 3, 4, 5, 6], Letzte zwei: 7, 8

# 5. Nur erstes und letztes (Rest ignorieren)
erste, *_, letzte = zahlen  # _ bedeutet "ignorieren"
print(f"Nur erste und letzte: {erste}, {letzte}")
# Ausgabe: Nur erste und letzte: 1, 8
```

**💡 Erklärung:**
- `*variable` sammelt mehrere Elemente in eine Liste
- `*_` sammelt und ignoriert Elemente (underscore = unwichtig)
- Der `*` kann an verschiedenen Positionen stehen
- Das Ergebnis von `*` ist immer eine Liste, auch wenn das Original ein Tupel war
## Aufgabe 4: Koordinaten-System
### Schritt 1: 2D-Punkte
```python
def erstelle_punkt(x, y):
    """Erstellt einen 2D-Punkt als Tupel"""
    return (x, y)  # Koordinaten als Tupel zurückgeben

def punkte_addieren(punkt1, punkt2):
    """Addiert zwei 2D-Punkte"""
    x1, y1 = punkt1  # Ersten Punkt entpacken
    x2, y2 = punkt2  # Zweiten Punkt entpacken
    return (x1 + x2, y1 + y2)  # Neuer Punkt als Tupel

def punkt_info(punkt):
    """Zeigt Informationen über einen Punkt"""
    x, y = punkt  # Punkt entpacken
    print(f"Punkt: ({x}, {y})")

# Testen Sie Ihre Funktionen
punkt_a = erstelle_punkt(2, 3)
punkt_b = erstelle_punkt(5, 7)

punkt_info(punkt_a)     # Punkt: (2, 3)
punkt_info(punkt_b)     # Punkt: (5, 7)

summe = punkte_addieren(punkt_a, punkt_b)
punkt_info(summe)       # Punkt: (7, 10)
```

### Schritt 2: 3D-Punkte
```python
def erstelle_3d_punkt(x, y, z):
    """Erstellt einen 3D-Punkt als Tupel"""
    return (x, y, z)  # Drei Koordinaten als Tupel

def entfernung_3d(punkt1, punkt2):
    """Berechnet die Entfernung zwischen zwei 3D-Punkten"""
    x1, y1, z1 = punkt1  # Ersten 3D-Punkt entpacken
    x2, y2, z2 = punkt2  # Zweiten 3D-Punkt entpacken
    
    dx = x2 - x1
    dy = y2 - y1
    dz = z2 - z1
    
    return (dx*dx + dy*dy + dz*dz) ** 0.5  # Euklidische Distanz

# Test
punkt1 = erstelle_3d_punkt(0, 0, 0)
punkt2 = erstelle_3d_punkt(3, 4, 0)
distanz = entfernung_3d(punkt1, punkt2)
print(f"Entfernung: {distanz}")  # Ausgabe: Entfernung: 5.0
```

**💡 Erklärung:**
- Koordinaten sind perfekt für Tupel (feste Struktur, unveränderlich)
- Unpacking macht Berechnungen lesbar: `x, y = punkt`
- 3D-Distanz: √((x₂-x₁)² + (y₂-y₁)² + (z₂-z₁)²)

```python
def berechne_statistiken(datenbank):
    """Berechnet Statistiken über die Studenten"""
    if not datenbank:
        return "Keine Daten"
    
    semester_liste = []
    studiengaenge = []
    
    for student in datenbank:
        # Entpacken Sie den Studenten
        _, _, _, studiengang, semester = student  # Nur Studiengang und Semester interessieren
        semester_liste.append(semester)
        if studiengang not in studiengaenge:
            studiengaenge.append(studiengang)
    
    return {
        "anzahl_studenten": len(datenbank),
        "durchschnitt_semester": sum(semester_liste) / len(semester_liste),
        "min_semester": min(semester_liste),
        "max_semester": max(semester_liste),
        "anzahl_studiengaenge": len(studiengaenge),
        "studiengaenge": studiengaenge
    }

stats = berechne_statistiken(studenten_db)
print("\nStatistiken:")
for key, value in stats.items():
    if isinstance(value, float):
        print(f"  {key}: {value:.1f}")
    else:
        print(f"  {key}: {value}")

# Ausgabe:
# Statistiken:
#   anzahl_studenten: 4
#   durchschnitt_semester: 2.5
#   min_semester: 1
#   max_semester: 4
#   anzahl_studiengaenge: 3
#   studiengaenge: ['Informatik', 'Mathematik', 'Physik']
```

- Tupel als Datensätze: strukturiert und unveränderlich
- Entpackung in Schleifen: `for id, name, ... in datenbank:`
- `_` als Platzhalter für unwichtige Werte
- Listen für Sammlungen: `gefunden.append(student)`

## Häufige Anfängerfehler

### ❌ Ein-Element-Tupel ohne Komma
```python
# FALSCH:
falsch = (42)    # Das ist eine Zahl!
print(type(falsch))  # <class 'int'>

# RICHTIG:
richtig = (42,)  # Das ist ein Tupel!
print(type(richtig))  # <class 'tuple'>
```

### ❌ Tupel ändern wollen
```python
tupel = (1, 2, 3)
# FALSCH:
# tupel[0] = 99  # TypeError!

# RICHTIG: Neues Tupel erstellen
neues_tupel = (99,) + tupel[1:]
```

### ❌ Unpacking-Anzahl falsch
```python
tupel = (1, 2, 3)
# FALSCH:
# a, b = tupel  # ValueError: zu viele Werte!

# RICHTIG:
a, b, c = tupel  # Anzahl muss stimmen
# oder:
a, *rest = tupel  # Mit * für den Rest
```
## Wann Tupel statt Listen verwenden?

### ✅ Tupel verwenden für:
- **Koordinaten:** `(x, y, z)`
- **Datenbankzeilen:** Feste Struktur
- **Funktions-Rückgaben:** Mehrere Werte
- **Dictionary-Keys:** Zusammengesetzte Schlüssel
- **Konfiguration:** Unveränderliche Werte

### ✅ Listen verwenden für:
- **Sammlung gleichartiger Objekte:** `[name1, name2, ...]`
- **Veränderliche Daten:** Elemente hinzufügen/entfernen
- **Sortierung:** `list.sort()`
- **Viele Operationen:** `append()`, `remove()`, etc.
