## 4.1 Mathematische Mengenoperationen

Sets in Python unterstützen alle wichtigen mathematischen Mengenoperationen. Diese sind sowohl als **Operatoren** (`|`, `&`, `-`, `^`) als auch als **Methoden** verfügbar.

```python
# Beispiel-Sets für alle Demonstrationen
programmierer = {"Python", "Java", "JavaScript", "SQL"}
data_scientist = {"Python", "R", "SQL", "Tableau"}

print(f"Programmierer: {programmierer}")
print(f"Data Scientist: {data_scientist}")
```

## 4.2 Vereinigung (Union) ∪

Die **Vereinigung** enthält alle Elemente, die in mindestens einem der Sets vorkommen.

```python
# Vereinigung: Alle Skills von beiden Gruppen
# Methode 1: Mit | Operator
alle_skills_op = programmierer | data_scientist
print(f"Union mit |: {alle_skills_op}")

# Methode 2: Mit union() Methode
alle_skills_method = programmierer.union(data_scientist)
print(f"Union mit union(): {alle_skills_method}")

# Mehrere Sets vereinigen
analyst = {"Excel", "PowerBI", "SQL"}
alle_drei = programmierer | data_scientist | analyst
print(f"Drei Sets vereinigt: {alle_drei}")

# Mit Methode: Kann auch Listen als Argument nehmen
erweitert = programmierer.union(data_scientist, ["C++", "Go"])
print(f"Mit zusätzlichen Skills: {erweitert}")
```

## 4.3 Schnittmenge (Intersection) ∩

Die **Schnittmenge** enthält nur Elemente, die in **allen** Sets vorkommen.

```python
# Schnittmenge: Skills die beide Gruppen haben
# Methode 1: Mit & Operator
gemeinsame_skills_op = programmierer & data_scientist
print(f"Schnittmenge mit &: {gemeinsame_skills_op}")

# Methode 2: Mit intersection() Methode
gemeinsame_skills_method = programmierer.intersection(data_scientist)
print(f"Schnittmenge mit intersection(): {gemeinsame_skills_method}")

# Praktisches Beispiel: Welche Skills haben alle drei Gruppen?
gemeinsame_alle_drei = programmierer & data_scientist & analyst
print(f"Skills aller drei Gruppen: {gemeinsame_alle_drei}")

# Prüfen ob Sets überlappen
if programmierer & data_scientist:
    print("Programmierer und Data Scientists haben gemeinsame Skills!")
else:
    print("Keine gemeinsamen Skills gefunden.")
```

## 4.4 Differenz (Difference) -

Die **Differenz** enthält Elemente des ersten Sets, die **nicht** im zweiten Set sind.

```python
# Differenz: Was haben Programmierer, aber nicht Data Scientists?
# Methode 1: Mit - Operator
nur_programmierer_op = programmierer - data_scientist
print(f"Nur Programmierer mit -: {nur_programmierer_op}")

# Methode 2: Mit difference() Methode
nur_programmierer_method = programmierer.difference(data_scientist)
print(f"Nur Programmierer mit difference(): {nur_programmierer_method}")

# Umgekehrt: Was haben Data Scientists, aber nicht Programmierer?
nur_data_scientist = data_scientist - programmierer
print(f"Nur Data Scientists: {nur_data_scientist}")

# WICHTIG: Differenz ist nicht symmetrisch!
print(f"A - B: {programmierer - data_scientist}")
print(f"B - A: {data_scientist - programmierer}")
```

## 4.5 Symmetrische Differenz (Symmetric Difference) ⊕

Die **symmetrische Differenz** enthält Elemente, die nur in **einem** der Sets vorkommen (aber nicht in beiden).

```python
# Symmetrische Differenz: Skills die nur eine Gruppe hat
# Methode 1: Mit ^ Operator
nur_eine_gruppe_op = programmierer ^ data_scientist
print(f"Symmetrische Differenz mit ^: {nur_eine_gruppe_op}")

# Methode 2: Mit symmetric_difference() Methode
nur_eine_gruppe_method = programmierer.symmetric_difference(data_scientist)
print(f"Symmetrische Differenz mit Methode: {nur_eine_gruppe_method}")

# Praktisch: Was sind die einzigartigen Skills jeder Gruppe?
print("Skills die nur eine Gruppe hat:")
for skill in nur_eine_gruppe_op:
    if skill in programmierer:
        print(f"  {skill}: Nur Programmierer")
    else:
        print(f"  {skill}: Nur Data Scientists")
```

## 4.6 Teilmengen-Tests

```python
# Prüfen ob ein Set Teilmenge eines anderen ist
web_dev = {"JavaScript", "HTML", "CSS"}
frontend = {"JavaScript", "HTML", "CSS", "React", "Vue"}
backend = {"Python", "Java", "SQL", "Docker"}

# issubset() - Ist web_dev eine Teilmenge von frontend?
print(f"Web-Dev ⊆ Frontend: {web_dev.issubset(frontend)}")        # True
print(f"Web-Dev ⊆ Backend: {web_dev.issubset(backend)}")          # False

# Mit <= Operator (gleicher Effekt)
print(f"Web-Dev ⊆ Frontend (<=): {web_dev <= frontend}")          # True

# issuperset() - Ist frontend eine Obermenge von web_dev?
print(f"Frontend ⊇ Web-Dev: {frontend.issuperset(web_dev)}")      # True

# Mit >= Operator (gleicher Effekt)  
print(f"Frontend ⊇ Web-Dev (>=): {frontend >= web_dev}")          # True

# Echte Teilmenge (< und >) - muss kleiner sein
print(f"Web-Dev ⊂ Frontend: {web_dev < frontend}")               # True (echte Teilmenge)
print(f"Web-Dev ⊂ Web-Dev: {web_dev < web_dev}")                 # False (gleich)
```

## 4.7 Disjunkte Sets (keine gemeinsamen Elemente)

```python
# isdisjoint() - Haben zwei Sets keine gemeinsamen Elemente?
mobile_dev = {"Swift", "Kotlin", "Flutter"}
web_dev = {"JavaScript", "HTML", "CSS"}
fullstack = {"JavaScript", "Python", "SQL"}

print(f"Mobile und Web disjunkt: {mobile_dev.isdisjoint(web_dev)}")     # True
print(f"Web und Fullstack disjunkt: {web_dev.isdisjoint(fullstack)}")   # False (JavaScript)

# Praktische Anwendung: Überlappende Skills finden
if not web_dev.isdisjoint(fullstack):
    overlap = web_dev & fullstack
    print(f"Überlappende Skills: {overlap}")
```

## 4.8 Praktische Anwendungsbeispiele

### Beispiel 1: Benutzerrechte verwalten

```python
# Verschiedene Benutzergruppen
admins = {"alice", "bob"}
editors = {"bob", "charlie", "diana"}
viewers = {"diana", "eva", "frank"}

print("=== Benutzerrechte-Analyse ===")

# Wer hat mehrere Rollen?
admin_editors = admins & editors
print(f"Admin + Editor: {admin_editors}")

# Wer hat nur Viewer-Rechte?
nur_viewer = viewers - admins - editors
print(f"Nur Viewer: {nur_viewer}")

# Alle Benutzer im System
alle_benutzer = admins | editors | viewers
print(f"Alle Benutzer: {alle_benutzer}")
```

### Beispiel 2: Datenvalidierung

```python
# Erlaubte und vorhandene Werte vergleichen
erlaubte_kategorien = {"elektronik", "bücher", "kleidung", "sport"}
produkt_kategorien = {"elektronik", "bücher", "spielzeug", "haushalt"}

print("=== Kategorie-Validierung ===")

# Welche Kategorien sind gültig?
gueltige_kategorien = produkt_kategorien & erlaubte_kategorien
print(f"Gültige Kategorien: {gueltige_kategorien}")

# Welche Kategorien sind ungültig?
ungueltige_kategorien = produkt_kategorien - erlaubte_kategorien
print(f"Ungültige Kategorien: {ungueltige_kategorien}")

# Welche erlaubten Kategorien werden nicht genutzt?
ungenutzte_kategorien = erlaubte_kategorien - produkt_kategorien
print(f"Ungenutzte Kategorien: {ungenutzte_kategorien}")
```

### Beispiel 3: Text-Analyse

```python
# Wörter in verschiedenen Texten
text1_woerter = set("Python ist eine tolle Programmiersprache".lower().split())
text2_woerter = set("Java ist auch eine gute Programmiersprache".lower().split())

print("=== Text-Vergleich ===")
print(f"Text 1 Wörter: {text1_woerter}")
print(f"Text 2 Wörter: {text2_woerter}")

# Gemeinsame Wörter
gemeinsame_woerter = text1_woerter & text2_woerter
print(f"Gemeinsame Wörter: {gemeinsame_woerter}")

# Einzigartige Wörter pro Text
nur_text1 = text1_woerter - text2_woerter
nur_text2 = text2_woerter - text1_woerter
print(f"Nur in Text 1: {nur_text1}")
print(f"Nur in Text 2: {nur_text2}")

# Alle verschiedenen Wörter
alle_woerter = text1_woerter | text2_woerter
print(f"Alle verschiedenen Wörter: {alle_woerter}")
```

## 4.9 Operator vs. Methoden - Übersicht

```python
# Übersicht aller Set-Operationen
print("=== Set-Operationen Übersicht ===")
print("Operation          | Operator | Methode")
print("-" * 45)
print("Vereinigung        |    |     | union()")
print("Schnittmenge       |    &     | intersection()")
print("Differenz          |    -     | difference()")
print("Sym. Differenz     |    ^     | symmetric_difference()")
print("Teilmenge          |    <=    | issubset()")
print("Obermenge          |    >=    | issuperset()")
print("Echte Teilmenge    |    <     | ")
print("Echte Obermenge    |    >     | ")
print("Disjunkt           |    -     | isdisjoint()")

# Praktischer Vergleich
set_a = {1, 2, 3}
set_b = {3, 4, 5}

print(f"\nBeispiel: A = {set_a}, B = {set_b}")
print(f"A | B = {set_a | set_b}")
print(f"A & B = {set_a & set_b}")
print(f"A - B = {set_a - set_b}")
print(f"A ^ B = {set_a ^ set_b}")
```
