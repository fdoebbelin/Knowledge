def erstelle_personen_tabelle():

## 9. Fehlerbehandlung bei Datenbanken

### 9.1 Sichere Datenbankoperationen
```python
def sichere_datenbank_operation():
    """Führt Datenbankoperationen mit Fehlerbehandlung durch"""
    import sqlite3
    
    try:
        # Verbindung zur Datenbank
        verbindung = sqlite3.connect("test_fehler.db")
        cursor = verbindung.cursor()
        
        # Tabelle erstellen
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS test (
                id INTEGER PRIMARY KEY,
                name TEXT NOT NULL
            )
        """)
        
        # Test-Daten einfügen
        cursor.execute("INSERT INTO test (name) VALUES (?)", ('Testperson',))
        
        # Änderungen speichern
        verbindung.commit()
        ergebnis = "✅ Datenbank-Operation erfolgreich!"
        
    except sqlite3.Error as db_fehler:
        ergebnis = f"❌ Datenbankfehler: {db_fehler}"
        
    except Exception as fehler:
        ergebnis = f"❌ Allgemeiner Fehler: {fehler}"
        
    finally:
        # Verbindung immer schließen (falls vorhanden)
        if 'verbindung' in locals():
            cursor.close()
            verbindung.close()
    
    return ergebnis

print(sichere_datenbank_operation())
```

## 10. Connection Context Manager

### 10.1 Automatisches Schließen mit 'with'
```python
def verwende_context_manager():
    """Verwendet 'with' für automatisches Schließen der Datenbankverbindung"""
    import sqlite3
    
    # 'with' sorgt für automatisches Schließen
    with sqlite3.connect("context_test.db") as verbindung:
        cursor = verbindung.cursor()
        
        # Tabelle erstellen
        cursor.execute("""
            CREATE TABLE IF NOT EXISTS notizen (
                id INTEGER PRIMARY KEY,
                text TEXT,
                datum DATE DEFAULT CURRENT_DATE
            )
        """)
        
        # Notiz hinzufügen
        cursor.execute(
            "INSERT INTO notizen (text) VALUES (?)", 
            ('Das ist eine Testnotiz mit Context Manager',)
        )
        
        # Alle Notizen abfragen
        cursor.execute("SELECT * FROM notizen")
        notizen = cursor.fetchall()
        
        # Verbindung wird automatisch geschlossen!
    
    return f"✅ Context Manager verwendet - {len(notizen)} Notizen in Datenbank"

print(verwende_context_manager())
```

## Zusammenfassung

### Wichtige SQLite-Operationen:
1. **`sqlite3.connect()`** - Verbindung zur Datenbank herstellen
2. **`CREATE TABLE`** - Neue Tabelle mit Spalten erstellen
3. **`INSERT INTO`** - Neue Datensätze einfügen
4. **`SELECT`** - Daten aus Tabellen abfragen
5. **`WHERE`** - Daten nach Bedingungen filtern
6. **`UPDATE`** - Bestehende Daten ändern

### SQLite vs. andere Formate:
- **Textdateien:** Einfache Notizen und Listen
- **CSV-Dateien:** Tabellendaten ohne Beziehungen
- **JSON-Dateien:** Verschachtelte, strukturierte Daten
- **SQLite-Datenbanken:** Komplexe Abfragen, Beziehungen, große Datenmengen

### Wann SQLite verwenden?
SQLite ist ideal für:
- Strukturierte Daten mit Beziehungen
- Komplexe Suchkriterien und Filter
- Große Datenmengen (tausende Einträge)
- Datenintegrität und -konsistenz
- Mehrbenutzer-Anwendungen

### Wichtige Sicherheitsregeln:
- **Parameterplatzhalter (?)** für sichere Dateneingabe verwenden
- **try-except** für Fehlerbehandlung implementieren
- **Verbindungen schließen** mit cursor.close() und connection.close()
- **Context Manager (with)** für automatisches Schließen nutzen

### Nächste Schritte:
- Komplexere SQL-Abfragen (JOIN, GROUP BY)
- Fremdschlüssel und Tabellenbeziehungen
- Indizes für bessere Performance
- Backup und Export von Datenbanken
