## Aufgabe 1: Erstes Dictionary erstellen
Erstellen Sie ein Dictionary für sich selbst mit folgenden Informationen:
- Vorname
- Nachname  
- Alter
- Lieblingsfarbe
- Hobbys (als Liste)

Geben Sie dann einzelne Werte aus dem Dictionary aus.

**Lösungshinweise:**
- Verwenden Sie die Syntax: `{schluessel: wert}`
- Zugriff mit: `dictionary[schluessel]`
- Listen als Werte sind erlaubt: `"hobbys": ["Lesen", "Sport"]`
## Aufgabe 2: Dictionary-Erstellung mit verschiedenen Methoden  

Erstellen Sie das gleiche Dictionary für eine Person auf drei verschiedene Arten:
1. Mit der `{}` Syntax
2. Mit dem `dict()` Konstruktor
3. Als leeres Dictionary, das schrittweise befüllt wird

**Beispiel-Person:**
- Name: "Maria Müller"
- Alter: 30
- Stadt: "München"
- Beruf: "Lehrerin"

**Lösungshinweise:**
- Methode 1: `person1 = {"name": "Maria", ...}`
- Methode 2: `person2 = dict(name="Maria", ...)`
- Methode 3: `person3 = {}` dann `person3["name"] = "Maria"`
## Aufgabe 3: Sicherer Zugriff üben

Gegeben ist folgendes Dictionary:
```python
auto = {
    "marke": "BMW",
    "modell": "X3", 
    "jahr": 2020,
    "farbe": "schwarz"
}
```

1. Geben Sie die Marke aus
2. Versuchen Sie, den "preis" auszugeben (existiert nicht!)
3. Verwenden Sie `get()` um den Preis sicher abzufragen mit Standardwert "Nicht angegeben"
4. Fügen Sie den Preis hinzu und fragen Sie ihn erneut ab

**Lösungshinweise:**
- Direkter Zugriff: `auto["marke"]`
- Sicherer Zugriff: `auto.get("preis", "Standardwert")`
- Hinzufügen: `auto["preis"] = 35000`
## Aufgabe 4: Verschachtelte Dictionaries

Erstellen Sie ein Dictionary für eine kleine Bibliothek mit folgender Struktur:
- Bibliotheksname
- Bücher (Dictionary mit Buch-ID als Schlüssel)
  - Jedes Buch hat: Titel, Autor, Jahr, Verfügbar (True/False)
- Öffnungszeiten (Dictionary mit Wochentagen)

Erstellen Sie mindestens 3 Bücher und geben Sie verschiedene Informationen aus.

**Lösungshinweise:**
- Verschachtelt: `{"bücher": {"B001": {"titel": "...", ...}}}`
- Zugriff: `bibliothek["bücher"]["B001"]["titel"]`
## Aufgabe 5: Produktkatalog erweitern

Erstellen Sie einen Produktkatalog für einen Online-Shop:

1. Erstellen Sie 5 Produkte mit jeweils:
   - Produkt-ID (als Schlüssel)
   - Name, Preis, Kategorie, Auf Lager (Boolean)

2. Berechnen Sie:
   - Gesamtanzahl der Produkte
   - Durchschnittspreis
   - Anzahl verfügbarer Produkte

3. Geben Sie alle Produkte einer bestimmten Kategorie aus

**Lösungshinweise:**
- Struktur: `{"P001": {"name": "...", "preis": 99.99, ...}}`
- Länge: `len(dictionary)`

- Filtern: `for` Schleife mit `if` Bedingung
## Aufgabe 6: Dictionary Comprehension

Erstellen Sie folgende Dictionaries mit Dictionary Comprehensions:

1. Zahlen 1-10 und ihre Quadrate: `{1: 1, 2: 4, 3: 9, ...}`
2. Monate und ihre Längen in Zeichen: `{"Januar": 6, "Februar": 7, ...}`
3. Nur gerade Zahlen von 1-20 und ihre Kubikzahlen

**Lösungshinweise:**
- Grundform: `{x: x**2 for x in range(1, 11)}`
- Mit Liste: `{monat: len(monat) for monat in monate_liste}`
- Mit Bedingung: `{x: x**3 for x in range(1, 21) if x % 2 == 0}`
## Aufgabe 7: Datenkonvertierung

Sie haben folgende Daten als Listen:
```python
namen = ["Anna", "Bob", "Clara", "David"]
alter = [25, 30, 22, 28]
staedte = ["Berlin", "München", "Hamburg", "Köln"]
```

1. Erstellen Sie ein Dictionary, das Namen auf Alter abbildet
2. Erstellen Sie ein Dictionary mit vollständigen Personendaten
3. Finden Sie die älteste Person

**Lösungshinweise:**
- `zip()` verbindet Listen: `dict(zip(namen, alter))`
- Verschachtelt: `{name: {"alter": ..., "stadt": ...} for ...}`
- Maximum: `max()` mit entsprechendem Parameter
