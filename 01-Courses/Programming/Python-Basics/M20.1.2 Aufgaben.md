## 💡 Lösungshinweise

### Git-Branch-Befehle:
- `git branch` zeigt alle lokalen Branches
- `git checkout -b name` erstellt neuen Branch und wechselt dorthin
- `git merge branch` integriert Branch in aktuellen Branch
- `git branch -d name` löscht Branch nach erfolgreichem Merge

### Merge-Konflikt-Lösung:
- Konflikt-Marker (`<<<<<<<`, `=======`, `>>>>>>>`) manuell entfernen
- Gewünschte Version behalten oder beide kombinieren
- `git add` für gelöste Datei, dann `git commit`

### Branch-Namenskonventionen:
- `feature/beschreibung` für neue Funktionen
- `bugfix/problem` für Fehlerbehebungen
- `hotfix/critical` für kritische Sofort-Fixes
