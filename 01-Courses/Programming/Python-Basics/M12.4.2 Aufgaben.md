## Aufgabe 1: Grundlegende Set-Operationen

Gegeben sind zwei Sets:
```python
mathe_schueler = {"Anna", "Bob", "Clara", "David", "Eva"}
physik_schueler = {"Bob", "Clara", "Frank", "Greta", "Hans"}
```

Führen Sie folgende Operationen durch:
1. Vereinigung: Alle Schüler, die Mathe ODER Physik haben
2. Schnittmenge: Schüler, die BEIDE Fächer haben
3. Differenz: Schüler, die nur Mathe haben
4. Symmetrische Differenz: Schüler, die nur EINES der Fächer haben

**Lösungshinweise:**
- Vereinigung: `set1 | set2` oder `set1.union(set2)`
- Schnittmenge: `set1 & set2` oder `set1.intersection(set2)`
- Differenz: `set1 - set2` oder `set1.difference(set2)`
- Sym. Differenz: `set1 ^ set2` oder `set1.symmetric_difference(set2)`
## Aufgabe 2: Mitarbeiter-Skills analysieren

Ein Unternehmen hat verschiedene Abteilungen mit unterschiedlichen Skills:
```python
frontend = {"HTML", "CSS", "JavaScript", "React", "Vue"}
backend = {"Python", "Java", "SQL", "Docker", "API"}
mobile = {"Swift", "Kotlin", "Flutter", "React"}
```

1. Welche Skills sind für alle Entwickler relevant?
2. Welche Skills hat nur die Frontend-Abteilung?
3. Welche Skills teilen sich Frontend und Mobile?
4. Erstellen Sie eine Liste aller Skills im Unternehmen
5. Welche Abteilungen haben überlappende Skills?

**Lösungshinweise:**
- Alle Skills: `set1 | set2 | set3`
- Nur Frontend: `frontend - backend - mobile`
- Gemeinsame Skills: `set1 & set2`
- Überlappung prüfen: `not set1.isdisjoint(set2)`
## Aufgabe 3: Benutzerrechte-System

Implementieren Sie ein Berechtigungssystem:
```python
admin_rechte = {"lesen", "schreiben", "löschen", "admin", "backup"}
editor_rechte = {"lesen", "schreiben", "bearbeiten", "upload"}
viewer_rechte = {"lesen", "download"}

benutzer = {
    "alice": admin_rechte,
    "bob": editor_rechte,
    "charlie": viewer_rechte,
    "diana": admin_rechte
}
```

Schreiben Sie Funktionen:
1. `gemeinsame_rechte(benutzer1, benutzer2)` → Rechte die beide haben
2. `einzigartige_rechte(benutzer)` → Rechte die nur dieser Benutzer hat
3. `kann_aktion(benutzer, aktion)` → Prüft ob Aktion erlaubt ist
4. `alle_aktionen()` → Alle möglichen Aktionen im System
5. `benutzer_mit_recht(recht)` → Welche Benutzer haben dieses Recht?

**Lösungshinweise:**
- Rechte vergleichen: `benutzer_rechte[user1] & benutzer_rechte[user2]`
- Einzigartig: Differenz zu allen anderen Benutzern
- Listen-Comprehension für Benutzer-Suche
