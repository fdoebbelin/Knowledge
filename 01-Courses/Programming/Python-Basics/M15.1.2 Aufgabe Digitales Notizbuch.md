## 💡 Lösungshinweise

### Datei schreiben:
```python
# Grundsyntax zum Schreiben
with open("dateiname.txt", "w", encoding="utf-8") as datei:
    datei.write("Text hier")

# Mehrere Zeilen schreiben
with open("dateiname.txt", "w", encoding="utf-8") as datei:
    for zeile in liste:
        datei.write(zeile + "\n")  # \n für neue Zeile
```
### Datei lesen:
```python
# Kompletten Inhalt lesen
with open("dateiname.txt", "r", encoding="utf-8") as datei:
    inhalt = datei.read()

# Zeile für Zeile lesen
zeilen = []
with open("dateiname.txt", "r", encoding="utf-8") as datei:
    for zeile in datei:
        zeilen.append(zeile.strip())  # strip() entfernt \n
```
### Anhängen:
```python
# Text an bestehende Datei anhängen
with open("dateiname.txt", "a", encoding="utf-8") as datei:
    datei.write("Neuer Text\n")
```
### Fehlerbehandlung:
```python
try:
    # Datei-Operation hier
    with open("datei.txt", "r", encoding="utf-8") as datei:
        inhalt = datei.read()
except FileNotFoundError:
    # Wenn Datei nicht existiert
    print("Datei nicht gefunden!")
except Exception as fehler:
    # Alle anderen Fehler
    print(f"Fehler: {fehler}")
```
