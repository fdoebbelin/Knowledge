## 💡 Lösungshinweise

### Kohäsion verbessern:
- Eine Funktion = eine Aufgabe (Single Responsibility)
- Berechnung, Formatierung und Ausgabe trennen
- Zusammengehörige Operationen gruppieren

### Kopplung reduzieren:
- Parameter statt globale Variablen verwenden
- Abhängigkeiten explizit als Parameter übergeben
- Konfiguration von außen injizieren

### Testbarkeit erreichen:
- Pure Functions: Input → Output, keine Seiteneffekte
- Seiteneffekte (print, Dateizugriff) isolieren
- Deterministische Funktionen (gleiche Eingabe → gleiche Ausgabe)

### Defensive Programmierung:
- Eingaben validieren vor Verarbeitung
- Hilfreiche Fehlermeldungen bei ungültigen Werten
- Robuste Funktionen die edge cases behandeln
