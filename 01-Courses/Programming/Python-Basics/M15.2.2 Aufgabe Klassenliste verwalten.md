## 💡 Lösungshinweise

### CSV schreiben:
```python
import csv

# Grundsyntax
with open("datei.csv", "w", newline="", encoding="utf-8") as datei:
    writer = csv.writer(datei)
    writer.writerow(["Spalte1", "Spalte2"])  # Eine Zeile
    
# Mehrere Zeilen
daten = [["Zeile1"], ["Zeile2"]]
for zeile in daten:
    writer.writerow(zeile)
```
### CSV lesen:
```python
# Grundsyntax
with open("datei.csv", "r", encoding="utf-8") as datei:
    reader = csv.reader(datei)
    for zeile in reader:
        print(zeile)  # zeile ist eine Liste

# Header separat
header = next(reader)  # Erste Zeile
```
### DictWriter:
```python
# Mit benannten Spalten
fieldnames = ["Name", "Alter"]
with open("datei.csv", "w", newline="", encoding="utf-8") as datei:
    writer = csv.DictWriter(datei, fieldnames=fieldnames)
    writer.writeheader()  # Header automatisch
    writer.writerow({"Name": "Anna", "Alter": "25"})
```
### DictReader:
```python
# Als Dictionary lesen
with open("datei.csv", "r", encoding="utf-8") as datei:
    reader = csv.DictReader(datei)
    for zeile in reader:
        print(zeile["Name"])  # Zugriff über Spaltenname
```
