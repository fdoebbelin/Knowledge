## Lernziele
- Listen erstellen und verstehen
- Elemente hinzufügen und ändern  
- Grundlegendes Slicing anwenden
## 1. Was sind Listen?

Listen sind Container, die mehrere Werte speichern können.

```python
# Eine leere Liste erstellen
meine_liste = []
print(f"Leere Liste: {meine_liste}")
```

```python
# Liste mit Zahlen
zahlen = [1, 2, 3, 4, 5]
print(f"Zahlen: {zahlen}")

# Liste mit verschiedenen Datentypen
gemischt = [1, "Hallo", 3.14, True]
print(f"Gemischt: {gemischt}")
```
## 2. Auf Listenelemente zugreifen

```python
# Grundlagen der Indizierung
fruechte = ["Apfel", "Banane", "Orange"]
print(f"Liste: {fruechte}")

# Erstes Element hat Index 0
print(f"Erstes Element [0]: {fruechte[0]}")
print(f"Zweites Element [1]: {fruechte[1]}")
print(f"Letztes Element [-1]: {fruechte[-1]}")
```

```python
# Einfaches Slicing - Teilbereiche
zahlen = [1, 2, 3, 4, 5]
print(f"Original: {zahlen}")

print(f"Erste drei [0:3]: {zahlen[0:3]}")
print(f"Ab Index 2 [2:]: {zahlen[2:]}")
print(f"Bis Index 3 [:3]: {zahlen[:3]}")
```
## 3. Elemente hinzufügen

```python
# append() - Ein Element am Ende hinzufügen
einkaufsliste = ["Brot", "Milch"]
print(f"Vorher: {einkaufsliste}")

einkaufsliste.append("Käse")
print(f"Nach append: {einkaufsliste}")
```

```python
# insert() - Element an bestimmter Stelle einfügen
zahlen = [1, 3, 4]
print(f"Vorher: {zahlen}")

zahlen.insert(1, 2)  # An Position 1 die Zahl 2 einfügen
print(f"Nach insert: {zahlen}")
```
## 4. Elemente ändern und entfernen

```python
# Elemente ändern
farben = ["rot", "grün", "blau"]
print(f"Vorher: {farben}")

farben[1] = "gelb"  # Index 1 ändern
print(f"Nach Änderung: {farben}")
```

```python
# Elemente entfernen
tiere = ["Hund", "Katze", "Maus", "Katze"]
print(f"Vorher: {tiere}")

# remove() entfernt das erste Vorkommen
tiere.remove("Katze")
print(f"Nach remove: {tiere}")

# pop() entfernt das letzte Element
letztes = tiere.pop()
print(f"Entfernt: {letztes}")
print(f"Nach pop: {tiere}")
```
## 5. Listen prüfen

```python
# Prüfen ob Elemente in der Liste sind
hobbys = ["Lesen", "Schwimmen", "Kochen"]
print(f"Hobbys: {hobbys}")

print(f"'Lesen' in der Liste? {'Lesen' in hobbys}")
print(f"'Tanzen' in der Liste? {'Tanzen' in hobbys}")

# Anzahl der Elemente
print(f"Anzahl Hobbys: {len(hobbys)}")
```
## 6. Praktisches Beispiel: Notenliste

```python
# Eine Notenliste verwalten
noten = []  # Leere Liste

# Noten hinzufügen
noten.append(1.5)
noten.append(2.0)
noten.append(1.8)

print(f"Alle Noten: {noten}")
print(f"Erste Note: {noten[0]}")
print(f"Anzahl Noten: {len(noten)}")

# Durchschnitt berechnen
durchschnitt = sum(noten) / len(noten)
print(f"Durchschnitt: {durchschnitt:.2f}")
```
## 7. Häufige Fehler vermeiden

```python
# FEHLER: Index außerhalb der Liste
zahlen = [1, 2, 3]
print(f"Liste: {zahlen}")

# Das funktioniert:
print(f"Index 0: {zahlen[0]}")
print(f"Index 2: {zahlen[2]}")

# Das würde einen Fehler geben:
# print(zahlen[3])  # IndexError!

# Sicher prüfen:
if len(zahlen) > 3:
    print(zahlen[3])
else:
    print("Index 3 existiert nicht")
```

```python
# Listen kopieren vs. zuweisen
original = [1, 2, 3]
falsche_kopie = original  # Nur Verweis!
richtige_kopie = original[:]  # Echte Kopie

original.append(4)
print(f"Original: {original}")
print(f"Falsche Kopie: {falsche_kopie}")  # Auch verändert!
print(f"Richtige Kopie: {richtige_kopie}")  # Unverändert
```
## Zusammenfassung

**Listen erstellen:**
- Leer: `[]`
- Mit Werten: `[1, 2, 3]`

**Zugriff:**
- Element: `liste[0]`
- Teilbereich: `liste[1:3]`

**Ändern:**
- Hinzufügen: `liste.append(wert)`
- Einfügen: `liste.insert(position, wert)`
- Ändern: `liste[0] = neuer_wert`
- Entfernen: `liste.remove(wert)` oder `liste.pop()`

**Prüfen:**
- Element vorhanden: `wert in liste`
- Anzahl: `len(liste)`
