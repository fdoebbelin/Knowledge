## Geschichte und Philosophie von Python

- Python wurde in den späten 1980er Jahren von Guido van Rossum am CWI in den Niederlanden entwickelt. 1
- Python war als Nachfolger der Programmiersprache ABC gedacht. 1
- Die Implementierung begann im Dezember 1989, die erste Version (0.9.0) wurde im Februar 1991 veröffentlicht. 1
- Van Rossums Ziel war eine einfache, intuitive und leistungsfähige Open-Source-Sprache. 16
- Der Name "Python" ist eine Hommage an Monty Python. 3
- Guido van Rossum war bis 2018 der "Benevolent Dictator For Life" (BDFL) von Python. 16
- Die Designphilosophien sind im "Zen von Python" (PEP 20) zusammengefasst.
- Diese Prinzipien betonen Lesbarkeit, Einfachheit und Explizitheit.
- Der "Pythonische" Weg betont einen offensichtlichen Weg, um etwas zu tun. 1
- Python bietet in der Praxis aber oft mehrere Lösungswege. 1
- Code, der dem Zen von Python entspricht, kann effizienter sein. 23
- Das Zen von Python kann im Interpreter mit `import this` angezeigt werden.

## Unterschiede zwischen Python 2 und Python 3
- Python 2.0 wurde 2000, Python 3.0 im Jahr 2008 veröffentlicht.
- Die Unterstützung für Python 2 endete 2020.
- Wesentliche Unterschiede:
	- `print` Anweisung vs. Funktion (`print()`).
	- Ganzzahldivision (Python 2: `5 / 2` = 2, Python 3: `5 / 2` = 2.5).
	- Unicode-Unterstützung (Python 3 standardmäßig).
	- `range()` vs. `xrange()` (Python 3 verwendet `range()` wie `xrange()` in Python 2). 28
- Die meisten modernen Bibliotheken und Frameworks sind nur für Python 3.
- Unternehmen migrieren von Python 2 zu Python 3 (z.B. Instagram).
- Für neue Lernende ist Python 3 die empfohlene Wahl.
- Tools wie `2to3` können bei der Portierung helfen. 27
