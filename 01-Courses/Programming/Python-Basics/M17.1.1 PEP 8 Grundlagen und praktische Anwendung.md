## 1. Was ist PEP 8?

### PEP 8 Grundlagen
PEP 8 ist die offizielle Python-Stilrichtlinie:

- **Vollform:** Python Enhancement Proposal 8
- **Zweck:** Einheitlicher Code-Stil für bessere Lesbarkeit
- **Grundprinzip:** "Code wird öfter gelesen als geschrieben"
- **Ziel:** Konsistenter, lesbarer Python-Code in allen Projekten

### Warum ist PEP 8 wichtig?

**Lesbarkeit verbessern:**
- Code ist leichter zu verstehen
- Schnelleres Einarbeiten in fremden Code
- Weniger Missverständnisse

**Teamarbeit fördern:**
- Alle Entwickler verwenden denselben Stil
- Einheitliche Code-Basis im Projekt
- Bessere Zusammenarbeit

**Professionalität:**
- Code sieht professionell aus
- Entspricht Python-Standard
- Leichtere Wartung und Debugging

```python
def demonstriere_lesbarkeit_unterschied():
    """Zeigt warum Lesbarkeit wichtig ist"""
    
    # Schlecht formatiert - schwer lesbar
    schlecht = "def calc(a,b,c):return a+b*c if a>0 else b-c"
    
    # Gut formatiert nach PEP 8 - leicht lesbar

        """Berechnet Ergebnis basierend auf Eingabewerten"""

Test-Ergebnis: {test_ergebnis}"""
    
    return vergleich
```

## 2. Namenskonventionen - Die Grundregeln

### Variablen und Funktionen (snake_case)

**Regel:** Kleinbuchstaben mit Unterstrichen zwischen Wörtern

**Richtig:**
- `student_name`
- `anzahl_studenten` 
- `ist_bestanden`
- `berechne_durchschnitt()`

**Falsch:**
- `studentName` (camelCase)
- `AnzahlStudenten` (PascalCase)
- `istbestanden` (ohne Unterstrich)

```python
def demonstriere_variable_konventionen():
```

### Konstanten (UPPER_CASE)

**Regel:** Großbuchstaben mit Unterstrichen zwischen Wörtern

**Richtig:**
- `MAX_STUDENTEN = 30`
- `PI = 3.14159`
- `STANDARD_ZEITLIMIT = 120`

**Falsch:**
- `maxStudenten = 30`
- `Max_Studenten = 30`

```python
def demonstriere_konstanten_konventionen():
    """Demonstriert korrekte Konstanten-Benennung"""
    
    # ✅ Richtig: UPPER_CASE für Konstanten
    MAX_STUDENTEN = 30
    MIN_NOTE = 1.0
    MAX_NOTE = 6.0
    PI = 3.14159
    STANDARD_ZEITLIMIT = 120  # Sekunden
    ECTS_PRO_SEMESTER = 30
    
    def berechne_kreisflaeche(radius):
        """Berechnet Kreisfläche mit Konstante PI"""
        return PI * radius * radius
    
    def pruefe_klassengröße(anzahl):
        """Prüft ob Klassengröße im erlaubten Bereich"""
        return anzahl <= MAX_STUDENTEN
    
    def bewerte_note(note):
        """Bewertet eine Note im gültigen Bereich"""
        if MIN_NOTE <= note <= MAX_NOTE:
            return f"Gültige Note: {note}"
        else:
            return f"Ungültige Note: {note}"
    
    # Konstanten verwenden
    kreisflaeche = berechne_kreisflaeche(5)
    klasse_ok = pruefe_klassengröße(25)
    note_bewertung = bewerte_note(2.1)
    
    konstanten_beispiel = {
        "Max Studenten": MAX_STUDENTEN,
        "ECTS pro Semester": ECTS_PRO_SEMESTER,
        "Kreisfläche (r=5)": round(kreisflaeche, 2),
        "Klasse OK (25)": klasse_ok,
        "Note Bewertung": note_bewertung
    }
    
    return f"UPPER_CASE Konstanten: {konstanten_beispiel}"

print(demonstriere_konstanten_konventionen())
```

### Klassen (PascalCase)

**Regel:** Jedes Wort beginnt mit Großbuchstaben, keine Unterstriche

**Richtig:**
- `Student`
- `NotenManager`
- `BankKonto`

**Falsch:**
- `student`
- `noten_manager`
- `bankKonto`

```python
def demonstriere_klassen_konventionen():
    """Demonstriert korrekte Klassen-Benennung"""
    
    # ✅ Richtig: PascalCase für Klassen
    class Student:
        """Repräsentiert einen Studenten"""
        def __init__(self, name, alter):
            self.name = name
            self.alter = alter
        
        def info(self):
            return f"{self.name} ({self.alter} Jahre)"
    
    class NotenManager:
        """Verwaltet Noten für Studenten"""
        def __init__(self):
            self.noten = {}
        
        def speichere_note(self, student_name, note):
            """Speichert eine Note für einen Studenten"""
            self.noten[student_name] = note
            return f"Note {note} für {student_name} gespeichert"
    
    class BankKonto:
        """Verwaltet ein Bankkonto"""
        def __init__(self, kontostand=0):
            self.kontostand = kontostand
        
        def info(self):
            return f"Kontostand: {self.kontostand}€"
    
    # Klassen verwenden
    student = Student("Lisa Weber", 22)
    noten_manager = NotenManager()
    note_meldung = noten_manager.speichere_note("Lisa Weber", 1.8)
    konto = BankKonto(1000)
    
    klassen_beispiel = {
        "Student Info": student.info(),
        "Note gespeichert": note_meldung,
        "Konto Info": konto.info()
    }
    
    return f"PascalCase Klassen: {klassen_beispiel}"

print(demonstriere_klassen_konventionen())
```

## 3. Code-Formatierung

### Einrückung mit 4 Leerzeichen

**Regel:** Genau 4 Leerzeichen pro Einrückungsebene, niemals Tabs

**Richtig:**
```python
if bedingung:
    # 4 Leerzeichen
    if weitere_bedingung:
        # 8 Leerzeichen (4 + 4)
        aktion()
```

**Falsch:**
```python
if bedingung:
  # 2 Leerzeichen - FALSCH
	# Tab-Zeichen - FALSCH
```

```python
def demonstriere_einrueckung():
    """Demonstriert korrekte Einrückung mit 4 Leerzeichen"""
    
    noten = [1.5, 2.0, 2.7, 1.3, 2.5, 3.1]
    
    def analysiere_noten_detailliert(noten_liste):
        """Analysiert Noten mit korrekter Einrückung"""
        if not noten_liste:
            return "Keine Noten vorhanden"
        
        # Erste Einrückungsebene: 4 Leerzeichen
        beste_note = min(noten_liste)
        schlechteste_note = max(noten_liste)
        durchschnitt = sum(noten_liste) / len(noten_liste)
        
        # Verschachtelte Bedingungen: 8 Leerzeichen
        if durchschnitt <= 2.0:
            bewertung = "sehr gut"
            if beste_note == 1.0:
                bonus = "Perfekte Bestnote!"
            else:
                bonus = "Sehr gute Leistung"
        elif durchschnitt <= 3.0:
            bewertung = "gut"
            bonus = "Solide Leistung"
        else:
            bewertung = "befriedigend"
            bonus = "Noch Verbesserungspotential"
        
        return {
            "beste_note": beste_note,
            "schlechteste_note": schlechteste_note,
            "durchschnitt": round(durchschnitt, 2),
            "bewertung": bewertung,
            "bonus": bonus
        }
    
    analyse_ergebnis = analysiere_noten_detailliert(noten)
    return f"Einrückung-Beispiel: {analyse_ergebnis}"

print(demonstriere_einrueckung())
```

### Leerzeichen um Operatoren

**Regel:** Leerzeichen um Operatoren, aber nicht bei Funktionsaufrufen

**Richtig:**
- `x = y + z`
- `liste = [1, 2, 3]`
- `funktion(parameter)`
- `dict["key"]`

**Falsch:**
- `x=y+z`
- `liste=[1,2,3]`
- `funktion (parameter)`
- `dict ["key"]`

```python
def demonstriere_leerzeichen_regeln():
    """Demonstriert korrekte Leerzeichen-Verwendung"""
    
    # ✅ Richtig: Leerzeichen um mathematische Operatoren
    summe = 10 + 20 + 30
    differenz = 100 - 25
    produkt = 5 * 8
    quotient = 144 / 12
    potenz = 2 ** 3
    
    # ✅ Richtig: Leerzeichen nach Kommas in Listen und Dictionaries
    zahlen_liste = [1, 2, 3, 4, 5]
    student_info = {"name": "Anna", "alter": 23, "note": 1.8, "semester": 4}
    
    # ✅ Richtig: Leerzeichen um Vergleichsoperatoren
    ist_bestanden = summe >= 50
    ist_jung = student_info["alter"] < 25
    ist_gute_note = student_info["note"] <= 2.0
    
    # ✅ Richtig: KEIN Leerzeichen bei Funktionsaufrufen und Indexzugriff
    maximum = max(zahlen_liste)
    name_gross = student_info["name"].upper()
    erstes_element = zahlen_liste[0]
    
    # ✅ Richtig: Leerzeichen um Zuweisungsoperatoren
    gesamtpunkte = summe
    gesamtpunkte += produkt
    
    formatierung_beispiele = {
        "Mathematik": f"Summe: {summe}, Produkt: {produkt}, Potenz: {potenz}",
        "Listen": zahlen_liste,
        "Dictionary": student_info["name"],
        "Vergleiche": f"Bestanden: {ist_bestanden}, Jung: {ist_jung}",
        "Funktionen": f"Maximum: {maximum}, Großbuchstaben: {name_gross}",
        "Index": f"Erstes Element: {erstes_element}"
    }
    
    return f"Leerzeichen-Regeln: {formatierung_beispiele}"

print(demonstriere_leerzeichen_regeln())
```

## 4. Häufige Stil-Fehler vermeiden

### Vor/Nach-Vergleich

```python
def demonstriere_stil_verbesserung():
    """Zeigt typische Stil-Probleme und deren Lösung"""
    
    # ❌ Schlechter Stil - viele PEP 8 Verstöße
    def schlechtes_beispiel():
        studentNames=['anna','max','lisa']
        totalPoints=0
        for n in studentNames:
            if len(n)>3:
                totalPoints=totalPoints+len(n)*2
        return totalPoints if totalPoints>10 else 0
    
    # ✅ Guter Stil nach PEP 8
    def gutes_beispiel():
        student_names = ['Anna', 'Max', 'Lisa']
        total_points = 0
        
        for name in student_names:
            if len(name) > 3:
                points = len(name) * 2
                total_points = total_points + points
        
        if total_points > 10:
            return total_points
        else:
            return 0
    
    # ✅ Noch besser: Pythonischer Stil
    def pythonisches_beispiel():
        student_names = ['Anna', 'Max', 'Lisa']
        
        # List Comprehension für bessere Lesbarkeit
        name_points = [len(name) * 2 for name in student_names if len(name) > 3]
        total_points = sum(name_points)
        
        return total_points if total_points > 10 else 0
    
    # Alle Varianten testen
    ergebnis_schlecht = schlechtes_beispiel()
    ergebnis_gut = gutes_beispiel()
    ergebnis_pythonisch = pythonisches_beispiel()
    
    stil_vergleich = {
        "Schlechter Stil": ergebnis_schlecht,
        "Guter Stil": ergebnis_gut,
        "Pythonischer Stil": ergebnis_pythonisch,
        "Alle Ergebnisse gleich": (
            ergebnis_schlecht == ergebnis_gut == ergebnis_pythonisch
        )
    }
    
    return f"Stil-Verbesserung: {stil_vergleich}"

print(demonstriere_stil_verbesserung())
```

### Typische Anfänger-Fehler identifizieren

**Häufige PEP 8 Verstöße:**

**Namensgebung:**
- ❌ `studentName`, `MaxValue`, `isOK`
- ✅ `student_name`, `MAX_VALUE`, `is_ok`

**Leerzeichen:**
- ❌ `x=y+z`, `list[0 ]`, `func (param)`
- ✅ `x = y + z`, `list[0]`, `func(param)`

**Einrückung:**
- ❌ 2 Leerzeichen oder Tab-Zeichen mischen
- ✅ Genau 4 Leerzeichen pro Ebene

**Zeilenlänge:**
- ❌ Zeilen über 79 Zeichen
- ✅ Aufteilen auf mehrere Zeilen

```python
def identifiziere_stil_probleme():
```

## 5. PEP 8 Checkliste für den Alltag

### Schnelle Überprüfung

**Namenskonventionen:**
- ✓ Variablen und Funktionen: snake_case
- ✓ Konstanten: UPPER_CASE
- ✓ Klassen: PascalCase

**Formatierung:**
- ✓ 4 Leerzeichen für Einrückung
- ✓ Leerzeichen um Operatoren: `a = b + c`
- ✓ Keine Leerzeichen: `func(param)`, `list[0]`
- ✓ Leerzeichen nach Kommas: `[1, 2, 3]`

**Code-Organisation:**
- ✓ Maximal 79 Zeichen pro Zeile
- ✓ Zwei Leerzeilen zwischen Funktionen
- ✓ Eine Leerzeile zwischen Methoden

**Lesbarkeit:**
- ✓ Aussagekräftige Namen wählen
- ✓ Nicht zu viele Kommentare
- ✓ Konsistenter Stil im ganzen Projekt


## Zusammenfassung

### Die wichtigsten PEP 8 Regeln:
1. **Namenskonventionen:** snake_case für Variablen/Funktionen, UPPER_CASE für Konstanten, PascalCase für Klassen
2. **Einrückung:** Genau 4 Leerzeichen pro Ebene, niemals Tabs
3. **Leerzeichen:** Um Operatoren ja, bei Funktionen/Listen nein
4. **Zeilenlänge:** Maximal 79 Zeichen, bei Bedarf aufteilen
5. **Konsistenz:** Einheitlicher Stil im gesamten Projekt

### Warum PEP 8 wichtig ist:
- **Code wird öfter gelesen als geschrieben**
- **Teamarbeit funktioniert besser**
- **Professioneller Code-Standard**
- **Leichtere Wartung und Debugging**

### Praktische Umsetzung:
- PEP 8 Checkliste bei jedem Code anwenden
- Code-Reviews mit PEP 8 Fokus durchführen
- Automatische Tools wie pylint oder black nutzen
- Eigenen Code systematisch nach PEP 8 überarbeiten
