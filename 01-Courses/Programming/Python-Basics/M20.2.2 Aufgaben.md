## 💡 Lösungshinweise

### GitHub-Setup:
- **Personal Access Token** statt Passwort für HTTPS-Authentication verwenden
- **Repository-Namen** sollten beschreibend und URL-freundlich sein (kebab-case)
- **Public vs. Private:** Public für Portfolio, Private für sensible Daten
- **.gitignore** immer für Python-Projekte konfigurieren

### Git-Remote-Befehle:
- `git remote add origin <url>` - Remote-Repository hinzufügen
- `git push -u origin main` - Erster Push mit Upstream-Tracking
- `git pull origin main` - Änderungen vom Remote holen
- `git clone <url>` - Repository kopieren
- `git remote -v` - Remote-Konfiguration anzeigen

### Pull Request Best Practices:
- **Beschreibender Titel** mit Präfix (feat:, fix:, docs:)
- **Ausführliche Beschreibung** was und warum geändert wurde
- **Screenshots** bei UI-Änderungen hinzufügen
- **Kleine, fokussierte PRs** statt große Änderungen

### Troubleshooting:
- **Authentication-Fehler:** Personal Access Token in GitHub-Settings erstellen
- **Push rejected:** Erst `git pull` für Remote-Updates ausführen
- **Merge-Konflikte:** Dateien manuell editieren und `git add` + `git commit`
- **Branch-Probleme:** `git status` und `git branch` für Orientierung
