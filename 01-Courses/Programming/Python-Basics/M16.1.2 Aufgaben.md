## 💡 Lösungshinweise

### Modul erstellen:
```python
# Beispiel-Struktur für ein Modul
modul_inhalt = '''"""
Modul-Beschreibung hier
"""

def funktion1(parameter):
    """Beschreibung der Funktion"""
    # Implementierung
    return ergebnis

def funktion2(parameter1, parameter2):
    """Beschreibung der Funktion"""
    # Implementierung
    return ergebnis
'''

with open("modulname.py", "w", encoding="utf-8") as datei:
    datei.write(modul_inhalt)
```

### Module importieren:
```python
# Verschiedene Import-Strategien
import modulname                           # Vollständiger Import
from modulname import funktion            # Spezifische Funktion
import modulname as alias                  # Mit Alias
from modulname import funktion1, funktion2 # Mehrere Funktionen

# Verwendung
ergebnis1 = modulname.funktion(parameter)     # Bei vollständigem Import
ergebnis2 = funktion(parameter)               # Bei spezifischem Import
ergebnis3 = alias.funktion(parameter)         # Bei Alias
```

### Noten-zu-Text Konvertierung:
```python
def note_zu_text(note):
    """Wandelt Zahlennote in Textnote um"""
    if note <= 1.5:
        return "sehr gut"
    elif note <= 2.5:
        return "gut"
    elif note <= 3.5:
        return "befriedigend"
    elif note <= 4.0:
        return "ausreichend"
    else:
        return "ungenügend"
```

### Studenten-Dictionary:
```python
def erstelle_student(name, alter, studiengang):
    """Erstellt ein Dictionary für einen Studenten"""
    return {
        "name": name,
        "alter": alter,
        "studiengang": studiengang
    }
```

### Listen sortieren:
```python
def studenten_nach_alter_sortieren(studenten_liste):
    """Sortiert Studenten nach Alter"""
    return sorted(studenten_liste, key=lambda student: student["alter"])
```
