# Studentenverwaltung

Eine umfassende Python-Anwendung zur Verwaltung von Studenten mit folgenden Features:

## Features
- ✅ **Basis-Verwaltung**: Studenten hinzufügen und anzeigen
- ✅ **Noten-System**: Noten eingeben und Durchschnitt berechnen  
- ✅ **Such-Funktionen**: Suche nach Name, Matrikelnummer und Studiengang
- ✅ **CSV-Export/Import**: Daten exportieren und importieren mit Backup

## Verwendung
```bash
python studentenverwaltung.py
```
