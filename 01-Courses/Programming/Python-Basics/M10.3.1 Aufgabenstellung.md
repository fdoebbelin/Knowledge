## 💡 Higher-order Functions Kurzreferenz

```python
# Funktion als Parameter übergeben
def meine_funktion(text, verarbeitung_funktion):
    return verarbeitung_funktion(text)

# Aufruf mit Funktionsname (ohne Klammern!)
ergebnis = meine_funktion("test", str.upper)

# Variable Anzahl von Funktionen
def mehrere_funktionen(wert, *funktionen):
    for func in funktionen:
        wert = func(wert)
    return wert

# Aufruf mit mehreren Funktionen
ergebnis = mehrere_funktionen("  TEST  ", str.strip, str.lower)
```

## 🧩 Was macht eine Higher-order Function?

Eine **Higher-order Function** ist eine Funktion, die:
- Andere Funktionen als Parameter entgegennimmt, ODER
- Funktionen als Rückgabewert zurückgibt

**Beispiel aus unserer Übung:**
```python
formatiere_text(text, gross_schreibung)
#                     ↑
#            Funktion als Parameter!
```
