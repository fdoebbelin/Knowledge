## 💡 Lösungshinweise

### JSON erstellen und speichern:
```python
import json

# Dictionary als JSON speichern
with open("datei.json", "w", encoding="utf-8") as datei:
    json.dump(data, datei, indent=4, ensure_ascii=False)
```

### JSON lesen:
```python
import json

# JSON-Datei laden
with open("datei.json", "r", encoding="utf-8") as datei:
    data = json.load(datei)

# Auf Werte zugreifen
titel = data["titel"]
```

### Listen in JSON bearbeiten:
```python
# Bestehende Liste laden
with open("liste.json", "r", encoding="utf-8") as datei:
    liste = json.load(datei)

# Element hinzufügen
liste.append(neues_element)

# Liste wieder speichern
with open("liste.json", "w", encoding="utf-8") as datei:
    json.dump(liste, datei, indent=4, ensure_ascii=False)
```

### Verschachtelte Daten:
```python
# Zugriff auf verschachtelte Struktur
verlag_name = buch["verlag"]["name"]
verlag_stadt = buch["verlag"]["adresse"]["stadt"]
```

### Fehlerbehandlung:
```python
try:
    with open("datei.json", "r", encoding="utf-8") as datei:
        data = json.load(datei)
except FileNotFoundError:
    return "JSON-Datei nicht gefunden"
except json.JSONDecodeError:
    return "Ungültiges JSON-Format"
except Exception as fehler:
    return f"Fehler: {fehler}"
```
