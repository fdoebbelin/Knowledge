## 1. Extrude (Aufpolstern / Herausziehen)
➡ Zweck: Aus einer flachen 2D-Skizze einen 3D-Körper erzeugen.  
➡ Bildhaft: Wie Knete, die man nach oben drückt.
### 🔍 Was passiert?
- Du zeichnest eine Skizze (z. B. Kreis, Rechteck).
- Du drückst sie gerade in eine bestimmte Richtung.
- Es entsteht ein volumiger Körper (z. B. ein Zylinder aus einem Kreis).
### ✔ Typisch für:
- Grundkörper erstellen
- Wände, Blöcke, Platten
## 2. Pocket (Tasche / Aushöhlen)
➡ Zweck: Material aus einem bestehenden Körper entfernen.  
➡ Bildhaft: Ein Werkzeug fräst Material heraus.
### 🔍 Was passiert?
- Du wählst eine Fläche eines Körpers.
- Du zeichnest darauf eine Skizze (z. B. ein Rechteck).
- Mit „Pocket“ wird dieses Profil in den Körper hinein geschnitten.
### ✔ Typisch für:
- Löcher, Aussparungen, Nuten
- Vertiefungen, Gewindebohrungen (Grundform)
## 3. Loft (Verrunden / Verbinden von Profilen)
➡ Zweck: Zwei oder mehr unterschiedliche Profile miteinander verbinden.  
➡ Bildhaft: Eine Haut, die sich zwischen verschiedenen Formen spannt.
### 🔍 Was passiert?
- Du erstellst mindestens zwei Skizzen auf verschiedenen Ebenen.  
    Beispiel:
    - unten: Kreis
    - oben: Quadrat
- Loft verbindet beide Formen zu einem organisch verlaufenden Körper.
### ✔ Typisch für:
- Trichter, Übergänge, Düsen
- „Bleche“ oder organische Formen
- Objekte, die nicht geradlinig wachsen
## 🚀 Kurzvergleich

| Werkzeug | Funktion                         | Voraussetzung   | Ergebnis                        |
| -------- | -------------------------------- | --------------- | ------------------------------- |
| Extrude  | Skizze gerade herausziehen       | 1 Profil        | Körper wächst gerade            |
| Pocket   | Material wegnehmen               | Körper + Skizze | Loch / Aussparung               |
| Loft     | Zwei oder mehr Profile verbinden | min. 2 Profile  | Freiform-Körper zwischen Formen |
|          |                                  |                 |                                 |
## 🎓 Merksatz

> Extrude baut drauf, Pocket baut ab, Loft verbindet.
