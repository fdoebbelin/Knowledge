## der MetaRow UG, Hr. Döbbelin:

- Er möchte gerne OpenSuSE Linux verwenden. (kann aber noch diskutiert werden)
- Es sollte eine OpenSource Projektsoftware auf einem lokalen Server installiert werden (Kann auch noch diskutiert werden) 
    - Sein Favorit ist ProjeQtor [https://www.projeqtor.org/en/](https://www.projeqtor.org/en/ "https://www.projeqtor.org/en/")
- Es soll jeder in der Klasse einen Zugangs-Account zum Server bekommen mit Zugriff auf die Projekt-Software
- Es sollen Gruppen gebildet werden mit klar definierten  Aufgabe :
	- Systemintegratoren
	- Anwendungsentwicklung
	- mit jeweils einem Projektleiter
- Die Projekte sollen zu Übungszwecken für den Lehrinhalt Projektmanagement dienen
	- deren Fortschritt dokumentiert werden sollte
- Zukunftsvision von Hr. Döbbelin:
	- Das Projekt soll auf einer von Ihm betreuten OpenSource Website veröffentlicht werden und einer Community die Plattform zur Weiterführung zu bieten.
- der MetaRow Player soll die Möglichkeit bieten interaktive Markdown-Dokumente als Lernumgebung anzubieten. Vorbild ist Jupyterlab als python zentrierte Serverumgebung
- der MetaRow- Player soll aber eine reine Desktop-Anwendung werden
