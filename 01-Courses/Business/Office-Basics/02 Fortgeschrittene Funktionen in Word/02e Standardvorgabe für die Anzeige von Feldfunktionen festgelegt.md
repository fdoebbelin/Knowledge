In Microsoft Word können Sie die Standardanzeige für Feldfunktionen, also ob Feldcodes oder Feldergebnisse angezeigt werden, in den Optionen des Programms einstellen. Diese Einstellung bestimmt, wie Felder standardmäßig angezeigt werden, wenn Sie ein Dokument öffnen. Hier ist eine Schritt-für-Schritt-Anleitung, wie Sie diese Standardvorgabe festlegen können:

### Festlegen der Standardanzeige für Feldfunktionen in Word

1. **Öffnen Sie die Word-Optionen**:
   - Klicken Sie auf den Tab „Datei“ in der oberen linken Ecke des Word-Fensters.
   - Wählen Sie „Optionen“ am unteren Rand des Menüs. Dies öffnet das Fenster „Word-Optionen“.

2. **Navigieren Sie zu den erweiterten Optionen**:
   - Im Dialogfenster „Word-Optionen“ finden Sie auf der linken Seite eine Liste von Kategorien. Klicken Sie auf „Erweitert“.

3. **Anpassen der Feldfunktionen**:
   - Scrollen Sie im Bereich „Erweitert“ nach unten, bis Sie den Abschnitt „Anzeigen“ erreichen.
   - Suchen Sie die Option „Feldfunktionen anstelle von Werten anzeigen“. Dieses Kontrollkästchen steuert, ob standardmäßig die Feldcodes oder die Ergebnisse der Felder angezeigt werden.
   - Setzen Sie ein Häkchen, wenn Sie standardmäßig die Feldcodes anzeigen möchten, oder entfernen Sie das Häkchen, wenn Sie die Feldergebnisse sehen möchten.

4. **Änderungen speichern**:
   - Klicken Sie auf „OK“, um die Änderungen zu speichern und das Dialogfenster zu schließen.

### Zusätzliche Hinweise
- **Anwendung der Einstellungen**: Diese Einstellung wirkt sich auf alle Dokumente aus, die Sie in Word öffnen. Jedoch können individuelle Dokumenteinstellungen oder Vorlageneinstellungen diese globale Einstellung überschreiben.
- **Umschalten während der Arbeit**: Unabhängig von Ihrer Standardeinstellung können Sie immer noch die Ansicht von Feldcodes und Feldergebnissen in einem geöffneten Dokument mit der Tastenkombination `Alt + F9` umschalten.
- **Aktualisieren von Feldern**: Vergessen Sie nicht, dass Sie Felder mit `F9` aktualisieren können, unabhängig davon, ob Sie Feldcodes oder Feldergebnisse anzeigen.

Indem Sie diese Einstellung an Ihre Arbeitsweise anpassen, können Sie die Bearbeitung von Dokumenten mit vielen Feldfunktionen effizienter gestalten.
