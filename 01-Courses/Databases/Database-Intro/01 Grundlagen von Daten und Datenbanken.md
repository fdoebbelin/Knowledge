## 1. Daten und Informationen

Definitionen:
- **Daten:** Rohinformationen ohne Kontext, z. B. Zahlen, Texte oder Fakten.
    - Beispiel:  _"Max Mustermann, 1, 1200 €"_
- **Informationen:** Verarbeitete und interpretierte Daten, die eine Bedeutung haben.
    - Beispiel: _" Der Mitarbeiter Max Mustermann hat letzten Monat 1200 Euro Umsatz generiert."_

Wichtig:
- Daten sind die Grundlage, Informationen sind das Ergebnis von Verarbeitung.

## 2. Was ist eine Datenbank?

**Definition:** 
- Eine Datenbank ist eine 
	- strukturierte Sammlung von Daten, die 
	- effizient verwaltet und abgerufen werden kann.

Beispiele für Datenbanken im Alltag:
- Kundenverwaltung in Unternehmen.
- Lagerhaltung und Inventar.
- Bestellungen und Transaktionen in Online-Shops.

Unterschied: Datenbank vs. Excel

| **Datenbank**                         | **Excel**                         |
| ------------------------------------- | --------------------------------- |
| Mehrbenutzerzugriff möglich           | Ein Benutzer zur gleichen Zeit    |
| Große Datenmengen effizient verwalten | Begrenzte Datenkapazität          |
| Vermeidung von Redundanzen            | Daten können mehrfach vorkommen   |
| Automatische Konsistenzprüfung        | Manuelle Überprüfung erforderlich |

## 3. Vorteile von Datenbanken

1. Konsistenz:
    - Daten sind immer aktuell und korrekt.
    - Beispiel: Ein geänderter Kundenname wird in allen Verknüpfungen automatisch aktualisiert.
2. Redundanzvermeidung:
    - Gleiche Daten werden nicht mehrfach gespeichert, was Speicher spart.
3. Mehrbenutzerzugriff:
    - Mehrere Personen können gleichzeitig auf die Daten zugreifen.
4. Effiziente Abfragen:
    - Schnelle Suche und Analyse auch bei großen Datenmengen.
5. Sicherheit:
    - Benutzerrechte und Zugriffsberechtigungen schützen sensible Daten.

## 4. Einsatzgebiete von Datenbanken

- Banken:
    - Verwaltung von Konten, Transaktionen, und Kundendaten.
- Online-Shops:
    - Speicherung von Produktkatalogen, Bestellungen und Kundeninformationen.
- Krankenhäuser:
    - Verwaltung von Patientenakten, Terminen und Medikamenten.
- Logistik:
    - Verwaltung von Lagerbeständen und Lieferketten.

## 5. Überblick: Komponenten einer Datenbank

- Tabellen:
    - Bestehen aus Zeilen (Datensätzen) und Spalten (Attributen).
    - Beispiel: Eine Kundentabelle hat Spalten für Name, Adresse und Telefonnummer.
- Felder:
    - Einzelne Werte in einer Tabelle, z. B. "Max Mustermann" im Feld "Name".
- Beziehungen:
    - Verknüpfungen zwischen Tabellen, um Daten effizient zu organisieren.

### 6. Reflexion: Warum Datenbanken?

Probleme ohne Datenbanken:
- Daten sind unorganisiert und schwer auffindbar.
- Redundante Daten führen zu Inkonsistenzen.
- Fehlende Sicherheit und eingeschränkter Zugriff.

Lösungen mit Datenbanken:
- Organisierte, strukturierte Datenspeicherung.
- Zentraler Zugriff für mehrere Benutzer.
- Effiziente Verwaltung und Suche nach Daten.
