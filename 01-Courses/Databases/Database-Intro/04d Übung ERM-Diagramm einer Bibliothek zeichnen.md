## Aufgabe

Erstellen Sie ein Entity-Relationship-Modell (ERM) nach der Chen-Notation für eine Bibliothek. Beachten Sie dabei folgende Anforderungen:
1. Wählen Sie mindestens 4 passende Entitäten aus.
2. Jede Entität soll neben dem Primärschlüssel (PK) mindestens 2 weitere Attribute haben.
3. Verbinden Sie die Entitäten mit passend benannten Beziehungen.
4. Kennzeichnen Sie die Kardinalitäten mit der Krähenfußnotation.

## Hinweise:
- Verwenden Sie Rechtecke für Entitäten.
- Stellen Sie Attribute als Ovale dar und verbinden Sie sie mit ihrer Entität.
- Unterstreichen Sie den Primärschlüssel.
- Benutzen Sie Rauten für Beziehungen zwischen Entitäten.
- Zeichnen Sie die Kardinalitäten mit der Krähenfußnotation an den Verbindungslinien.

### Mögliche Entitäten zur Auswahl:
- Buch
- Autor
- Verlag
- Mitglied
- Ausleihe
- Bibliotheksmitarbeiter
- Regal
- Kategorie
