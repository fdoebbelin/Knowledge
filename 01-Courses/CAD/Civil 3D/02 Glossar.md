## Civil Engineering und Autodesk Civil 3D

| **Englischer Begriff**                   | **Deutsche Übersetzung**  | **Kurze Erklärung**                                                                                                                                                         |
| ---------------------------------------- | ------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Alignment**                            | Achse                     | Eine 2D- oder 3D-Linie, die die geometrische Lage eines linearen Objekts wie Straßen oder Kanäle definiert.                                                                 |
| **Alignment Stationing**                 | Stationsangaben           | Bezeichnet Positionen entlang einer Achse in festen Abständen oder an besonderen Punkten (z. B. 0+100, 0+200).                                                              |
| **Boundary**                             | Grenze                    | Ein geschlossener Bereich, der eine Oberfläche begrenzt oder eine spezifische Region definiert.                                                                             |
| **Breakline**                            | Bruchlinie                | Linien, die Höhenänderungen oder Kanten auf einer Oberfläche definieren und die TIN-Berechnung steuern.                                                                     |
| **Catchment Area**                       | Einzugsgebiet             | Der Bereich, aus dem Wasser zu einem Punkt (z. B. Entwässerungspunkte) abfließt.                                                                                            |
| **Corridor**                             | Korridor                  | Ein 3D-Modell linearer Infrastrukturen wie Straßen oder Eisenbahnen, basierend auf Achsen, Profilen und Querschnitten.                                                      |
| **Cross Section**                        | Querschnitt               | Ein Schnitt durch ein lineares Objekt wie eine Straße, der die Form und den Aufbau entlang der Achse zeigt.                                                                 |
| **Datum**                                | Bezugsebene               | Eine definierte Höhe, die als Referenz für Höhenmessungen verwendet wird.                                                                                                   |
| **Dynamic Model**                        | Dynamisches Modell        | Ein Modell, bei dem Änderungen an einem Element automatisch alle abhängigen Elemente aktualisieren.                                                                         |
| **Erosion Control**                      | Erosionskontrolle         | Maßnahmen zur Verhinderung von Bodenverlust bei Geländemodifikationen.                                                                                                      |
| **Feature Line**                         | Feature-Linie             | 3D-Linien mit Höheninformationen, die zur Definition von Geländeänderungen oder Entwässerungsstrukturen verwendet werden.                                                   |
| **Grading**                              | Geländeprofilierung       | Werkzeuge zur Modellierung von Böschungen, Aufschüttungen und Abtragungen auf einer bestehenden Oberfläche.                                                                 |
| **Grading Criteria**                     | Gradierungskriterien      | Regeln, die definieren, wie Grading-Objekte erstellt werden (z. B. Neigung oder Höhenversatz).                                                                              |
| **Hatching**                             | Schraffur                 | Füllt geschlossene Geometrien (z. B. Flächen) mit Mustern zur Darstellung von Materialien oder Zonen.                                                                       |
| **Label**                                | Beschriftung              | Automatisierte Textinformationen, die Objekte wie Achsen, Profile oder Grundstücke beschreiben.                                                                             |
| **LandXML**                              | LandXML                   | Ein offenes Dateiformat zum Austausch von Vermessungs-, Entwurfs- und Oberflächendaten.                                                                                     |
| **Parcel**                               | Grundstück                | Flächenobjekt, das ein Grundstück oder eine Parzelle darstellt, mit Attributen wie Fläche und Umrisslinien.                                                                 |
| **Parcel Fabric**                        | Grundstücksgeometrie      | Ein Netzwerk von zusammenhängenden Grundstücken oder Parzellen, das in Civil 3D modelliert wird.                                                                            |
| **Pipe Network**                         | Leitungsnetz              | Modell eines unterirdischen oder oberirdischen Rohrleitungssystems, z. B. für Regenwasser oder Abwasser.                                                                    |
| **Point**                                | Punkt                     | 3D-Koordinaten mit zusätzlichen Attributen wie Punktnummer und Beschreibung. Häufig für Vermessungsdaten verwendet.                                                         |
| **Point Group**                          | Punktgruppe               | Eine Sammlung von Punkten, die basierend auf gemeinsamen Eigenschaften (z. B. Beschreibung) organisiert sind.                                                               |
| **Pressure Network**                     | Druckleitungsnetz         | Modelliert unter Druck stehende Rohrleitungssysteme wie Wasser-, Gas- oder Ölleitungen. Es umfasst Rohre, Formstücke (z. B. Bögen, T-Stücke) und Armaturen (z. B. Ventile). |
| **Profile**                              | Profil                    | Ein vertikaler Schnitt entlang einer Achse, der Höhenveränderungen darstellt.                                                                                               |
| **Right-of-Way (ROW)**                   | Flurstücksrecht           | Der Bereich, der für den Bau von Straßen oder anderen Infrastrukturen reserviert ist.                                                                                       |
| **Sample Line**                          | Probenlinie               | Linien, die entlang einer Achse definiert werden, um Querschnitte zu erstellen.                                                                                             |
| **Station Offset**                       | Station/Versatz           | Bezeichnet die Entfernung eines Punktes relativ zu einer Achse (Stationierung und seitlicher Versatz).                                                                      |
| **Superelevation**                       | Überhöhung                | Neigungsanpassung von Straßen in Kurven, um den Fliehkraftausgleich zu verbessern.                                                                                          |
| **Superimposed Profile**                 | Überlagertes Profil       | Ein zusätzliches Profil, das über ein Hauptprofil gelegt wird, z. B. für Entwässerungslinien entlang einer Straße.                                                          |
| **Surface**                              | Oberfläche                | Repräsentiert die Geländetopographie durch Dreiecksvermaschungen (TIN) oder Rasterdaten.                                                                                    |
| **Survey Database**                      | Vermessungsdatenbank      | Zentrale Speicherung und Organisation von Vermessungsdaten, einschließlich Punkten, Linien und Netzen.                                                                      |
| **TIN (Triangulated Irregular Network)** | Dreiecksvermaschung (TIN) | Ein Netzwerk aus Dreiecken, das verwendet wird, um eine Oberfläche oder Topographie darzustellen.                                                                           |
| **Targeting**                            | Zielausrichtung           | Definiert, wie ein Objekt (z. B. Böschung) eine Oberfläche, ein Profil oder eine andere Referenz erreicht.                                                                  |
| **Viewport**                             | Ansichtsfenster           | Ein Bereich im Layout, der eine Ansicht des Modells in einem bestimmten Maßstab zeigt.                                                                                      |
| **Volume Calculation**                   | Volumenberechnung         | Ermittlung von Aushub- und Aufschüttungsmengen zwischen verschiedenen Oberflächen.                                                                                          |
