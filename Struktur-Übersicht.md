## 🏷️ Empfohlene Tag-Struktur

### Kategorien
```
#course      → Für Lernmaterialien
#tech        → Für technische Dokumentation
#project     → Für Projekte
#software    → Für Software-Docs
#note        → Für Notizen
```

### Status
```
#status/active      → Aktuell relevant
#status/archived    → Nicht mehr aktiv
#status/draft       → In Arbeit
#status/complete    → Abgeschlossen
```

### Priorität
```
#prio/high      → Wichtig
#prio/medium    → Normal
#prio/low       → Niedrig
```

### Themen (Beispiele)
```

#docker
#database

#ai
```

## 🎯 Best Practices

### Dateinamen
✅ DO:
- `M01a-Einführung.md`
- `00-Overview.md`
- `Setup-Guide.md`

❌ DON'T:
- `Notiz 1.md`
- `Unbenannt.md`
- `temp.md`

### Ordnerstruktur
- Maximal 3 Ebenen tief
- Sprechende Namen (englisch)
- Konsistente Präfixe

### Links
- Relative Links bevorzugen
- Aussagekräftige Link-Texte
- Broken Links regelmäßig prüfen
