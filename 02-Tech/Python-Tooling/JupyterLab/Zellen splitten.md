Es scheint, als ob Sie die falsche Tastenkombination verwenden. In Jupyter Notebooks ist die korrekte Tastenkombination zum Splitten einer Codezelle `Ctrl + Shift + -` (Minus). Hier sind die Schritte noch einmal:

### Jupyter Notebook

1. Öffnen Sie Ihr Jupyter Notebook.
2. Wählen Sie die Codezelle aus, die Sie splitten möchten.
3. Platzieren Sie den Cursor an der Stelle, an der Sie die Zelle teilen möchten.
4. Verwenden Sie die Tastenkombination `Ctrl + Shift + -`, um die Zelle an der Cursor-Position zu teilen.

Beispiel:

```python
# Ursprüngliche Zelle
def hello():
    print("Hello")
def world():
    print("World")
```

Nach dem Splitten:

```python
# Erste Zelle
def hello():
    print("Hello")
```

```python
# Zweite Zelle
def world():
    print("World")
```

Mit diesen Schritten sollten Sie in der Lage sein, Codezellen in Jupyter Notebooks zu splitten.
