**Alltags-/Desktop (Live zum Ausprobieren) – GLIM-Ordner vorhanden**

- Ubuntu (+ Flavors Kubuntu/Xubuntu/Lubuntu) — [https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop) → `ubuntu/` bzw. `xubuntu/`
- Linux Mint — [https://linuxmint.com/download.php](https://linuxmint.com/download.php) → `linuxmint/`
- Fedora Workstation — [https://fedoraproject.org/workstation/download/](https://fedoraproject.org/workstation/download/) → `fedora/` (der Fedora Media Writer schreibt eine „Live"-Version, die man ohne Installation booten kann) [GitHub](https://github.com/fancypantalons/hyprland-config)
- Debian **Live** (ausdrücklich die `debian-live-*`-Images, **nicht** das netinst!) — [https://www.debian.org/CD/live/](https://www.debian.org/CD/live/) → `debian/`
- antiX — [https://antixlinux.com/](https://antixlinux.com/) → `antix/`

**Arch-basiert (Live-Installer) – GLIM-Ordner `arch/`**

- Arch Linux — [https://archlinux.org/download/](https://archlinux.org/download/) → `arch/`
- CachyOS — [https://cachyos.org/download/](https://cachyos.org/download/) → `arch/` (mit archiso-Tweak in `inc-arch.cfg`)
