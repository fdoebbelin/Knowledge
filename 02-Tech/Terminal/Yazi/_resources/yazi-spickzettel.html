Konfigurationsdateien in ~/.config/yazi/

yazi.tomlVerhalten, Opener, Vorschau
keymap.tomlEigene Tastenbelegungen
theme.tomlFarben, Symbole, Trennzeichen
init.luaPlugins initialisieren und anpassen
package.tomlPlugins und Flavors, verwaltet mit ya pkg add autor/repo
Nur geänderte Werte eintragen, alles andere kommt aus der Standardkonfiguration. Änderungen wirken nach einem Neustart von Yazi.

yazi.toml – versteckte Dateien zeigen, Helix als Editor

[mgr]
show_hidden = true

[opener]
edit = [
  { run = "hx %s", block = true, for = "unix" },
]

keymap.toml – mit ! eine Shell im aktuellen Verzeichnis

[[mgr.prepend_keymap]]
on   = "!"
run  = 'shell "$SHELL" --block'
desc = "Shell hier öffnen"

theme.toml – Rundungen am Cursor-Indikator entfernen

[indicator]
padding = { open = "", close = "" }

Shell-Wrapper y für Bash / Zsh (~/.bashrc, ~/.zshrc)

function y() {
  local tmp cwd; tmp="$(mktemp -t "yazi-cwd.XXXXXX")"
  command yazi "$@" --cwd-file="$tmp"
  IFS= read -r -d '' cwd < "$tmp"
  [ "$cwd" != "$PWD" ] && [ -d "$cwd" ] \
    && builtin cd -- "$cwd" || builtin true
  command rm -f -- "$tmp"
}

Shell-Wrapper y für Nushell (config.nu)

def --env y [...args] {
  let tmp = (mktemp -t "yazi-cwd.XXXXXX")
  ^yazi ...$args --cwd-file $tmp
  let cwd = (open $tmp)
  if $cwd != $env.PWD and ($cwd | path exists) {
    cd $cwd
  }
  rm -fp $tmp
}
