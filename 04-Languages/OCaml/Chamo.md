Chamo

Chamo is a source code editor, even if it can be used to edit any text file. A system of "views" allows to edit some kinds of files in specific views.

It is developped in [OCaml](http://www.ocaml.org/) and OCaml is also used to configure it, like Elisp is used for emacs. Since version 4.0, user interface uses [OCaml-STK](https://zoggy.frama.io/ocaml-stk/) instead of LablGtk.

[This page](https://zoggy.frama.io/chamo/introduction.html) will give you an idea of what Chamo offers. Then you can read the [Documentation](https://zoggy.frama.io/chamo/doc.html) and the [FAQ](https://zoggy.frama.io/chamo/faq.html).

Development is hosted on [Framagit](https://framagit.org/zoggy/chamo).
