## Sequenzielle Datentypen - Übersicht

Unter sequenziellen Datentypen wird eine Klasse von Datentypen zusammengefasst, die Folgen von gleichartigen oder verschiedenen Elementen verwalten. Die in sequenziellen Datentypen gespeicherten Elemente haben eine definierte Reihenfolge, und man kann über eindeutige Indizes auf sie zugreifen.

Python stellt im Wesentlichen die folgenden fünf sequenziellen Typen zur Verfügung:

- `str`
- `bytes`
- `bytearray`
- `list`
- `tuple`

## Text- vs. Binärdaten

### str - Textdaten

Der Datentyp `str` ist für die Speicherung und Verarbeitung von Texten vorgesehen:

- Besteht aus einer Folge von Buchstaben, Leer- und Interpunktionszeichen sowie Zeilenvorschüben
- Unterstützt regionale Sonderzeichen wie deutsche Umlaute (»ä«, »ü«, »ö«)
- Unveränderlich (immutable)

```python
text = "Hallo Welt! äöü"
print(text)  # Funktioniert problemlos mit Sonderzeichen
```

### bytes - Binärdaten (unveränderlich)

Der Datentyp `bytes` kann einen binären Datenstrom speichern:

- Besteht aus einer Folge von Bytes (Zahlen von 0-255)
- Unveränderlich (immutable)
- Geeignet für Binärschnittstellen (Dateien, Netzwerk, etc.)

```python
binary_data = b"Hello"  # Nur ASCII-Zeichen erlaubt
print(binary_data)  # b'Hello'
```

### bytearray - Binärdaten (veränderlich)

Der Datentyp `bytearray` ist ebenfalls für Binärdaten vorgesehen:

- Wie `bytes`, aber veränderlich (mutable)
- Unterstützt die gleichen Operationen wie Listen

```python
mutable_binary = bytearray(b"Hello")
mutable_binary[0] = ord('h')  # Änderung möglich
print(mutable_binary)  # bytearray(b'hello')
```

## Übersicht der sequenziellen Datentypen

|Datentyp|Speichert|Veränderlichkeit|
|---|---|---|
|`list`|Listen beliebiger Instanzen|veränderlich|
|`tuple`|Listen beliebiger Instanzen|unveränderlich|
|`str`|Text als Sequenz von Buchstaben|unveränderlich|
|`bytes`|Binärdaten als Sequenz von Bytes|unveränderlich|
|`bytearray`|Binärdaten als Sequenz von Bytes|veränderlich|

## Strukturelle Trennung - Ein Python-Spezifikum

Die strukturelle Trennung von Textdaten und Binärdaten ist eine Eigenschaft, die Python von vielen anderen Programmiersprachen unterscheidet.

### Unterschied zu Python 2

In Python 2 gab es die Datentypen `str` und `unicode`:

- `str` in Python 2 entspricht dem jetzigen `bytes`
- `unicode` in Python 2 entspricht dem jetzigen `str`

Durch die klare Trennung in Python 3 ist der Umgang mit Zeichenketten strukturierter geworden, erfordert aber Aufmerksamkeit bei der Verwendung von Standardbibliothek-Funktionen bezüglich ihrer Parameter- und Rückgabetypen.

## Immutable vs. Mutable Verhalten

### Unveränderliche Datentypen (str, bytes, tuple)

Bei Operationen wird eine neue Instanz erzeugt:

```python
s = "Hallo"
s += " Welt"  # Neue Instanz wird erzeugt
```

### Veränderliche Datentypen (list, bytearray)

Bei Operationen wird die bestehende Instanz modifiziert:

```python
l = [1, 2]
l += [3, 4]  # Bestehende Liste wird erweitert
```

## Wichtige Konzepte

### Hashbarkeit

Unveränderliche Datentypen können als Schlüssel in Dictionaries verwendet werden:

```python
# Tupel als Dictionary-Schlüssel (funktioniert)
koordinaten = {(0, 0): "Ursprung", (1, 1): "Punkt A"}

# Listen als Dictionary-Schlüssel (funktioniert NICHT)
# koordinaten = {[0, 0]: "Ursprung"}  # TypeError!
```

### Anwendungsgebiete

**Listen verwenden für:**

- Sammlungen, die sich während der Programmausführung ändern
- Unbekannte finale Größe zur Entwicklungszeit
- Daten, die sortiert oder manipuliert werden müssen

**Tupel verwenden für:**

- Feste Datenstrukturen (Koordinaten, RGB-Werte)
- Funktions-Rückgabewerte mit mehreren Werten
- Dictionary-Schlüssel
- Unveränderliche Konfigurationsdaten

**Strings verwenden für:**

- Textverarbeitung und -darstellung
- Benutzereingaben und -ausgaben
- Textbasierte Datenformate

**Bytes/bytearray verwenden für:**

- Netzwerkkommunikation
- Dateizugriff auf binäre Formate
- Kryptographische Operationen
- Interaktion mit C-Bibliotheken
