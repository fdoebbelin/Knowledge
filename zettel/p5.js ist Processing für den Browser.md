**Processing** entstand 2001 am MIT Media Lab: Casey Reas und Ben Fry bauten, angeregt von John Maedas *Design by Numbers*, ein Werkzeug für Gestalter, die mit Code Bilder und Interaktionen erzeugen wollten („Creative Coding“). Die Sprache setzte auf Java auf; im Web liefen die Sketche als Java-Applets.

Applets sind aus den Browsern verschwunden, die Sprache des Webs ist JavaScript. **p5.js**, begonnen von Lauren McCarthy, überträgt deshalb die Idee von Processing auf JavaScript – nicht als Übersetzer, sondern als Bibliothek mit denselben Grundfunktionen wie `createCanvas`, `ellipse`, `fill` oder `mouseX`. (Nicht zu verwechseln mit dem älteren *Processing.js* von John Resig, das Processing-Code nach JavaScript übersetzte.)

Für Einsteiger ist p5.js ein abgeschirmter Garten: Man lernt Variablen, Bedingungen und Schleifen und sieht sofort ein Bild, ohne sich zuerst mit HTML, CSS und Werkzeugketten zu befassen. Ein Online-Editor unter editor.p5js.org genügt.

Der Ursprung des Koordinatensystems liegt wie bei fast allen Bildschirmsystemen oben links, *y* wächst nach unten – eine typische erste Hürde für alle, die das Koordinatensystem aus der Schule kennen.
