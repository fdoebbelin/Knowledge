Abstraktion lässt sich nicht als Begriff vermitteln und dann anwenden. Sie entsteht, wenn man zuerst ein konkretes Programm schreibt, das genau einen Fall löst, und es dann Stück für Stück verallgemeinert. Zwei Faustregeln beschreiben den Weg:

- **Erst konstant, dann variabel.** Ein Kreis wird mit festen Zahlen gezeichnet. Erst wenn er sitzt, wird die Position zur Variablen, dann zum Parameter einer Funktion.
- **Erst eines, dann viele.** Zuerst ein einzelner Ball, danach eine Liste von Bällen, die eine Schleife zeichnet.

Auf jeder Stufe bleibt das Programm lauffähig, und man kann an den Parametern drehen und sehen, was passiert. Man reagiert also weiterhin auf ein sichtbares Ergebnis, nur auf einer höheren Ebene: erst auf Zahlen, dann auf Funktionsargumente, dann auf Listen von Objekten.
