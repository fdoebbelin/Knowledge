- **Besonders gut für:** Schnellen Überblick und praktische Beispiele
## 2. "Unit Testing (und ein bisschen TDD)" (16 Min)

**YouTube:** ArchiLab - Mai 2021[^2]

- **Länge:** 16:05 Minuten

- **Besonders gut für:** TDD-Konzept verstehen
- **aber in JAVA**
