In Python gibt es eine Reihe von Operationen, die für alle sequenziellen Datentypen (str, bytes, bytearray, list und tuple) verfügbar sind.

## 12.2.1 Auf Elemente prüfen

Mit dem `in` Operator kann überprüft werden, ob ein Element in einer Sequenz enthalten ist:

```python
# Mit Listen
lst = ["eins", 2, 3.0, "vier", 5, "sechs", "sieben"]
3.0 in lst  # True
"vier" in lst  # True
10 in lst  # False

# Mit Strings
s = "Dies ist unser Test-String"
"u" in s  # True
"ist" in s  # True
"Hallo" in s  # False
```

Der `not in` Operator prüft, ob ein Element nicht in einer Sequenz enthalten ist:

```python
"a" in "Besuch beim Zahnarzt"  # True
"a" not in "Besuch beim Zahnarzt"  # False
```

## 12.2.2 Verkettung

Der `+` Operator verkettet zwei Sequenzen:

```python
# Mit Strings
vorname = "Heinz"
nachname = "Meier"
name = vorname + " " + nachname  # "Heinz Meier"
name
```

```python
# Mit +=
s = "Musik"
t = "lautsprecher"
s += t  # s wird zu "Musiklautsprecher"
s
```

Wichtiger Unterschied bei veränderlichen und unveränderlichen Datentypen:

- Bei unveränderlichen Datentypen (str, tuple) wird eine neue Instanz erzeugt
- Bei veränderlichen Datentypen (list, bytearray) wird die bestehende Instanz modifiziert

## 12.2.3 Wiederholung

Mit dem `*` Operator kann eine Sequenz wiederholt werden:

```python
3 * "abc"  # "abcabcabc"
"xyz" * 5  # "xyzxyzxyzxyzxyz"

# Mit *=
weihnachtsmann = "ho"
weihnachtsmann *= 3  # "hohoho"

# Auch mit Listen möglich
[1, 2] * 3  # [1, 2, 1, 2, 1, 2]
```

Bei Listen werden nur Referenzen vervielfacht, nicht die Objekte selbst:

```python
x = [["Schöne"], ["Liste"]] * 3
# [['Schöne'], ['Liste'], ['Schöne'], ['Liste'], ['Schöne'], ['Liste']]

x[1][0] = "Hä?"
# [['Schöne'], ['Hä?'], ['Schöne'], ['Hä?'], ['Schöne'], ['Hä?']]
```

## 12.2.4 Indizierung

Zugriff auf einzelne Elemente mit dem `[]` Operator:

```python
alphabet = "abcdefghijklmnopqrstuvwxyz"
alphabet[9]  # 'j'
alphabet[1]  # 'b'

l = [1, 2, 3, 4, 5, 6]
l[3]  # 4
```

Negative Indizes zählen von hinten:

```python
name = "Python"
name[-2]  # 'o'

l = [1, 2, 3, 4, 5, 6]
l[-1]  # 6
```

## 12.2.5 Slicing

Extrahieren von Teilsequenzen mit `[start:ende]`:

```python
s = "schrottWICHTIGschrott"
s[7:14]  # "WICHTIG"

l = ["Ich", "bin", "eine", "Liste", "von", "Strings"]
l[2:5]  # ['eine', 'Liste', 'von']
```

Mischen von positiven und negativen Indizes:

```python
string = "ameisen"
string[1:-1]  # "meise"
```

Weglassen von Indizes:

```python
s = "abcdefghijklmnopqrstuvwxyz"
s[:5]   # "abcde"
s[5:]   # "fghijklmnopqrstuvwxyz"
s[:]    # Kopie der gesamten Sequenz
```

Slicing mit Schrittweite:

```python
ziffern = "0123456789"
ziffern[1:10:2]  # "13579"
ziffern[1::2]    # "13579"

# Negative Schrittweite dreht die Sequenz um
name = "ytnoM Python"
name[4::-1]  # "Monty"
name[::-1]   # "nohtyP Monty"
```

## 12.2.6 Länge einer Sequenz

Die Länge einer Sequenz wird mit `len()` ermittelt:

```python
string = "Wie lang bin ich wohl?"
len(string)  # 22

len(["Hallo", 5, 2, 3, "Welt"])  # 5
```

## 12.2.7 Das kleinste und größte Element

Ermittlung des kleinsten und größten Elements mit `min()` und `max()`:

```python
l = [5, 1, 10, -9.5, 12, -5]
max(l)  # 12
min(l)  # -9.5

# Auch für Strings
max("wer gewinnt wohl")  # 'w'
min("zeichenkette")      # 'c'
```

## 12.2.8 Ein Element suchen

Suche nach einem Element mit der `index()` Methode:

```python
ziffern = [1, 2, 3, 4, 5, 6, 7, 8, 9]
ziffern.index(3)  # 2

s = "Hallo Welt"
s.index("l")  # 2
```

Die Suche kann auf einen Teilbereich beschränkt werden:

```python
folge = [0, 11, 222, 3333, 44444, 3333, 222, 11, 0]
folge.index(222)    # 2
folge.index(222, 3)  # 6
folge.index(222, -5)  # 6

"Hallo Welt".index("l", 5, 100)  # 8
```

## 12.2.9 Elemente zählen

Zählen der Vorkommen eines Elements mit der `count()` Methode:

```python
s = [1, 2, 2, 3, 2]
s.count(2)  # 3

"Hallo Welt".count("l")  # 3
```
