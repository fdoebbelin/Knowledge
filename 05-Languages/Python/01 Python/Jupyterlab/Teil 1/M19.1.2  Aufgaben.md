## 💡 Lösungshinweise

### Git-Repository Setup:
- `git init` im Projektordner ausführen
- `git config --global user.name/email` falls noch nicht konfiguriert
- Immer `git status` vor und nach Änderungen prüfen

### Commit-Strategien:
- Jede neue Funktion als separater Commit
- Aussagekräftige Commit-Nachrichten verwenden
- Kleine, logische Änderungen pro Commit

### Git-Befehle systematisch nutzen:
- `git add datei.py` für einzelne Dateien
- `git add .` für alle Änderungen
- `git commit -m "Beschreibung"` mit klarer Nachricht
- `git log --oneline` für Übersicht
