## 1.1 Strings erstellen

Strings sind Text in Python. Sie werden mit Anführungszeichen erstellt:

```python
# Verschiedene Arten, Strings zu erstellen
name = "Anna"
hobby = 'Programmieren'
alter_text = "25"

print("Name:", name)
print("Hobby:", hobby)
print("Alter als Text:", alter_text)
```

```python
# Längere Texte mit mehreren Zeilen
lange_nachricht = """Hallo!
Das ist eine Nachricht
über mehrere Zeilen."""

print(lange_nachricht)
```

```python
# f-Strings: Variablen in Text einbauen
name = "Max"
alter = 30

# Modern und einfach zu lesen
begruessung = f"Hallo {name}, du bist {alter} Jahre alt!"
print(begruessung)

# Mit Berechnungen
preis = 5.50
anzahl = 3
gesamtpreis = f"Gesamt: {preis * anzahl} Euro"
print(gesamtpreis)
```
## 1.2 Text verbinden und wiederholen

```python
# Texte mit + verbinden
vorname = "Maria"
nachname = "Schmidt"
vollname = vorname + " " + nachname
print("Vollname:", vollname)

# Text wiederholen mit *
linie = "-" * 20
print(linie)
print("WICHTIG")
print(linie)
```

```python
# Mehrere Texte elegant verbinden
woerter = ["Python", "ist", "super"]
satz = " ".join(woerter)
print("Satz:", satz)

# Mit verschiedenen Verbindungen
mit_komma = ", ".join(woerter)
print("Mit Kommas:", mit_komma)
```
## 1.3 In Texten suchen

```python
# Prüfen, ob Text enthalten ist
email = "max.mustermann@email.de"

# Einfache Suche mit 'in'
if "@" in email:
    print("Das ist eine E-Mail-Adresse")
else:
    print("Das ist keine E-Mail-Adresse")

# Mehrere Prüfungen
if "gmail" in email:
    print("Gmail-Adresse")
elif "email" in email:
    print("Email.de-Adresse")
else:
    print("Anderer Anbieter")
```
## 1.4 Text-Teile herausholen (Slicing)

```python
# Text-Teile mit [start:end] herausholen
text = "Python ist toll"
print("Ganzer Text:", text)

# Erste 6 Zeichen
anfang = text[0:6]
print("Anfang:", anfang)

# Ab Position 7 bis zum Ende
ende = text[7:]
print("Ende:", ende)

# Letzten 4 Zeichen
letzten = text[-4:]
print("Letzten 4 Zeichen:", letzten)
```

```python
# Praktisches Beispiel: Datum aufteilen
datum = "2024-03-15"
print("Datum:", datum)

jahr = datum[0:4]
monat = datum[5:7]
tag = datum[8:10]

print("Jahr:", jahr)
print("Monat:", monat) 
print("Tag:", tag)
```

```python
# Text umdrehen
wort = "Python"
rueckwaerts = wort[::-1]
print("Original:", wort)
print("Rückwärts:", rueckwaerts)

# Jeden zweiten Buchstaben
jeder_zweite = wort[::2]
print("Jeden zweiten:", jeder_zweite)
```
## 1.5 Text vergleichen

```python
# Texte vergleichen
text1 = "Hallo"
text2 = "hallo"
text3 = "Hallo"

print("text1 == text2:", text1 == text2)  # False (Groß-/Kleinschreibung)
print("text1 == text3:", text1 == text3)  # True

# Groß-/Kleinschreibung ignorieren
print("Ignoriere Groß-/Klein:", text1.lower() == text2.lower())
```

```python
# Alphabetische Reihenfolge
namen = ["Zebra", "Anna", "Bob"]
print("Unsortiert:", namen)

sortiert = sorted(namen)
print("Sortiert:", sortiert)

# Nach Länge sortieren
nach_laenge = sorted(namen, key=len)
print("Nach Länge:", nach_laenge)
```
