## 4. Branches verstehen und erstellen

### Was sind Branches?
```bash
# Zelle 4.1: Branch-Konzept erklären
def erklaere_branches():
    """Erklärt das Branch-Konzept für Anfänger"""
    
    branch_analogie = {
        "Hauptstraße (main)": "Der stabile, funktionierende Code",
        "Seitenstraße (feature-branch)": "Experimenteller Code für neue Features",
        "Parallelentwicklung": "Mehrere Features gleichzeitig entwickeln",
        "Zusammenführung (merge)": "Fertiges Feature zurück zur Hauptstraße"
    }
    
    print("🌳 Branches verstehen:")
    for konzept, erklärung in branch_analogie.items():
        print(f"   🔀 {konzept}: {erklärung}")
    
    print("\n🎯 Warum Branches verwenden?")
    print("   ✅ Sicherer experimentieren ohne main zu beschädigen")
    print("   ✅ Mehrere Features parallel entwickeln")
    print("   ✅ Einfach zwischen verschiedenen Versionen wechseln")
    print("   ✅ Teamarbeit ohne Konflikte")
    
    return "Branch-Konzept erfolgreich erklärt"

print(erklaere_branches())
```

## 7. Branch-Workflow verstehen

### Workflow-Übersicht

🔄 **Branch-Workflow für Anfänger:**
- 🌟 **main-Branch**: Stabiler, funktionierender Code
- 🚀 **Feature-Branch**: Neue Funktionen entwickeln
- 🔀 **Merge**: Fertiges Feature zurück zu main
- 🧹 **Cleanup**: Alte Branches löschen

### Branch-Strategien

🌳 **Einfache Branch-Strategien:**

| Branch-Typ     | Zweck | Beispiel |
|------------|-------|----------|
| `main`         | Stabiler Hauptcode | Produktive Version |
| `feature/name` | Neue Funktionen | `feature/calculator-ui` |
| `bugfix/name`  | Fehlerbehebungen | `bugfix/division-error` |
| `hotfix/name`  | Schnelle Korrekturen | `hotfix/security-patch` |

### Wichtige Branch-Befehle

💻 **Essenzielle Branch-Befehle:**

| Befehl | Beschreibung |
|--------|-------------|
| `git branch` | Alle Branches anzeigen |
| `git branch name` | Neuen Branch erstellen |
| `git checkout name` | Zu Branch wechseln |
| `git checkout -b name` | Branch erstellen und wechseln |
| `git merge branch` | Branch in aktuellen Branch mergen |
| `git branch -d name` | Branch löschen |
