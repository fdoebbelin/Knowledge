## Aufgabe 1: Einfache Dictionary-Operationen

Erstellen Sie ein Dictionary für ein Lieblingsbuch mit folgenden Informationen:
- titel
- autor  
- seiten
- jahr

Führen Sie dann folgende Operationen durch:
1. Geben Sie den Titel des Buches aus
2. Ändern Sie die Seitenzahl auf 350
3. Fügen Sie das Genre "Fantasy" hinzu
4. Geben Sie alle Informationen aus

**Lösungshinweise:**
- Verwenden Sie `dictionary[schluessel]` für Zugriff und Änderung
- Neue Einträge: `dictionary[neuer_schluessel] = wert`
- Ausgabe mit `print(dictionary)`
## Aufgabe 2: Kontaktverwaltung

Erstellen Sie ein Kontaktbuch-System:

1. Erstellen Sie ein leeres Dictionary `kontakte`
2. Fügen Sie 3 Kontakte hinzu (Name als Schlüssel, Telefonnummer als Wert)
3. Geben Sie alle Kontakte in schöner Form aus
4. Ändern Sie eine Telefonnummer
5. Löschen Sie einen Kontakt
6. Versuchen Sie, einen nicht existierenden Kontakt sicher abzurufen

**Lösungshinweise:**
- Leeres Dictionary: `kontakte = {}`
- Iteration: `for name, telefon in kontakte.items():`
- Sicherer Zugriff: `kontakte.get(name, "Nicht gefunden")`
- Löschen: `del kontakte[name]` oder `kontakte.pop(name)`
## Aufgabe 3: Einkaufsliste mit Preisen

Erstellen Sie eine Einkaufsliste mit Produkten und Preisen:

1. Erstellen Sie ein Dictionary mit 5 Produkten und ihren Preisen
2. Berechnen Sie die Gesamtsumme aller Produkte
3. Finden Sie das teuerste Produkt
4. Fügen Sie 2 neue Produkte hinzu
5. Geben Sie alle Produkte sortiert nach Preis aus

**Lösungshinweise:**
- Summe: `sum(dictionary.values())`
- Maximum: `max(dictionary.values())`
- Sortieren: `sorted(dictionary.items(), key=lambda x: x[1])`
## Aufgabe 4: Wörterzähler

Schreiben Sie ein Programm, das die Häufigkeit von Wörtern in einem Text zählt:

1. Gegeben ist der Text: "Python ist toll Python macht Spaß Python ist einfach"
2. Zählen Sie, wie oft jedes Wort vorkommt
3. Geben Sie die 3 häufigsten Wörter aus
4. Ignorieren Sie dabei Groß-/Kleinschreibung

**Lösungshinweise:**
- Text aufteilen: `text.lower().split()`
- Zählung: `if wort in woerter_count: woerter_count[wort] += 1`
- Oder verwenden Sie `woerter_count.get(wort, 0) + 1`
- Sortierung nach Häufigkeit
## Aufgabe 5: Schülerverwaltung

Erstellen Sie ein Schülerverwaltungssystem:

1. Dictionary mit Schülernamen als Schlüssel und Listen von Noten als Werte
2. Funktionen implementieren:
   - Neue Note hinzufügen
   - Durchschnitt eines Schülers berechnen  
   - Klassendurchschnitt berechnen
   - Besten Schüler finden

**Beispiel-Startdaten:**
```python
schueler = {
    "Anna": [1.3, 2.0, 1.7],
    "Bob": [2.3, 1.7, 2.0], 
    "Clara": [1.0, 1.3, 1.7]
}
```

**Lösungshinweise:**
- Note hinzufügen: `schueler[name].append(note)`
- Durchschnitt: `sum(noten) / len(noten)`
- Minimum finden: `min()` mit passendem key-Parameter
## Aufgabe 6: Dictionary-Zusammenführung

Sie haben zwei Dictionaries mit Produktinformationen:
```python
preise = {"Apfel": 1.20, "Banane": 0.80, "Orange": 1.50}
lager = {"Apfel": 50, "Banane": 30, "Orange": 20, "Birne": 15}
```

1. Erstellen Sie ein neues Dictionary, das alle Produkte enthält
2. Für Produkte, die in beiden Dictionaries stehen, kombinieren Sie die Informationen
3. Geben Sie eine Übersicht aus: "Produkt: Preis €X, Lager: Y Stück"

**Lösungshinweise:**
- Alle Schlüssel finden: `set(dict1.keys()) | set(dict2.keys())`  
- `.get()` für sichere Zugriffe verwenden
- `.update()` zum Zusammenführen
