## Lernziele
- Unterschied zwischen Kommentaren und Docstrings verstehen
- Docstrings für Funktionen schreiben
- Inline-Kommentare sinnvoll einsetzen
- Dokumentation als wichtigen Teil der Programmierung erkennen

## 1. Kommentare vs. Docstrings
### Was ist der Unterschied?

```python
def demonstriere_dokumentation():
    """Das ist ein Docstring - beschreibt WAS die Funktion macht"""
    # Das ist ein Kommentar - erklärt WIE der Code funktioniert
    ergebnis = "Dokumentation macht Code verständlich"
    return ergebnis

print("Ergebnis:", demonstriere_dokumentation())
```

### Wann verwende ich was?

```python
def zeige_verwendungszwecke():
    """Zeigt die verschiedenen Verwendungszwecke von Dokumentation"""
    # Kommentare erklären komplizierte Logik
    wichtige_zahl = 42  # Die Antwort auf alles
    
    # Docstrings beschreiben die Funktion selbst
    return "Kommentare: WIE - Docstrings: WAS"

print("Verwendung:", zeige_verwendungszwecke())
```

## 2. Einfache Docstrings schreiben
### Einzeilige Docstrings

```python
def berechne_quadrat(zahl):
    """Berechnet das Quadrat einer Zahl."""
    return zahl ** 2

print("Quadrat von 5:", berechne_quadrat(5))
```

### Mehrzeilige Docstrings

```python
def berechne_durchschnitt(zahlen):
    """
    Berechnet den Durchschnitt einer Zahlenliste.
    
    Args:
        zahlen (list): Liste von Zahlen
        
    Returns:
        float: Der berechnete Durchschnitt
    """
    return sum(zahlen) / len(zahlen)

print("Durchschnitt:", berechne_durchschnitt([1, 2, 3, 4, 5]))
```

## 3. Nützliche Inline-Kommentare
### Komplizierte Logik erklären

```python
def analysiere_kommentare():
    """Zeigt sinnvolle Inline-Kommentare"""
    punkte = [85, 92, 78, 96, 88]
    
    # Durchschnitt berechnen
    durchschnitt = sum(punkte) / len(punkte)
    
    # Note basierend auf Durchschnitt bestimmen
    if durchschnitt >= 90:
        note = "Sehr gut"  # 90% und höher
    elif durchschnitt >= 80:
        note = "Gut"       # 80-89%
    else:
        note = "Befriedigend"  # Unter 80%
    
    return f"Durchschnitt: {durchschnitt:.1f} - Note: {note}"

print("Analyse:", analysiere_kommentare())
```

## Zusammenfassung

### Dokumentations-Arten:
1. **Docstrings** - Beschreiben WAS eine Funktion macht
2. **Inline-Kommentare** - Erklären WIE komplizierter Code funktioniert
3. **Parameter-Dokumentation** - Beschreiben Eingaben und Ausgaben

### Grundregeln:
- Docstrings für alle Funktionen verwenden
- Kommentare nur bei komplizierter Logik
- Deutsche Sprache für bessere Verständlichkeit
- Kurz und präzise formulieren

### Warum dokumentieren?
Dokumentation hilft:
- Dir selbst beim späteren Verstehen
- Anderen beim Verwenden deines Codes
- Beim Finden und Beheben von Fehlern
