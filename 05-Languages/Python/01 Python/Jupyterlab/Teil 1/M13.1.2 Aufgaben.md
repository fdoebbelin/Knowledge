### Aufgabe 1: Persönliche Visitenkarte

Erstellen Sie ein Programm, das eine persönliche Visitenkarte ausgibt.

**Was Sie tun sollen:**
```python
# Zelle 1: Daten definieren
name = "Ihr Name"
beruf = "Ihr Beruf" 
email = "ihre.email@beispiel.de"
telefon = "+49 123 456789"

# TODO: Erstellen Sie eine schöne Visitenkarte mit f-Strings
```

**💡 Lösungshinweise:**
- Verwenden Sie f-Strings: `f"Text mit {variable}"`
- Erstellen Sie Linien mit `"-" * 40`
- Nutzen Sie `\n` für neue Zeilen oder mehrere `print()`-Befehle

**Erwartete Ausgabe:**
```
========================================
           VISITENKARTE
========================================
Name:     Max Mustermann
Beruf:    Python-Entwickler
E-Mail:   max@beispiel.de
Telefon:  +49 123 456789
========================================
```

### Aufgabe 4: Text-Verschlüsselung

Erstellen Sie eine einfache "Geheimschrift" durch Buchstaben-Vertauschung.

**Was Sie tun sollen:**

## 💡 Hilfreiche String-Operationen

```python
# Für die Aufgaben nützlich:
text = "Beispiel"

# Länge herausfinden
laenge = len(text)

# Position eines Zeichens finden
position = text.find("s")  # Gibt -1 zurück wenn nicht gefunden

# Text aufteilen in Wörter
woerter = text.split()

# Zeichen zählen
anzahl_e = text.count("e")

# Groß/Klein umwandeln
gross = text.upper()
klein = text.lower()
```
