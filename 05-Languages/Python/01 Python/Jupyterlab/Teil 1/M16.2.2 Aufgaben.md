### Paket-Import mit Fehlerbehandlung:
```python
try:
    import requests
    status = "installiert"
except ImportError:
    status = "nicht installiert"
```

### Einfache HTTP-Anfrage:
```python
import requests
response = requests.get("https://example.com")
if response.status_code == 200:
    print("Erfolgreich!")
```
