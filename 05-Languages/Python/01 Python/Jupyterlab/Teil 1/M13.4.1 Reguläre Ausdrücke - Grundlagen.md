## 4.1 Was sind Reguläre Ausdrücke?

Reguläre Ausdrücke (RegEx) sind wie **"intelligente Suchvorlagen"** für Text. Sie helfen dabei, bestimmte Muster in Texten zu finden und zu bearbeiten.

```python
# Warum RegEx? Ein einfaches Beispiel
text = "Meine Nummer ist 0123-456789 und meine Freundin hat 0987-654321"

# Ohne RegEx - umständlich
woerter = text.split()
nummern = [wort for wort in woerter if "-" in wort and wort.replace("-", "").isdigit()]
print("Ohne RegEx:", nummern)
```

```python
# Mit RegEx - elegant und mächtig
import re

muster = r'\d{4}-\d{6}'  # 4 Ziffern, Bindestrich, 6 Ziffern
nummern_regex = re.findall(muster, text)
print("Mit RegEx:", nummern_regex)
```

**Warum RegEx verwenden?**
- ✅ **Mächtig:** Komplexe Muster in einer Zeile
- ✅ **Flexibel:** Verschiedene Varianten gleichzeitig finden
- ✅ **Standardisiert:** Funktioniert in vielen Programmiersprachen
## 4.2 Einfache Zeichen - Die Bausteine

Beginnen wir mit den einfachsten RegEx-Bausteinen:

```python
# Beispieltext für alle Übungen
text = "Heute ist der 15.03.2024, Uhrzeit: 14:30"
print("Beispieltext:", text)
```

```python
# 1. Normale Buchstaben - finden sich selbst
print("'ist' finden:", re.findall(r'ist', text))
print("'xyz' finden:", re.findall(r'xyz', text))  # Leer
```

```python
# 2. \d = Ziffer (0-9) 
print("Einzelne Ziffern:", re.findall(r'\d', text))
```

```python
# 3. \w = Wort-Zeichen (Buchstabe, Ziffer oder _)
print("Wort-Zeichen:", re.findall(r'\w', text)[:10])  # Nur erste 10
```

```python
# 4. . = beliebiges Zeichen
print("3er-Gruppen:", re.findall(r'...', text)[:5])
```
## 4.3 Quantifikatoren - Wie oft?

Quantifikatoren bestimmen, **wie oft** ein Zeichen vorkommen soll:

```python
zahlen_text = "A1 B22 C333 D4444 E55555"
print("Text:", zahlen_text)
```

```python
# + = mindestens einmal
zahlen = re.findall(r'\d+', zahlen_text)
print("\\d+ (mindestens eine Ziffer):", zahlen)
```

```python
# {n} = genau n mal
zwei_ziffern = re.findall(r'\d{2}', zahlen_text)
print("\\d{2} (genau 2 Ziffern):", zwei_ziffern)
```

```python
# {min,max} = zwischen min und max mal
zwischen = re.findall(r'\d{2,4}', zahlen_text)
print("\\d{2,4} (2-4 Ziffern):", zwischen)
```
## 4.4 Zeichen-Klassen - Auswahl treffen

Mit eckigen Klammern können wir bestimmte Zeichen auswählen:

```python
gemischt = "Codes: A1B2, X9Y8, m3n4, Z7z6"
print("Text:", gemischt)
```

```python
# [A-F0-9] = Hexadezimalziffern
hexziffern = re.findall(r'[A-F0-9]', gemischt)
print("Hexadezimalziffern:", hexziffern)
```

```python
# [0-9] = Ziffern (wie \d)
ziffern = re.findall(r'[0-9]', gemischt)
print("Ziffern:", ziffern)
```

```python
# Kombinationen: Großbuchstabe + Ziffer
codes = re.findall(r'[A-Z][0-9]', gemischt)
print("Codes:", codes)
```

## 4.5 Wichtige RegEx-Funktionen

Python bietet verschiedene Funktionen für RegEx:

```python
email_text = "Kontakte: max@beispiel.de, anna@test.com, info@firma.org"
email_muster = r'\w+@\w+\.\w+'
print("Text:", email_text)
```

```python
# re.findall() - findet ALLE Übereinstimmungen
alle_emails = re.findall(email_muster, email_text)
print("Alle E-Mails:", alle_emails)
```

```python
# re.search() - findet die ERSTE Übereinstimmung
erste_email = re.search(email_muster, email_text)
if erste_email:
    print("Erste E-Mail:", erste_email.group())
    print("Position:", erste_email.start(), "bis", erste_email.end())
```

```python
# re.sub() - Text ersetzen
anonymisiert = re.sub(email_muster, '[EMAIL]', email_text)
print("Anonymisiert:", anonymisiert)
```
## 4.6 Praktische Beispiele
### Telefonnummern validieren

```python
def ist_gueltige_telefonnummer(nummer):
    """Prüft deutsche Telefonnummer: 3-4 Ziffern + Trenner + 6-8 Ziffern"""
    muster = r'^\d{3,4}[-\s]\d{6,8}$'
    return re.match(muster, nummer) is not None

# Test
test_nummern = ["030-12345678", "0171 9876543", "12345", "030/12345678"]
for nummer in test_nummern:
    gueltig = ist_gueltige_telefonnummer(nummer)
    print(f"{'✅' if gueltig else '❌'} '{nummer}'")
```
### Postleitzahlen finden

```python
def finde_postleitzahlen(text):
    """Findet deutsche 5-stellige PLZ mit Wortgrenzen"""
    return re.findall(r'\b\d{5}\b', text)

adressen = [
    "Berlin 10115",
    "PLZ: 80331 München",  
    "Hausnummer 12345 ist keine PLZ"
]

for adresse in adressen:
    plz_liste = finde_postleitzahlen(adresse)
    print(f"'{adresse}' → PLZ: {plz_liste}")
```
### Einfache Passwort-Prüfung

```python
def pruefe_passwort(passwort):
    """Einfache Passwort-Validierung"""
    return {
        "6+ Zeichen": len(passwort) >= 6,
        "Hat Ziffer": bool(re.search(r'\d', passwort)),
        "Hat Großbuchstabe": bool(re.search(r'[A-Z]', passwort)),
        "Hat Kleinbuchstabe": bool(re.search(r'[a-z]', passwort))
    }

# Test
for pw in ["123456", "Test123", "GROSS123"]:
    print(f"Passwort: '{pw}'")
    for regel, ok in pruefe_passwort(pw).items():
        print(f"  {'✅' if ok else '❌'} {regel}")
```
## 4.7 Häufige Anfängerfehler vermeiden

```python
# Fehler 1: Raw Strings vergessen
text_mit_zahlen = "Zahlen: 123, 456"
print("Besser r'\\d+' statt '\\d+' verwenden")
print("Ergebnis:", re.findall(r'\d+', text_mit_zahlen))
```

```python
# Fehler 2: Wortgrenzen vergessen
text_zahlen = "Telefon: 12345678, Hausnummer: 123"
ohne_grenzen = re.findall(r'\d{3}', text_zahlen)
mit_grenzen = re.findall(r'\b\d{3}\b', text_zahlen)
print("Ohne \\b:", ohne_grenzen)
print("Mit \\b:", mit_grenzen)
```
## 4.8 Nützliche RegEx-Muster

```python
# Sammlung praktischer Muster
patterns = {
    "Deutsche PLZ": r'\b\d{5}\b',
    "Einfache E-Mail": r'\w+@\w+\.\w+',
    "Deutsche Telefon": r'\d{3,4}[-\s]\d{6,8}',
    "Datum DD.MM.YYYY": r'\d{1,2}\.\d{1,2}\.\d{4}',
    "Zeit HH:MM": r'\d{1,2}:\d{2}',
    "Nur Buchstaben": r'^[A-Za-z]+$',
    "Nur Zahlen": r'^\d+$'
}

for name, muster in patterns.items():
    print(f"{name:18}: {muster}")
```

```python
# Test mit Beispieldaten
test_daten = """
Adresse: Hauptstr. 123, 10115 Berlin
E-Mail: test@beispiel.de  
Telefon: 030-1234567
Termin: 15.03.2024 um 14:30
"""

for name, muster in patterns.items():
    gefunden = re.findall(muster, test_daten)
    if gefunden:
        print(f"{name}: {gefunden}")
```
## Zusammenfassung

### Das Wichtigste zu RegEx:
- `r'...'` = Raw String verwenden (wichtig!)
- `\d` = Ziffer, `\w` = Wort-Zeichen, `.` = beliebiges Zeichen
- `+` = eins oder mehr, `{3}` = genau 3 mal
- `[A-Z]` = Großbuchstaben, `[0-9]` = Ziffern
- `\b` = Wortgrenze (sehr nützlich)
- `^` = Textanfang, `$` = Textende
### Wichtige Funktionen:
- `re.findall()` = alle finden
- `re.search()` = erste finden
- `re.sub()` = ersetzen
### Tipps für Einsteiger:
- Einfach anfangen, schrittweise erweitern
- Online-Tools zum Testen nutzen (regex101.com)
- Immer mit verschiedenen Beispielen testen
- Wortgrenzen `\b` nicht vergessen
