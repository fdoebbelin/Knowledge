## 💡 Lösungshinweise

### SQLite Grundlagen:
```python
import sqlite3

# Verbindung herstellen
verbindung = sqlite3.connect("datenbank.db")
cursor = verbindung.cursor()

# Tabelle erstellen
cursor.execute("""
    CREATE TABLE IF NOT EXISTS tabelle (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL
    )
""")
```

### Daten einfügen:
```python
# Einzelner Datensatz
cursor.execute("INSERT INTO tabelle (name) VALUES (?)", ("Wert",))

# Mehrere Datensätze
daten = [("Wert1",), ("Wert2",)]
cursor.executemany("INSERT INTO tabelle (name) VALUES (?)", daten)

# Änderungen speichern
verbindung.commit()
```

### Daten abfragen:
```python
# Alle Daten
cursor.execute("SELECT * FROM tabelle")
alle_daten = cursor.fetchall()

# Mit WHERE-Bedingung
cursor.execute("SELECT * FROM tabelle WHERE name = ?", ("Wert",))
gefilterte_daten = cursor.fetchall()
```

### Fehlerbehandlung:
```python
try:
    with sqlite3.connect("db.db") as verbindung:
        cursor = verbindung.cursor()
        cursor.execute("SQL hier")
except sqlite3.Error as db_fehler:
    return f"Datenbankfehler: {db_fehler}"
except Exception as fehler:
    return f"Fehler: {fehler}"
```

### JOIN-Abfragen:
```python
cursor.execute("""
    SELECT studenten.name, noten.note 
    FROM studenten 
    JOIN noten ON studenten.id = noten.student_id
""")
```
