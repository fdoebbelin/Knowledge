## 🔧 Musterlösung - Schritt für Schritt

### Schritt 1: Filtern mit Lambda

```python
# Zelle 1: filter() mit Lambda-Funktionen
print("🧪 FILTERN MIT LAMBDA")
print("=" * 30)

# Filter 1: Verkäufe über 500€
hohe_verkaeufe = list(filter(lambda v: v['umsatz'] > 500, verkaufsdaten))
print(f"\n💰 Verkäufe über 500€ ({len(hohe_verkaeufe)} gefunden):")
for verkauf in hohe_verkaeufe:
    print(f"  {verkauf['verkaufer']} - {verkauf['produkt']} - {verkauf['umsatz']}€")

# Filter 2: Nur Anna's Verkäufe  
anna_verkaeufe = list(filter(lambda v: v['verkaufer'] == 'Anna Schmidt', verkaufsdaten))
print(f"\n👩 Anna's Verkäufe ({len(anna_verkaeufe)} gefunden):")
for verkauf in anna_verkaeufe:
    print(f"  {verkauf['produkt']} - {verkauf['umsatz']}€")

# Filter 3: Nur Laptops
laptops = list(filter(lambda v: v['produkt'] == 'Laptop', verkaufsdaten))
print(f"\n💻 Laptop-Verkäufe ({len(laptops)} gefunden):")
for verkauf in laptops:
    print(f"  {verkauf['verkaufer']} - {verkauf['umsatz']}€")

print(f"\n✅ Filter funktionieren! Lambda-Syntax: lambda v: v['feld'] == wert")
```

### Schritt 3: Sortieren mit Lambda

```python
# Zelle 3: sorted() mit Lambda-Funktionen
print("🧪 SORTIEREN MIT LAMBDA")
print("=" * 30)

# Sortierung 1: Nach Umsatz (aufsteigend)
nach_umsatz = sorted(verkaufsdaten, key=lambda v: v['umsatz'])
print(f"\n📈 Nach Umsatz (niedrig → hoch):")
for verkauf in nach_umsatz:
    print(f"  {verkauf['umsatz']:>4}€ - {verkauf['verkaufer']} - {verkauf['produkt']}")

# Sortierung 2: Nach Umsatz (absteigend)
nach_umsatz_desc = sorted(verkaufsdaten, key=lambda v: v['umsatz'], reverse=True)
print(f"\n📉 Nach Umsatz (hoch → niedrig):")
for verkauf in nach_umsatz_desc:
    print(f"  {verkauf['umsatz']:>4}€ - {verkauf['verkaufer']} - {verkauf['produkt']}")

# Sortierung 3: Nach Verkäufer-Namen (alphabetisch)
nach_verkaufer = sorted(verkaufsdaten, key=lambda v: v['verkaufer'])
```

### Schritt 4: Kombinierte Operationen

```python
# Zelle 4: Kombinierte Lambda-Operationen
print("🧪 KOMBINIERTE OPERATIONEN")
print("=" * 35)

# Kombination 1: Verkäufe über 100€, sortiert nach Umsatz (absteigend)
high_value_sortiert = sorted(
    filter(lambda v: v['umsatz'] > 100, verkaufsdaten),
    key=lambda v: v['umsatz'],
    reverse=True
)
print(f"\n💎 Verkäufe über 100€ (sortiert, {len(high_value_sortiert)} gefunden):")
for verkauf in high_value_sortiert:
    print(f"  {verkauf['umsatz']:>4}€ - {verkauf['verkaufer']} - {verkauf['produkt']}")

# Kombination 2: Nur Laptop-Umsätze extrahieren
laptop_umsaetze = list(map(
    lambda v: v['umsatz'],
    filter(lambda v: v['produkt'] == 'Laptop', verkaufsdaten)
))
print(f"\n💻 Laptop-Umsätze extrahiert:")
print(f"  {laptop_umsaetze}")

# Kombination 3: Top 3 Verkäufe finden
top_3 = sorted(verkaufsdaten, key=lambda v: v['umsatz'], reverse=True)[:3]
print(f"\n🏆 Top 3 Verkäufe:")
for i, verkauf in enumerate(top_3, 1):
    print(f"  {i}. {verkauf['umsatz']:>4}€ - {verkauf['verkaufer']} - {verkauf['produkt']}")

# Kombination 4: Gesamtumsatz berechnen
gesamtumsatz = sum(map(lambda v: v['umsatz'], verkaufsdaten))
print(f"\n💰 Gesamtumsatz aller Verkäufe:")
print(f"  {gesamtumsatz:,}€")

# Kombination 5: Durchschnittsumsatz berechnen
durchschnitt = sum(map(lambda v: v['umsatz'], verkaufsdaten)) / len(verkaufsdaten)
print(f"\n📊 Durchschnittsumsatz:")
print(f"  {durchschnitt:.2f}€")

# Bonus: Verkäufer-Statistik
print(f"\n📈 Verkäufer-Statistik:")
verkaufer_namen = list(set(map(lambda v: v['verkaufer'], verkaufsdaten)))
for verkaufer in sorted(verkaufer_namen):
    verkaufer_verkaeufe = list(filter(lambda v: v['verkaufer'] == verkaufer, verkaufsdaten))
    verkaufer_umsatz = sum(map(lambda v: v['umsatz'], verkaufer_verkaeufe))
    print(f"  {verkaufer}: {len(verkaufer_verkaeufe)} Verkäufe, {verkaufer_umsatz:,}€")

print(f"\n✅ Kombinierte Operationen zeigen die Macht von Lambda-Funktionen!")
```

## 🎓 Zusammenfassung der Lösung

### Lambda-Funktionen Syntax:
```python
lambda parameter: rückgabewert
```

### Wichtige Anwendungen:

1. **filter()** - Elemente nach Bedingung auswählen
   ```python
   list(filter(lambda v: v['umsatz'] > 500, verkaufsdaten))
   ```

2. **map()** - Elemente transformieren
   ```python
   list(map(lambda v: v['umsatz'] * 1.1, verkaufsdaten))
   ```

3. **sorted()** - Nach Kriterium sortieren
   ```python
   sorted(verkaufsdaten, key=lambda v: v['umsatz'])
   ```

### Vorteile von Lambda-Funktionen:

- **Kompakt:** Eine Zeile statt einer ganzen Funktionsdefinition
- **Flexibel:** Verschiedene Kriterien ohne neue Funktionen
- **Kombinierbar:** Verkettung für komplexe Datenverarbeitung
- **Lesbar:** Bei einfachen Operationen übersichtlicher

### Wann Lambda verwenden:

- ✅ **Einfache, einzeilige Operationen**
- ✅ **Mit filter(), map(), sorted()**
- ✅ **Wenn die Logik klar und kurz ist**
- ❌ **Komplexe, mehrzeilige Logik**
- ❌ **Wenn Wiederverwendung wichtig ist**

### Praxis-Tipp:
Lambda-Funktionen sind perfekt für **schnelle Datenfilterung und -transformation**. Bei komplexeren Operationen sollten Sie normale Funktionen verwenden!
