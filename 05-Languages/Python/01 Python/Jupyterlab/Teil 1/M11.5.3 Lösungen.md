## Aufgabe 1: Sichere Listenfunktionen

**Problem:** Die Funktionen verändern ungewollt die ursprünglichen Listen.

### ✅ Lösung: Defensive Kopien verwenden

```python
def sortiere_liste(zahlen):
    """
    Sortiert eine Liste OHNE das Original zu verändern.
    
    Args:
        zahlen: Liste von Zahlen
    Returns:
        Neue sortierte Liste
    """
    # ✅ LÖSUNG: Kopie erstellen und bearbeiten
    kopie = zahlen.copy()  # Wichtig: Original kopieren!
    kopie.sort()           # Kopie sortieren
    return kopie           # Kopie zurückgeben

def entferne_negative(zahlen):
    """
    Entfernt negative Zahlen OHNE das Original zu verändern.
    
    Args:
        zahlen: Liste von Zahlen
    Returns:
        Neue Liste nur mit positiven Zahlen
    """
    # ✅ LÖSUNG: List Comprehension (erstellt automatisch neue Liste)
    return [zahl for zahl in zahlen if zahl >= 0]
```

## Aufgabe 2: Statistische Funktionen

**Aufgabe:** Tupel für mehrere zusammengehörige Rückgabewerte verwenden.

### ✅ Lösung: Tupel-Rückgabe implementieren

```python
def berechne_statistik(zahlen):
    """
    Berechnet statistische Werte für eine Zahlenliste.
    
    Args:
        zahlen: Liste von Zahlen
        
    Returns:
        Tupel: (anzahl, summe, durchschnitt, minimum, maximum)
    """
    # Fehlerbehandlung für leere Liste
    if not zahlen:  # Falls Liste leer ist
        return 0, 0, 0, None, None
    
    # ✅ LÖSUNG: Statistische Werte berechnen
    anzahl = len(zahlen)           # Anzahl der Elemente
    summe = sum(zahlen)            # Summe aller Zahlen
    durchschnitt = summe / anzahl  # Durchschnitt
    minimum = min(zahlen)          # Kleinstes Element
    maximum = max(zahlen)          # Größtes Element
    
    # Alle Werte als Tupel zurückgeben
    return anzahl, summe, durchschnitt, minimum, maximum

# Test der Statistik-Funktion
test_zahlen = [2, 5, 1, 8, 3, 7, 4]
anz, summe, avg, min_val, max_val = berechne_statistik(test_zahlen)

print(f"Zahlen: {test_zahlen}")
print(f"Anzahl: {anz}")
print(f"Summe: {summe}")
print(f"Durchschnitt: {avg:.2f}")
print(f"Minimum: {min_val}")
print(f"Maximum: {max_val}")
```

**Ausgabe:**
```
Zahlen: [2, 5, 1, 8, 3, 7, 4]
Anzahl: 7
Summe: 30
Durchschnitt: 4.29
Minimum: 1
Maximum: 8
```

**💡 Wichtige Konzepte:**
- Tupel-Rückgabe: `return wert1, wert2, wert3`
- Tupel-Unpacking: `a, b, c = funktion()`
- Fehlerbehandlung für leere Listen
## Aufgabe 3: Listen kombinieren

**Aufgabe:** `*args` für beliebig viele Parameter verwenden.

### ✅ Lösung: *args und extend() nutzen

```python
def kombiniere_und_sortiere(*listen):
    """
    Kombiniert mehrere Listen und sortiert das Ergebnis.
    
    Args:
        *listen: Beliebig viele Listen
        
    Returns:
        Tupel: (sortierte_kombinierte_liste, anzahl_original_listen)
    """
    # ✅ LÖSUNG: Listen kombinieren und sortieren
    kombiniert = []  # Leere Liste für das Ergebnis
    
    # Alle Listen durchgehen
    for liste in listen:
        kombiniert.extend(liste)  # Alle Elemente hinzufügen
    
    # Sicherheit: Neue sortierte Liste erstellen (nicht in-place sortieren)
    sortiert = sorted(kombiniert)
    
    # Tupel mit Ergebnis und Anzahl zurückgeben
    return sortiert, len(listen)

# Test der Kombinations-Funktion
liste1 = [3, 7, 1]
liste2 = [5, 2]
liste3 = [8, 4, 6]

kombiniert, anzahl = kombiniere_und_sortiere(liste1, liste2, liste3)
print(f"Original Listen: {liste1}, {liste2}, {liste3}")
print(f"Kombiniert und sortiert: {kombiniert}")
print(f"Anzahl ursprünglicher Listen: {anzahl}")

# Test mit unterschiedlicher Anzahl Listen
nur_eine, anz1 = kombiniere_und_sortiere([9, 2, 5])
print(f"Nur eine Liste: {nur_eine}, Anzahl: {anz1}")
```

**Ausgabe:**
```
Original Listen: [3, 7, 1], [5, 2], [8, 4, 6]
Kombiniert und sortiert: [1, 2, 3, 4, 5, 6, 7, 8]
Anzahl ursprünglicher Listen: 3
Nur eine Liste: [2, 5, 9], Anzahl: 1
```

**💡 Wichtige Konzepte:**
- `*args` für flexible Parameteranzahl
- `extend()` fügt alle Elemente einer Liste hinzu
- `sorted()` ist sicherer als `.sort()` (erstellt neue Liste)
## Aufgabe 4: Notenverwaltung

**Aufgabe:** Komplettes System mit mehreren zusammenarbeitenden Funktionen.

### ✅ Lösung: Modulares Design mit sicheren Funktionen

```python
def fuege_note_hinzu(noten_liste, neue_note):
    """
    Fügt eine neue Note hinzu (OHNE die ursprüngliche Liste zu ändern).
    
    Args:
        noten_liste: Bestehende Notenliste
        neue_note: Neue Note (1.0 bis 6.0)
        
    Returns:
        Neue Liste mit der zusätzlichen Note
    """
    # ✅ LÖSUNG: Kopie erstellen und neue Note hinzufügen
    neue_liste = noten_liste.copy()  # Original kopieren
    neue_liste.append(neue_note)     # Neue Note hinzufügen
    return neue_liste                # Neue Liste zurückgeben

def berechne_notenschnitt(noten_liste):
    """
    Berechnet den Notenschnitt.
    
    Args:
        noten_liste: Liste von Noten
        
    Returns:
        Durchschnittsnote (float)
    """
    # Fehlerbehandlung für leere Liste
    if not noten_liste:
        return 0.0
    
    # ✅ LÖSUNG: Durchschnitt berechnen
    return sum(noten_liste) / len(noten_liste)

def analysiere_noten(noten_liste):
    """
    Analysiert die Noten und gibt umfassende Statistik zurück.
    
    Args:
        noten_liste: Liste von Noten
        
    Returns:
        Tupel: (anzahl_noten, schnitt, beste_note, schlechteste_note, anzahl_bestanden)
    """
    # Fehlerbehandlung für leere Liste
    if not noten_liste:
        return 0, 0.0, None, None, 0
    
    # ✅ LÖSUNG: Alle Statistiken berechnen
    anzahl_noten = len(noten_liste)
    schnitt = berechne_notenschnitt(noten_liste)  # Wiederverwendung!
    beste_note = min(noten_liste)      # Beste Note (kleinste Zahl)
    schlechteste_note = max(noten_liste)  # Schlechteste Note (größte Zahl)
    
    # Anzahl bestandener Noten (besser als 4.0)
    anzahl_bestanden = len([note for note in noten_liste if note < 4.0])
    
    return anzahl_noten, schnitt, beste_note, schlechteste_note, anzahl_bestanden

# Test der Notenverwaltung
noten = [2.3, 1.7, 3.0, 2.7, 4.0, 1.3]
print(f"Ursprüngliche Noten: {noten}")

# Neue Note hinzufügen
neue_noten = fuege_note_hinzu(noten, 2.0)
print(f"Nach Hinzufügen einer 2.0: {neue_noten}")
print(f"Original unverändert: {noten}")  # ✅ Wichtig: Original prüfen!

# Notenschnitt berechnen
schnitt = berechne_notenschnitt(neue_noten)
print(f"Notenschnitt: {schnitt:.2f}")

# Vollständige Analyse
anz, schnitt, beste, schlechteste, bestanden = analysiere_noten(neue_noten)
print(f"Analyse:")
print(f"  Anzahl Noten: {anz}")
print(f"  Schnitt: {schnitt:.2f}")
print(f"  Beste Note: {beste}")
print(f"  Schlechteste Note: {schlechteste}")
print(f"  Bestanden: {bestanden}")
```

**Ausgabe:**
```
Ursprüngliche Noten: [2.3, 1.7, 3.0, 2.7, 4.0, 1.3]
Nach Hinzufügen einer 2.0: [2.3, 1.7, 3.0, 2.7, 4.0, 1.3, 2.0]
Original unverändert: [2.3, 1.7, 3.0, 2.7, 4.0, 1.3]
Notenschnitt: 2.43
Analyse:
  Anzahl Noten: 7
  Schnitt: 2.43
  Beste Note: 1.3
  Schlechteste Note: 4.0
  Bestanden: 6
```

**💡 Wichtige Konzepte:**
- Funktionen können andere Funktionen verwenden (Modularität)
- Immer Fehlerbehandlung für leere Listen
- List Comprehension für bedingte Zählung
## Aufgabe 5: Erweiterte Listenoperationen

**Aufgabe:** Komplexere Algorithmen mit Listen und Tupeln.

### ✅ Lösung: Fortgeschrittene Patterns implementieren

```python
def finde_doppelte(liste):
    """
    Findet alle Werte, die mehrmals in der Liste vorkommen.
    
    Args:
        liste: Liste mit möglichen Duplikaten
        
    Returns:
        Tupel: (doppelte_werte, einzigartige_werte)
    """
    # ✅ LÖSUNG: Vorkommen zählen und kategorisieren
    
    # Schritt 1: Zähle wie oft jedes Element vorkommt
    vorkommen = {}
    for element in liste:
        if element in vorkommen:
            vorkommen[element] += 1
        else:
            vorkommen[element] = 1
    
    # Schritt 2: Trenne in doppelte und einzigartige
    doppelte = []
    einzigartige = []
    
    for element, anzahl in vorkommen.items():
        if anzahl > 1:
            doppelte.append(element)
        else:
            einzigartige.append(element)
    
    return doppelte, einzigartige

def teile_liste(liste, bedingung_func):
    """
    Teilt Liste in zwei Teile basierend auf einer Bedingung.
    
    Args:
        liste: Zu teilende Liste
        bedingung_func: Funktion die True/False zurückgibt
        
    Returns:
        Tupel: (werte_die_bedingung_erfuellen, werte_die_bedingung_nicht_erfuellen)
    """
    # ✅ LÖSUNG: List Comprehensions für Filterung
    erfuellen = [x for x in liste if bedingung_func(x)]
    erfuellen_nicht = [x for x in liste if not bedingung_func(x)]
    
    return erfuellen, erfuellen_nicht

def verschmelze_sortiert(*sortierte_listen):
    """
    Verschmilzt mehrere bereits sortierte Listen zu einer sortierten Liste.
    
    Args:
        *sortierte_listen: Beliebig viele bereits sortierte Listen
        
    Returns:
        Eine sortierte Liste mit allen Elementen
    """
    # ✅ LÖSUNG: Alle Listen kombinieren und sortieren
    alle_elemente = []
    
    # Alle Listen kombinieren
    for liste in sortierte_listen:
        alle_elemente.extend(liste)
    
    # Sortieren und zurückgeben
    return sorted(alle_elemente)

# Tests für erweiterte Operationen

print(f"Alle Zahlen: {zahlen}")
print(f"Gerade: {gerade}")
print(f"Ungerade: {ungerade}")

print("\nTest: verschmelze_sortiert")
liste1 = [1, 3, 5, 7]
liste2 = [2, 4, 6]
liste3 = [8, 9, 10]
verschmolzen = verschmelze_sortiert(liste1, liste2, liste3)
print(f"Liste 1: {liste1}")
print(f"Liste 2: {liste2}")
print(f"Liste 3: {liste3}")
print(f"Verschmolzen: {verschmolzen}")
```

**Ausgabe:**

**💡 Wichtige Konzepte:**
- Dictionary zum Zählen von Vorkommen

## Zusammenfassung: Die 5 wichtigsten Regeln

### 🔒 1. Sicherheit: Listen kopieren
```python
# ❌ Gefährlich - verändert Original
def schlecht(liste):
    liste.sort()
    return liste

# ✅ Sicher - kopiert zuerst
def gut(liste):
    kopie = liste.copy()
    kopie.sort()
    return kopie
```

### 📦 2. Tupel für mehrere Rückgabewerte
```python
# ✅ Mehrere Werte als Tupel zurückgeben
def berechne_stats(zahlen):
    return len(zahlen), sum(zahlen), sum(zahlen)/len(zahlen)

# ✅ Tupel unpacking beim Aufruf
anzahl, summe, schnitt = berechne_stats([1, 2, 3, 4, 5])
```

### 🔄 3. *args für flexible Parameter
```python
# ✅ Beliebig viele Listen akzeptieren
def kombiniere(*listen):
    result = []
    for liste in listen:
        result.extend(liste)
    return result

# Verwendung
alle = kombiniere([1, 2], [3, 4], [5, 6])
```

### ✅ 4. List Comprehensions bevorzugen
```python
# ✅ Kurz und elegant
positive = [x for x in zahlen if x > 0]
verdoppelt = [x * 2 for x in zahlen]

# Statt langer Schleifen
```

### 🚫 5. Niemals ungewollt Listen ändern
```python
# ✅ Immer testen ob Original unverändert ist
original = [1, 2, 3]
result = meine_funktion(original)
print(f"Original: {original}")  # Muss unverändert sein!
```
