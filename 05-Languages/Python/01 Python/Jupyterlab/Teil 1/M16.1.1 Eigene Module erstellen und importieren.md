## 1. Was sind Module?

### Problem ohne Module

Ohne Module müssen wir denselben Code immer wieder in verschiedenen Dateien kopieren. Das führt zu mehreren Problemen:

- **Code-Wiederholung:** Gleiche Funktionen in mehreren Dateien kopieren
- **Wartungsaufwand:** Änderungen müssen überall gemacht werden
- **Fehleranfälligkeit:** Bugs müssen an vielen Stellen gefixt werden
- **Unübersichtlichkeit:** Sehr lange Dateien mit allem Code

### Lösung mit Modulen

Module lösen diese Probleme elegant:

- **Wiederverwendung:** Einmal schreiben, überall verwenden
- **Zentrale Wartung:** Änderungen nur an einer Stelle
- **Organisation:** Code thematisch aufteilen
- **Lesbarkeit:** Kleinere, fokussierte Dateien

### Module vs. Skripte

- **Skript:** Wird direkt ausgeführt (python datei.py)
- **Modul:** Wird von anderen Dateien importiert
- **Zweck Skript:** Eigenständiges Programm
- **Zweck Modul:** Stellt Funktionen für andere bereit

## 2. Erstes eigenes Modul erstellen

### Mathematik-Modul erstellen

```python
def erstelle_mathematik_modul():
    """Erstellt eine Datei mit mathematischen Funktionen"""
    
    # Inhalt für das Mathematik-Modul
    modul_inhalt = '''"""
Mathematik-Modul mit Grundrechenarten
Dieses Modul stellt einfache mathematische Funktionen bereit.
"""

def addiere(a, b):
    """Addiert zwei Zahlen"""
    return a + b

def subtrahiere(a, b):
    """Subtrahiert zwei Zahlen"""
    return a - b

def multipliziere(a, b):
    """Multipliziert zwei Zahlen"""
    return a * b

def dividiere(a, b):
    """Dividiert zwei Zahlen"""
    if b != 0:
        return a / b
    else:
        return "Fehler: Division durch Null!"

def quadriere(x):
    """Berechnet das Quadrat einer Zahl"""
    return x * x
'''
    
    # Datei erstellen
    with open("mathematik.py", "w", encoding="utf-8") as datei:
        datei.write(modul_inhalt)
    
    return "✅ Mathematik-Modul 'mathematik.py' wurde erstellt!"

print(erstelle_mathematik_modul())
```

def erstelle_erweiterten_rechner():
    """Erstellt einen erweiterten Taschenrechner als Modul"""
    
    rechner_inhalt = '''"""
Erweiterter Taschenrechner
Dieses Modul bietet erweiterte Rechenfunktionen.
"""

def prozent_berechnen(wert, prozent):
    """Berechnet einen Prozentwert"""
    return (wert * prozent) / 100

def durchschnitt(zahlen_liste):
    """Berechnet den Durchschnitt einer Zahlenliste"""
    if not zahlen_liste:
        return 0
    return sum(zahlen_liste) / len(zahlen_liste)

def maximum(zahlen_liste):
    """Findet die größte Zahl in einer Liste"""
    if not zahlen_liste:
        return None
    return max(zahlen_liste)

def minimum(zahlen_liste):
    """Findet die kleinste Zahl in einer Liste"""
    if not zahlen_liste:
        return None
    return min(zahlen_liste)

def fakultaet(n):
    """Berechnet die Fakultät einer Zahl"""
    if n == 0 or n == 1:
        return 1
    ergebnis = 1
    for i in range(2, n + 1):
        ergebnis *= i
    return ergebnis
'''
    
    with open("rechner_erweitert.py", "w", encoding="utf-8") as datei:
        datei.write(rechner_inhalt)
    
    return "✅ Erweiterter Rechner 'rechner_erweitert.py' wurde erstellt!"

## 6. Module-Import-Varianten verstehen

### Alle Import-Möglichkeiten im Überblick

**import modul**

- Komplettes Modul importieren
- Zugriff mit modul.funktion()
- Klare Zuordnung der Funktionen
- Empfohlen für wenige Funktionen

**from modul import funktion**

- Nur spezifische Funktionen importieren
- Direkter Zugriff ohne Modulname
- Gut für häufig verwendete Funktionen

**import modul as alias**

- Modul mit kurzem Namen importieren
- Praktisch bei langen Modulnamen
- Kurze, prägnante Aliase wählen

**from modul import ***

- Alle Funktionen importieren
- Vorsicht: kann Namen überschreiben!
- Nicht empfohlen für Anfänger

```python
def demonstriere_import_star_problem():
    """Zeigt warum 'from modul import *' problematisch sein kann"""
    
    # Eigene Funktion definieren
    def addiere(a, b):
        return f"Meine Addition: {a + b}"
    
    print(f"Vor import: {addiere(5, 3)}")
    
    # Nach 'from mathematik import *' würde unsere Funktion überschrieben
    # Das ist ein häufiger Fehler bei Anfängern
    
    warnung = """⚠️ Problem mit 'from modul import *':
- Kann eigene Funktionen überschreiben
- Schwer zu finden, welche Funktion woher kommt
- Macht Code schwer verständlich
- Besser: Explizite Importe verwenden"""
    
    return warnung

print(demonstriere_import_star_problem())
```

def zeige_modul_informationen():
    """Zeigt wie man Informationen über Module erhält"""
    import mathematik
    
    # Modul-Dokumentation anzeigen
    modul_doc = mathematik.__doc__ if mathematik.__doc__ else "Keine Dokumentation"
    
    # Verfügbare Funktionen auflisten
    funktionen = [name for name in dir(mathematik) if not name.startswith('_')]
    
    info = f"""Modul-Informationen:
Modul: mathematik.py
Dokumentation: {modul_doc.strip()}
Verfügbare Funktionen: {funktionen}
Anzahl Funktionen: {len(funktionen)}"""
    
    return info

print(zeige_modul_informationen())

## 8. Dateien-Übersicht erstellen

```python
def zeige_erstellte_dateien():
    """Zeigt eine Übersicht aller erstellten Modul-Dateien"""
    import os
    
    python_dateien = [datei for datei in os.listdir('.') if datei.endswith('.py')]
    
    dateien_info = {}
    for datei in python_dateien:
        try:
            with open(datei, 'r', encoding='utf-8') as f:
                zeilen = len(f.readlines())
            dateien_info[datei] = f"{zeilen} Zeilen"
        except:
            dateien_info[datei] = "Konnte nicht gelesen werden"
    
    print("📁 ERSTELLTE MODUL-DATEIEN:")
    print("=" * 40)
    for datei, info in dateien_info.items():
        print(f"✅ {datei}: {info}")
    
    return f"Insgesamt {len(python_dateien)} Python-Module erstellt!"

print(zeige_erstellte_dateien())
```

## Zusammenfassung

### Wichtige Konzepte:

1. **Module erstellen:** Eigene .py-Dateien mit Funktionen schreiben
2. **Module importieren:** `import`, `from ... import`, Aliase verwenden
3. **Code-Organisation:** Thematisch verwandte Funktionen in Module gruppieren
4. **Wiederverwendung:** Einmal geschriebene Funktionen überall nutzen
5. **Wartbarkeit:** Änderungen zentral in Modulen vornehmen

### Import-Strategien:

- **`import modul`**: Für wenige Funktionen, klare Zuordnung
- **`from modul import funktion`**: Für häufig verwendete Funktionen
- **`import modul as alias`**: Für kurze Namen bei langen Modulnamen
- **`from modul import *`**: Nur in Ausnahmefällen, da Namenskonflikte möglich

### Best Practices:

- Aussagekräftige Modul- und Funktionsnamen wählen
- Module dokumentieren mit Docstrings
- Ein Modul = Ein Themenbereich
- Funktionen klein und fokussiert halten
- Import-Statements am Dateianfang
