## 1. Dictionary Comprehensions - Grundlagen

Dictionary Comprehensions erstellen Dictionaries mit der gleichen eleganten Syntax wie List Comprehensions.

```python
# Traditionelle Dictionary-Erstellung
zahlen = [1, 2, 3, 4, 5]

# Mit for-Schleife
quadrat_dict_alt = {}
for zahl in zahlen:
    quadrat_dict_alt[zahl] = zahl ** 2

print("Mit for-Schleife:", quadrat_dict_alt)
```

```python
# Mit Dictionary Comprehension - elegant!
quadrat_dict_neu = {zahl: zahl ** 2 for zahl in zahlen}
print("Mit Dict Comprehension:", quadrat_dict_neu)
print("Syntax: {key: value for item in iterable}")
```

## 2. Dictionary Comprehensions - Erweiterte Syntax

```python
# Grundstruktur: {KEY_EXPRESSION: VALUE_EXPRESSION for ITEM in ITERABLE if CONDITION}

# Beispiel 1: Wort-Längen Dictionary
woerter = ["Python", "Java", "C++", "JavaScript", "Go"]
wort_laengen = {wort: len(wort) for wort in woerter}
print("Wort-Längen:", wort_laengen)
```

```python
# Beispiel 2: Mit Filterung - nur lange Wörter
lange_woerter = {wort: len(wort) for wort in woerter if len(wort) >= 4}
print("Lange Wörter:", lange_woerter)
```

```python
# Beispiel 3: Transformierte Keys und Values
wort_info = {wort.upper(): f"{len(wort)} Zeichen" for wort in woerter}
print("Wort-Info:", wort_info)
```

## 3. Praktische Dictionary Comprehension Patterns

### 3.1 Listen zu Dictionaries transformieren

```python
studenten = ["Anna", "Bob", "Charlie", "Diana"]
```

### 3.3 Gruppierung und Aggregation

```python
# Daten gruppieren
personen = [
    ("Anna", "Berlin", 25),
    ("Bob", "München", 30),
    ("Charlie", "Berlin", 28),
    ("Diana", "Hamburg", 35),
    ("Eva", "Berlin", 22)
]

# Als Dictionary Comprehension für Anzahl pro Stadt
stadt_anzahl = {stadt: len([1 for name, s, alter in personen if s == stadt]) 
                for stadt in set(s for name, s, alter in personen)}
print("Personen pro Stadt:", stadt_anzahl)
```

```python
# Durchschnittsalter pro Stadt
stadt_alter = {}
for stadt in set(s for name, s, alter in personen):
    alter_liste = [alter for name, s, alter in personen if s == stadt]
    stadt_alter[stadt] = sum(alter_liste) / len(alter_liste)

print("Durchschnittsalter pro Stadt:", stadt_alter)
```

## 4. Set Comprehensions - Grundlagen

Set Comprehensions erstellen Mengen (Sets) - automatisch ohne Duplikate!

```python
# Traditionelle Set-Erstellung
zahlen = [1, 2, 2, 3, 3, 3, 4, 4, 5]

# Mit for-Schleife
quadrate_set_alt = set()
for zahl in zahlen:
    quadrate_set_alt.add(zahl ** 2)

print("Mit for-Schleife:", quadrate_set_alt)
```

```python
# Mit Set Comprehension - elegant und automatisch unique!
quadrate_set_neu = {zahl ** 2 for zahl in zahlen}
print("Mit Set Comprehension:", quadrate_set_neu)
print("Syntax: {expression for item in iterable}")
```

### 5.2 Mathematische Operationen

```python
# Primzahlen-Check (vereinfacht)
def ist_primzahl(n):
    if n < 2:
        return False
    for i in range(2, int(n ** 0.5) + 1):
        if n % i == 0:
            return False
    return True

# Set aller Primzahlen bis 50
primzahlen = {n for n in range(2, 51) if ist_primzahl(n)}
print("Primzahlen bis 50:", sorted(primzahlen))
```

```python
# Quadrate von Primzahlen
primzahl_quadrate = {n ** 2 for n in primzahlen if n < 10}
print("Primzahl-Quadrate (n<10):", sorted(primzahl_quadrate))
```

## 9. Häufige Patterns und Best Practices

### 9.1 Sichere Dictionary-Zugriffe

```python
# Daten mit möglichen fehlenden Werten
rohdaten = [
    {"name": "Anna", "alter": 25, "stadt": "Berlin"},
    {"name": "Bob", "alter": 30},  # Stadt fehlt
    {"name": "Charlie", "stadt": "München"},  # Alter fehlt
    {"name": "Diana", "alter": 28, "stadt": "Hamburg"}
]

# Sichere Extraktion mit get()
namen_alter = {
    item["name"]: item.get("alter", "Unbekannt") 
    for item in rohdaten 
    if "name" in item
}
print("Namen und Alter:", namen_alter)
```

```python
# Nur vollständige Datensätze
vollstaendige_daten = {
    item["name"]: {"alter": item["alter"], "stadt": item["stadt"]}
    for item in rohdaten
    if all(key in item for key in ["name", "alter", "stadt"])
}
print("Vollständige Daten:", vollstaendige_daten)
```

### 9.2 Inverse Mappings

```python
# Original Dictionary
farb_codes = {"rot": "#FF0000", "grün": "#00FF00", "blau": "#0000FF"}

# Inverse Mapping: Code -> Farbe
code_farben = {code: farbe for farbe, code in farb_codes.items()}

```

```python
# Bei mehreren Values pro Key
kategorien = {
    "obst": ["apfel", "banane", "orange"],
    "gemüse": ["karotte", "brokkoli", "spinat"],
    "fleisch": ["rind", "schwein", "huhn"]
```

## 10. Wann welche Comprehension verwenden?

```python
# Entscheidungshilfe mit Beispiel
daten = ["Python", "Java", "Python", "C++", "Java", "Go"]

# List Comprehension: Wenn Reihenfolge und Duplikate wichtig sind
liste_ergebnis = [item.upper() for item in daten if len(item) > 2]
print("Liste (mit Duplikaten):", liste_ergebnis)
```

```python
# Set Comprehension: Wenn nur eindeutige Werte gewünscht sind
set_ergebnis = {item.upper() for item in daten if len(item) > 2}
print("Set (ohne Duplikate):", set_ergebnis)
```

```python
# Dictionary Comprehension: Wenn Key-Value-Beziehungen gebraucht werden
dict_ergebnis = {item: len(item) for item in daten}
print("Dictionary (Key-Value):", dict_ergebnis)
```

## 11. Zusammenfassung

```python
# Alle drei Comprehension-Typen in einem praktischen Beispiel
verkaufsdaten = [
    ("2024-01", "Laptop", 1200),
    ("2024-01", "Maus", 25),
    ("2024-01", "Laptop", 1200),  # Duplikat
    ("2024-02", "Tastatur", 80),
    ("2024-02", "Monitor", 300),
    ("2024-03", "Laptop", 1200)
]

# Eleganter mit Dictionary Comprehension
monate = {monat for monat, produkt, preis in verkaufsdaten}
monatsumsatz_elegant = {
    monat: sum(preis for m, produkt, preis in verkaufsdaten if m == monat)
    for monat in monate
}

print("Monatsumsatz:", monatsumsatz_elegant)
```

```python
# Set: Alle verkauften Produkte (unique)
verkaufte_produkte = {produkt for monat, produkt, preis in verkaufsdaten}
print("Verkaufte Produkte:", verkaufte_produkte)
```

```python
# List: Alle Preise (mit Duplikaten für Durchschnittsberechnung)
alle_preise = [preis for monat, produkt, preis in verkaufsdaten]
print("Durchschnittspreis:", sum(alle_preise) / len(alle_preise))
```

### Wichtige Erkenntnisse:
- **Dictionary Comprehensions:** Ideal für Key-Value-Mappings und Lookup-Tabellen
- **Set Comprehensions:** Perfekt für eindeutige Werte und Membership-Tests
- **Automatische Optimierung:** Python optimiert Comprehensions intern
- **Lesbarkeit:** Bei komplexer Logik normale Schleifen bevorzugen
- **Kombination:** Verschiedene Comprehension-Typen ergänzen sich perfekt
