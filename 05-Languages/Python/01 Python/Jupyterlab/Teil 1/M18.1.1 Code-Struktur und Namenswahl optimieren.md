## Lernziele
- DRY-Prinzip (Don't Repeat Yourself) verstehen und anwenden
- Aussagekräftige Namen für bessere Code-Lesbarkeit wählen
- Magic Numbers durch benannte Konstanten ersetzen
- Code-Duplikation erkennen und durch Funktionen eliminieren

## 1. Problem: Schlechter Code mit Duplikation

### Typische Anfänger-Probleme
```python
def zeige_schlechten_code():
    """Zeigt typische Code-Probleme von Anfängern"""
    
    # Schlechter Code mit vielen Problemen
    schlechter_code = '''
def calc():
    d = [85, 92, 78, 96, 88]
    s = 0
    for i in d:
        s = s + i
    a = s / 5
    
    if a >= 90:
        print("Excellent")
    elif a >= 80:
        print("Good") 
    elif a >= 70:
        print("Average")
    else:
        print("Poor")
    
    # Gleiche Logik nochmal - DUPLIKATION!
    d2 = [75, 82, 79, 88, 91]
    s2 = 0
    for i in d2:
        s2 = s2 + i
    a2 = s2 / 5
    
    if a2 >= 90:
        print("Excellent")
    elif a2 >= 80:
        print("Good")
    # ... nochmal die gleichen if-Bedingungen
    '''
    
    probleme = [
        "❌ Unverständliche Namen: d, s, a, calc()",
        "❌ Magic Numbers: 90, 80, 70, 5",
        "❌ Code-Duplikation: Gleiche Logik zweimal",
        "❌ Keine Funktionsaufteilung: Alles in einer Funktion",
        "❌ Schwer zu ändern: Konstanten überall verteilt"
    ]
    
    print("🚨 PROBLEME IM SCHLECHTEN CODE:")
    for problem in probleme:
        print(f"   {problem}")
    
    return "Schlechter Code mit 5 typischen Anfänger-Problemen identifiziert"

print(zeige_schlechten_code())
```

## 2. Lösung: DRY-Prinzip anwenden

### Konstanten definieren (Magic Numbers eliminieren)
```python
def definiere_konstanten():
    """Zeigt wie Magic Numbers durch Konstanten ersetzt werden"""
    
    # Konstanten mit aussagekräftigen Namen
    EXCELLENT_THRESHOLD = 90
    GOOD_THRESHOLD = 80
    AVERAGE_THRESHOLD = 70
    
    konstanten_info = {
        "EXCELLENT_THRESHOLD": {"wert": EXCELLENT_THRESHOLD, "bedeutung": "Ab dieser Note ist die Leistung ausgezeichnet"},
        "GOOD_THRESHOLD": {"wert": GOOD_THRESHOLD, "bedeutung": "Ab dieser Note ist die Leistung gut"},
        "AVERAGE_THRESHOLD": {"wert": AVERAGE_THRESHOLD, "bedeutung": "Ab dieser Note ist die Leistung durchschnittlich"}
    }
    
    print("✅ KONSTANTEN DEFINIERT:")
    for name, info in konstanten_info.items():
        print(f"   {name} = {info['wert']} ({info['bedeutung']})")
    
    return f"3 Magic Numbers durch benannte Konstanten ersetzt"

print(definiere_konstanten())
```

### Aussagekräftige Funktionsnamen verwenden
```python
def berechne_notendurchschnitt(noten_liste):
    """Berechnet den Durchschnitt einer Notenliste"""
    
    if not noten_liste:  # Defensive Programmierung
        return 0
    
    gesamtsumme = sum(noten_liste)
    anzahl_noten = len(noten_liste)
    durchschnitt = gesamtsumme / anzahl_noten
    
    print(f"📊 BERECHNUNG:")
    print(f"   Noten: {noten_liste}")
    print(f"   Summe: {gesamtsumme}")
    print(f"   Anzahl: {anzahl_noten}")
    print(f"   Durchschnitt: {durchschnitt:.1f}")
    
    return durchschnitt

# Test der Funktion
student_noten = [85, 92, 78, 96, 88]
print(f"Durchschnitt: {berechne_notendurchschnitt(student_noten):.1f}")
```

### Code-Duplikation eliminieren
```python
def bestimme_leistungsklasse(durchschnittsnote):
    """Bestimmt die Leistungsklasse basierend auf dem Durchschnitt"""
    
    # Konstanten (in realem Code global definiert)
    EXCELLENT_THRESHOLD = 90
    GOOD_THRESHOLD = 80
    AVERAGE_THRESHOLD = 70
    
    if durchschnittsnote >= EXCELLENT_THRESHOLD:
        kategorie = "Ausgezeichnet"
    elif durchschnittsnote >= GOOD_THRESHOLD:
        kategorie = "Gut"
    elif durchschnittsnote >= AVERAGE_THRESHOLD:
        kategorie = "Durchschnittlich"
    else:
        kategorie = "Verbesserungsbedarf"
    
    print(f"🎯 BEWERTUNG:")
    print(f"   Note: {durchschnittsnote:.1f}")
    print(f"   Kategorie: {kategorie}")
    
    return kategorie

# Test der Funktion
note = 87.8
print(f"Leistungsklasse: {bestimme_leistungsklasse(note)}")
```

## 3. Clean Code: Alles zusammenführen

### Hauptfunktion mit klarer Struktur
```python
def bewerte_student_leistung(student_name, noten_liste):
    """Bewertet die Gesamtleistung eines Studenten"""
    
    # Schritt 1: Durchschnitt berechnen
    durchschnitt = berechne_notendurchschnitt(noten_liste)
    
    # Schritt 2: Leistungsklasse bestimmen  
    leistungsklasse = bestimme_leistungsklasse(durchschnitt)
    
    # Schritt 3: Ergebnis zusammenfassen
    bewertung = {
        "student": student_name,
        "noten": noten_liste,
        "durchschnitt": round(durchschnitt, 1),
        "kategorie": leistungsklasse
    }
    
    print(f"\n📋 STUDENT BEWERTUNG:")
    print(f"   Student: {bewertung['student']}")
    print(f"   Durchschnitt: {bewertung['durchschnitt']}")
    print(f"   Kategorie: {bewertung['kategorie']}")
    
    return bewertung

# Test mit zwei Studenten - KEINE Duplikation mehr!
anna_noten = [85, 92, 78, 96, 88]
ben_noten = [75, 82, 79, 88, 91]

anna_bewertung = bewerte_student_leistung("Anna", anna_noten)
ben_bewertung = bewerte_student_leistung("Ben", ben_noten)

print(f"\nErgebnis Anna: {anna_bewertung['kategorie']}")
print(f"Ergebnis Ben: {ben_bewertung['kategorie']}")
```

## Zusammenfassung

### Angewendete Best Practices:

**DRY-Prinzip:**
- Wiederholende Berechnungslogik in `berechne_notendurchschnitt()` ausgelagert
- Bewertungslogik in `bestimme_leistungsklasse()` zentralisiert
- Eine Funktion pro Aufgabe (Single Responsibility)

**Aussagekräftige Namen:**
- `berechne_notendurchschnitt()` statt `calc()`
- `noten_liste` statt `d`
- `durchschnittsnote` statt `a`
- `EXCELLENT_THRESHOLD` statt `90`

**Funktionsaufteilung:**
- Berechnung und Bewertung getrennt
- Jede Funktion hat eine klare Aufgabe
- Funktionen sind wiederverwendbar und testbar
