## 💡 RegEx Quick Reference

```python
# Grundlegende Zeichen
\d          # Ziffer (0-9)
\w          # Buchstabe, Ziffer oder _
\s          # Leerzeichen, Tab, Newline
.           # Beliebiges Zeichen (außer Newline)
\b          # Wortgrenze

# Quantifikatoren
+           # 1 oder mehr
*           # 0 oder mehr  
?           # 0 oder 1 (optional)
{n}         # Genau n mal
{n,m}       # Zwischen n und m mal
{n,}        # n oder mehr mal

# Zeichen-Klassen
[abc]       # a oder b oder c
[a-z]       # Kleinbuchstaben
[A-Z]       # Großbuchstaben
[0-9]       # Ziffern (wie \d)
[^abc]      # Alles außer a, b, c

# Anchors
^           # Anfang der Zeile/String
$           # Ende der Zeile/String
\b          # Wortgrenze

# Wichtige re-Funktionen
re.findall(pattern, text)      # Alle Treffer als Liste
re.search(pattern, text)       # Erstes Match-Objekt
re.match(pattern, text)        # Match am String-Anfang
re.sub(pattern, replacement, text)  # Ersetzen
re.split(pattern, text)        # Aufteilen
```
