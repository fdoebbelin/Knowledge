## Aufgabe 1: Persönliche Visitenkarte

```python
# Zelle 1: Daten definieren
name = "Max Mustermann"
beruf = "Python-Entwickler" 
email = "max@beispiel.de"
telefon = "+49 123 456789"

# Visitenkarte erstellen
linie = "=" * 40
print(linie)
print("           VISITENKARTE")
print(linie)
print(f"Name:     {name}")
print(f"Beruf:    {beruf}")
print(f"E-Mail:   {email}")
print(f"Telefon:  {telefon}")
print(linie)
```

**Erklärung:**
- `"=" * 40` erstellt eine Linie mit 40 Gleichheitszeichen
- f-Strings `f"Text {variable}"` fügen Variablen in Text ein
- Mehrere `print()` Befehle für saubere Formatierung
## Aufgabe 2: Datums-Formatter

```python
# Zelle 2: Datum umwandeln
datum_roh = "2024-12-25"
print(f"Ursprüngliches Datum: {datum_roh}")

# Jahr, Monat, Tag mit Slicing herausholen
jahr = datum_roh[0:4]    # Zeichen 0 bis 3
strich = datum_roh[4:5]
monat = datum_roh[5:7]   # Zeichen 5 bis 6  
tag = datum_roh[8:10]    # Zeichen 8 bis 9

print(f"Jahr: {jahr}")
print(f"Strich: {strich}")
print(f"Monat: {monat}")
print(f"Tag: {tag}")

# Monatsnamen definieren
monate = ["", "Januar", "Februar", "März", "April", "Mai", "Juni",
          "Juli", "August", "September", "Oktober", "November", "Dezember"]

# Monat von Text zu Zahl umwandeln
monat_nummer = int(monat)  # "12" wird zu 12
monat_name = monate[monat_nummer]  # 12. Element in der Liste

# Schönes Datum zusammenbauen
schoenes_datum = f"{tag}. {monat_name} {jahr}"
print(f"Formatiertes Datum: {schoenes_datum}")
```

**Erklärung:**
- `datum_roh[0:4]` holt die Zeichen von Position 0 bis 3 (Jahr)
- `int(monat)` wandelt Text "12" in Zahl 12 um
- Liste `monate[12]` gibt "Dezember" zurück (12. Position)
## Aufgabe 3: E-Mail-Validator

```python
# Zelle 3: E-Mail prüfen
email_adressen = [
    "max@gmail.com",
    "anna.schmidt@email.de", 
    "ungueltig-email",
    "test@yahoo.com"
]

print("E-Mail-Validierung:")
print("-" * 30)

# Jede E-Mail-Adresse prüfen
for email in email_adressen:
    # Prüfen ob @ und . enthalten sind
    hat_at = "@" in email
    hat_punkt = "." in email
    
    # Beide Bedingungen müssen erfüllt sein
    if hat_at and hat_punkt:
        print(f"✅ {email} - GÜLTIG")
    else:
        print(f"❌ {email} - UNGÜLTIG")
        
        # Zusätzliche Hinweise geben
        if not hat_at:
            print(f"   → Fehlt: @")
        if not hat_punkt:
            print(f"   → Fehlt: .")
```

**Erklärung:**
- `for email in email_adressen:` geht durch jede E-Mail
- `"@" in email` prüft ob @ im Text enthalten ist
- `and` verknüpft beide Bedingungen
- `if not hat_at:` prüft ob die Bedingung NICHT erfüllt ist
## Aufgabe 4: Text-Verschlüsselung

```python
# Zelle 4: Text verschlüsseln
nachricht = "HALLO WELT"
print(f"Original: {nachricht}")

# Alphabet definieren
alphabet = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"

# Verschlüsselten Text zusammenbauen
verschluesselt = ""

# Jeden Buchstaben einzeln bearbeiten
for buchstabe in nachricht:
    if buchstabe == " ":
        # Leerzeichen bleibt unverändert
        verschluesselt = verschluesselt + " "
    else:
        # Position im Alphabet finden
        position = alphabet.find(buchstabe)
        
        if position != -1:  # Buchstabe gefunden
            # Nächste Position (mit Überlauf vermeiden)
            if position == 25:  # Z ist der letzte Buchstabe
                naechste_position = 0  # Z wird zu A
            else:
                naechste_position = position + 1
            
            # Neuen Buchstaben holen
            neuer_buchstabe = alphabet[naechste_position]
            verschluesselt = verschluesselt + neuer_buchstabe
        else:
            # Unbekanntes Zeichen bleibt unverändert
            verschluesselt = verschluesselt + buchstabe

print(f"Verschlüsselt: {verschluesselt}")

# Bonus: Rückwärts entschlüsseln
print(f"Zur Kontrolle - einen Schritt zurück:")
entschluesselt = ""
for buchstabe in verschluesselt:
    if buchstabe == " ":
        entschluesselt = entschluesselt + " "
    else:
        position = alphabet.find(buchstabe)
        if position != -1:
            if position == 0:  # A ist der erste Buchstabe
                vorherige_position = 25  # A wird zu Z
            else:
                vorherige_position = position - 1
            
            alter_buchstabe = alphabet[vorherige_position]
            entschluesselt = entschluesselt + alter_buchstabe
        else:
            entschluesselt = entschluesselt + buchstabe

print(f"Entschlüsselt: {entschluesselt}")
```

**Erklärung:**
- `for buchstabe in nachricht:` geht durch jeden Buchstaben
- `alphabet.find(buchstabe)` findet die Position (0-25) oder -1 wenn nicht gefunden
- `if position == 25:` behandelt den Sonderfall Z → A
- `verschluesselt = verschluesselt + neuer_buchstabe` baut das Ergebnis auf
## Bonus-Aufgabe: Text-Statistik

```python
# Bonus: Text-Statistik
text = "Python ist eine großartige Programmiersprache für Anfänger"
print(f"Text: {text}")
print("=" * 60)

# Grundlegende Statistiken
anzahl_zeichen = len(text)
woerter = text.split()  # Aufteilen in Wörter
anzahl_woerter = len(woerter)

print(f"Anzahl Zeichen: {anzahl_zeichen}")
print(f"Anzahl Wörter: {anzahl_woerter}")

# Längster und kürzester Wort finden
laengster_wort = ""
kuerzester_wort = woerter[0] if woerter else ""

for wort in woerter:
    # Längster Wort
    if len(wort) > len(laengster_wort):
        laengster_wort = wort
    
    # Kürzester Wort
    if len(wort) < len(kuerzester_wort):
        kuerzester_wort = wort

print(f"Längstes Wort: '{laengster_wort}' ({len(laengster_wort)} Zeichen)")
print(f"Kürzestes Wort: '{kuerzester_wort}' ({len(kuerzester_wort)} Zeichen)")

# Buchstabe "e" zählen
anzahl_e_klein = text.count("e")
anzahl_e_gross = text.count("E") 
anzahl_e_gesamt = anzahl_e_klein + anzahl_e_gross

print(f"Buchstabe 'e': {anzahl_e_klein}x")
print(f"Buchstabe 'E': {anzahl_e_gross}x") 
print(f"Gesamt 'e/E': {anzahl_e_gesamt}x")

# Durchschnittliche Wortlänge
if anzahl_woerter > 0:
    zeichen_in_woertern = sum(len(wort) for wort in woerter)
    durchschnitt = zeichen_in_woertern / anzahl_woerter
    print(f"Durchschnittliche Wortlänge: {durchschnitt:.1f} Zeichen")
```

**Erklärung:**
- `text.split()` teilt Text in Wörter auf (an Leerzeichen)
- `text.count("e")` zählt wie oft "e" vorkommt
- `sum(len(wort) for wort in woerter)` addiert alle Wortlängen
- `:.1f` rundet auf eine Dezimalstelle
## Zusammenfassung der Lösung

### Wichtige String-Operationen verwendet:
