## 💡 Lambda-Funktionen Kurzreferenz

```python
# Grundsyntax
lambda parameter: rückgabewert

# Mit filter() - Elemente auswählen
list(filter(lambda x: x > 5, [1, 6, 3, 8]))  # [6, 8]

# Mit map() - Elemente transformieren  
list(map(lambda x: x * 2, [1, 2, 3]))  # [2, 4, 6]

# Mit sorted() - Elemente sortieren
sorted([{'a': 3}, {'a': 1}], key=lambda x: x['a'])  # [{'a': 1}, {'a': 3}]
```
