## 1.1 Was sind Dictionaries?

Dictionaries sind Sammlungen von **Schlüssel-Wert-Paaren**. Stellen Sie sich ein echtes Wörterbuch vor: Sie schlagen ein Wort (Schlüssel) nach und finden die Bedeutung (Wert).

```python
# Einfaches Dictionary erstellen
person = {
    "name": "Anna Schmidt",
    "alter": 28,
    "beruf": "Entwicklerin",
    "stadt": "Berlin"
}

# Zugriff über Schlüssel
print(f"Name: {person['name']}")        # Anna Schmidt
print(f"Alter: {person['alter']}")      # 28
```

## 1.2 Warum Dictionaries verwenden?

**Vergleich: Liste vs. Dictionary**

```python
# Liste - unübersichtlich
person_liste = ["Anna Schmidt", 28, "Entwicklerin", "Berlin"]
print(f"Name: {person_liste[0]}")  # Was ist Index 0?

# Dictionary - selbsterklärend
person_dict = {
    "name": "Anna Schmidt",
    "alter": 28,
    "beruf": "Entwicklerin", 
    "stadt": "Berlin"
}
print(f"Name: {person_dict['name']}")  # Klar verständlich!
```

**Vorteile von Dictionaries:**
- Schneller Zugriff über aussagekräftige Schlüssel
- Selbstdokumentierender Code
- Einfache Datenmodellierung
- Flexible Struktur

## 1.3 Dictionary erstellen - Verschiedene Methoden

### Methode 1: Direkte Erstellung mit {}

```python
# Am häufigsten verwendet
student = {
    "name": "Max Mustermann",
    "matrikelnummer": "12345",
    "semester": 3,
    "noten": [1.3, 2.0, 1.7]
}
```

### Methode 2: Mit dict() Konstruktor

```python
# Aus Schlüsselwörtern
person = dict(
    name="Lisa", 
    alter=25, 
    stadt="Hamburg"
)
print(person)  # {'name': 'Lisa', 'alter': 25, 'stadt': 'Hamburg'}

# Aus Listen mit zip()
schluessel = ["name", "alter", "beruf"]
werte = ["Tom", 30, "Designer"]
person_neu = dict(zip(schluessel, werte))
print(person_neu)  # {'name': 'Tom', 'alter': 30, 'beruf': 'Designer'}
```

### Methode 3: Leeres Dictionary + schrittweise Befüllung

```python
# Leeres Dictionary erstellen
kontakte = {}

# Schritt für Schritt hinzufügen
kontakte["Anna"] = "anna@email.com"
kontakte["Bob"] = "bob@email.com"
kontakte["Charlie"] = "charlie@email.com"

print(kontakte)
# {'Anna': 'anna@email.com', 'Bob': 'bob@email.com', 'Charlie': 'charlie@email.com'}
```

### Methode 4: Dictionary Comprehensions (für Fortgeschrittene)

```python
# Quadratzahlen von 1 bis 5
quadrate = {x: x**2 for x in range(1, 6)}
print(quadrate)  # {1: 1, 2: 4, 3: 9, 4: 16, 5: 25}

# Wörter und ihre Längen
woerter = ["Python", "ist", "toll"]
wort_laengen = {wort: len(wort) for wort in woerter}
print(wort_laengen)  # {'Python': 6, 'ist': 3, 'toll': 4}
```

## 1.4 Welche Schlüssel sind erlaubt?

```python
# Verschiedene Schlüsseltypen
beispiele = {
    "text": "String als Schlüssel",
    42: "Zahl als Schlüssel", 
    (1, 2): "Tupel als Schlüssel",
    True: "Boolean als Schlüssel"
}

# Listen sind NICHT erlaubt als Schlüssel
try:
    fehler = {[1, 2, 3]: "Liste als Schlüssel"}  # Fehler!
except TypeError as e:
    print(f"Fehler: {e}")
```

**Regel:** Schlüssel müssen **unveränderlich** sein (String, Zahl, Tupel, Boolean).

## 1.5 Sicherer Zugriff mit get()

```python
benutzer = {"name": "Alice", "alter": 25}

# Direkter Zugriff - kann Fehler verursachen
try:
    email = benutzer["email"]  # KeyError!
except KeyError:
    print("Schlüssel 'email' nicht gefunden!")

# Sicherer Zugriff mit get()
name = benutzer.get("name", "Unbekannt")           # "Alice"
email = benutzer.get("email", "Keine Angabe")      # "Keine Angabe" 
telefon = benutzer.get("telefon")                  # None

print(f"Name: {name}")
print(f"Email: {email}")
print(f"Telefon: {telefon}")
```

## 1.6 Verschachtelte Dictionaries

```python
# Komplexere Datenstrukturen
firma = {
    "name": "TechCorp",
    "mitarbeiter": {
        "entwicklung": {
            "leiter": "Dr. Schmidt",
            "anzahl": 15
        },
        "marketing": {
            "leiter": "Frau Müller", 
            "anzahl": 8
        }
    },
    "standorte": ["Berlin", "Hamburg", "München"]
}

# Zugriff auf verschachtelte Daten
print(f"Firma: {firma['name']}")
print(f"Entwicklungsleiter: {firma['mitarbeiter']['entwicklung']['leiter']}")
print(f"Standorte: {', '.join(firma['standorte'])}")
```

## 1.7 Praktisches Beispiel: Produktkatalog

```python
# Einfacher Produktkatalog
produkte = {
    "P001": {
        "name": "Laptop",
        "preis": 999.99,
        "auf_lager": True
    },
    "P002": {
        "name": "Maus", 
        "preis": 25.99,
        "auf_lager": False
    },
    "P003": {
        "name": "Tastatur",
        "preis": 79.99,
        "auf_lager": True
    }
}

# Produkte anzeigen
print("=== Produktkatalog ===")
for produkt_id, details in produkte.items():
    status = "✅ Verfügbar" if details["auf_lager"] else "❌ Ausverkauft"
    print(f"{produkt_id}: {details['name']} - {details['preis']}€ {status}")

# Durchschnittspreis berechnen
preise = [produkt["preis"] for produkt in produkte.values()]
durchschnitt = sum(preise) / len(preise)
print(f"\nDurchschnittspreis: {durchschnitt:.2f}€")
```

## 1.8 Wann welche Datenstruktur verwenden?

| Datenstruktur | Verwenden wenn... | Beispiel |
|---------------|-------------------|----------|
| **Liste** | Reihenfolge wichtig, numerische Indizes | `[1, 2, 3, 4]` |
| **Tupel** | Unveränderliche Daten | `(x, y, z)` Koordinaten |
| **Dictionary** | Daten haben natürliche Bezeichner | `{"name": "Anna", "alter": 25}` |

```python
# Beispiele für die richtige Wahl:

# Liste: Einkaufsliste (Reihenfolge wichtig)
einkaufen = ["Milch", "Brot", "Eier"]

# Tupel: GPS-Koordinaten (unveränderlich)
position = (52.5200, 13.4050)  # Berlin

# Dictionary: Personendaten (benannte Eigenschaften)
person = {"name": "Anna", "alter": 25, "stadt": "Berlin"}
```
