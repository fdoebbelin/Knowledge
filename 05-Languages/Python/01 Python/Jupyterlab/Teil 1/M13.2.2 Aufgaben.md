## Aufgaben

### Aufgabe 1: Benutzername-Validator

Erstellen Sie ein Programm, das Benutzernamen auf Gültigkeit prüft.

**Was Sie tun sollen:**
```python
# Zelle 1: Benutzername validieren
benutzernamen = [
    "max_müller",
    "Anna123",
    "123invalid", 
    "user@domain.com",
    "valid_user",
    "",
    "ab"
]

# TODO: Prüfen Sie jeden Benutzernamen auf:
# - Mindestens 3 Zeichen lang
# - Beginnt mit einem Buchstaben
# - Enthält nur Buchstaben, Zahlen und Unterstrich
# - Keine Leerzeichen oder andere Sonderzeichen
```

**💡 Lösungshinweise:**
- `len(text)` gibt die Länge zurück
- `text[0].isalpha()` prüft ob erstes Zeichen ein Buchstabe ist
- `text.replace("_", "").isalnum()` prüft ob nur Buchstaben/Zahlen (nach Entfernung der Unterstriche)
- Verwenden Sie if-Bedingungen für jede Regel

**Erwartete Ausgabe:**
```
max_müller: ❌ Enthält ungültige Zeichen
Anna123: ✅ Gültig
123invalid: ❌ Beginnt nicht mit Buchstaben
...
```

### Aufgabe 3: Passwort-Stärke-Checker

Bewerten Sie die Stärke von Passwörtern.

**Was Sie tun sollen:**
```python

    "123456",
    "passwort",
    "Passwort123",
    "SicheresPasswort!123",
    "abc",
    "MeinSuperSicheresPasswort2024!"

# TODO: Bewerten Sie jedes Passwort nach diesen Kriterien:
# - Mindestens 8 Zeichen = 1 Punkt
# - Enthält Großbuchstaben = 1 Punkt  
# - Enthält Kleinbuchstaben = 1 Punkt
# - Enthält Zahlen = 1 Punkt
```

**💡 Lösungshinweise:**

## 💡 Hilfreiche String-Methoden

```python
# Für die Aufgaben nützlich:

# Text-Eigenschaften prüfen
text.isalpha()      # Nur Buchstaben?
text.isdigit()      # Nur Zahlen?
text.isalnum()      # Buchstaben + Zahlen?
text.isupper()      # Großbuchstaben?
text.islower()      # Kleinbuchstaben?

# Text bearbeiten
text.strip()        # Leerzeichen entfernen
text.upper()        # Zu Großbuchstaben
text.lower()        # Zu Kleinbuchstaben
text.replace(alt, neu)  # Text ersetzen

# Text suchen
text.find(substring)    # Position finden (-1 wenn nicht gefunden)
text.startswith(prefix) # Beginnt mit...?
text.endswith(suffix)   # Endet mit...?
text.count(substring)   # Wie oft kommt vor?

# Text aufteilen/verbinden
text.split(separator)   # Aufteilen
separator.join(liste)   # Verbinden

# Generator Expressions für Prüfungen
any(bedingung for item in liste)  # Mindestens eins erfüllt?
all(bedingung for item in liste)  # Alle erfüllen?
```
