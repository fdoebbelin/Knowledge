## 💡 Lösungshinweise

### DRY-Prinzip anwenden:
- Wiederholende if-else Logik in Funktionen auslagern
- Gemeinsame Datenstrukturen (Listen/Dictionaries) verwenden
- Schleifen statt Copy-Paste von ähnlichem Code

### Aussagekräftige Namen:
- `berechne_endpreis()` statt `calc_price()`
- `artikelpreis` statt `p`
- `bestellmenge` statt `q`
- `MINDESTBESTAND` statt `100`

### Funktionsaufteilung:
- Eine Funktion = eine Aufgabe
- Berechnungen von Ausgaben trennen
- Parameter klar definieren
