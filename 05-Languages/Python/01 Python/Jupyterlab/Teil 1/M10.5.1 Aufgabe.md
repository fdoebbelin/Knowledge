# M10 Übung 5: Dateigrößen-Rechner - Aufgabenstellung

## 🎯 Lernziel
In dieser Übung lernen Sie rekursive Funktionen zu entwickeln, die hierarchische Datenstrukturen verarbeiten können. Sie implementieren einen Dateigrößen-Rechner, der die Gesamtgröße von verschachtelten Ordnerstrukturen berechnet.

## 📋 Problemstellung
Entwickeln Sie eine rekursive Funktion `berechne_ordner_groesse()`, die die Gesamtgröße einer Ordnerstruktur berechnet. Die Ordnerstruktur wird als verschachteltes Dictionary dargestellt, das sowohl Dateien als auch Unterordner enthalten kann.

## 📊 Beispieldaten

```python
# Ordnerstruktur als Dictionary
# - "dateien": Liste mit Dateigrößen in KB
# - "unterordner": Dictionary mit weiteren Ordnerstrukturen
ordner_struktur = {
    "dateien": [150, 300, 75],  # 3 Dateien mit 150KB, 300KB, 75KB
    "unterordner": {
        "dokumente": {
            "dateien": [200, 450, 120, 80],
            "unterordner": {
                "archiv": {
                    "dateien": [1000, 2500],
                    "unterordner": {}
                }
            }
        },
        "bilder": {
            "dateien": [800, 1200, 950],
            "unterordner": {
                "urlaub_2024": {
                    "dateien": [1500, 1300, 1800, 1100],
                    "unterordner": {}
                }
            }
        },
        "videos": {
            "dateien": [5000, 7500, 3200],
            "unterordner": {}
        }
    }
}
```

## 🎯 Erwartete Ausgabe
Ihre Funktion soll die Gesamtgröße aller Dateien in der Ordnerstruktur zurückgeben:

```
Gesamtgröße der Ordnerstruktur: 28,370 KB (27.7 MB)

Detailierte Auflistung:
- Hauptordner: 525 KB
  - Dateien: 525 KB (150 + 300 + 75)
  
- Unterordner "dokumente": 4,350 KB
  - Dateien: 850 KB (200 + 450 + 120 + 80)
  - Archiv: 3,500 KB (1000 + 2500)
  
- Unterordner "bilder": 8,795 KB
  - Dateien: 2,950 KB (800 + 1200 + 950)
  - Urlaub_2024: 5,700 KB (1500 + 1300 + 1800 + 1100)
  
- Unterordner "videos": 15,700 KB
  - Dateien: 15,700 KB (5000 + 7500 + 3200)
```

## 🛠️ Aufgabenteile

### Teil 1: Basis-Rekursionsfunktion
Implementieren Sie die Grundfunktion `berechne_ordner_groesse(ordner_struktur)`:
- **Basisfall**: Wenn keine Unterordner vorhanden sind
- **Rekursiver Fall**: Berechnung für alle Unterordner
- **Rückgabe**: Gesamtgröße in KB

### Teil 2: Erweiterte Ausgabefunktion
Entwickeln Sie `zeige_ordner_details(ordner_struktur, ordner_name="Hauptordner", tiefe=0)`:
- Hierarchische Anzeige der Ordnerstruktur
- Einrückung entsprechend der Verschachtelungstiefe
- Anzeige von Einzelgrößen und Gesamtsummen

### Teil 3: Formatierungshilfen
Erstellen Sie Hilfsfunktionen:
- `kb_zu_mb(kb_wert)`: Konvertierung KB zu MB
- `formatiere_groesse(kb_wert)`: Benutzerfreundliche Größenanzeige
