## Was ist SQL?

SQL (Structured Query Language) ist eine standardisierte Sprache zur Verwaltung und Abfrage von relationalen Datenbanken. Sie ermöglicht es, Daten zu erstellen, zu lesen, zu aktualisieren und zu löschen (CRUD-Operationen).

## Die wichtigsten SQL-Befehlskategorien

### 1. DDL (Data Definition Language) - Strukturbefehle

**CREATE TABLE** - Erstellt eine neue Tabelle
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    name TEXT NOT NULL,
    email TEXT UNIQUE,
    age INTEGER
);
```

**ALTER TABLE** - Ändert die Struktur einer Tabelle
```sql
ALTER TABLE users ADD COLUMN phone TEXT;
ALTER TABLE users DROP COLUMN age;
```

**DROP TABLE** - Löscht eine Tabelle komplett
```sql
DROP TABLE users;
```

### 2. DML (Data Manipulation Language) - Datenbefehle

**INSERT** - Fügt neue Datensätze ein
```sql
-- Einzelner Datensatz
INSERT INTO users (name, email, age) 
VALUES ('Max Mustermann', 'max@example.com', 25);

-- Mehrere Datensätze
INSERT INTO users (name, email, age) VALUES 
    ('Anna Schmidt', 'anna@example.com', 30),
    ('Tom Weber', 'tom@example.com', 22);
```

**UPDATE** - Ändert bestehende Datensätze
```sql
UPDATE users 
SET age = 26, email = 'max.neu@example.com' 
WHERE name = 'Max Mustermann';
```

**DELETE** - Löscht Datensätze
```sql
DELETE FROM users WHERE age < 18;
DELETE FROM users; -- Löscht alle Datensätze
```

### 3. DQL (Data Query Language) - Abfragebefehle

**SELECT** - Grundlegende Abfrage
```sql
-- Alle Spalten, alle Zeilen
SELECT * FROM users;

-- Bestimmte Spalten
SELECT name, email FROM users;

-- Mit Bedingung
SELECT * FROM users WHERE age > 25;
```

**WHERE** - Filterbedingungen
```sql
SELECT * FROM users WHERE age BETWEEN 20 AND 30;
SELECT * FROM users WHERE name LIKE 'M%';  -- Namen die mit M beginnen
SELECT * FROM users WHERE email IS NOT NULL;
```

**ORDER BY** - Sortierung
```sql
SELECT * FROM users ORDER BY age ASC;  -- Aufsteigend
SELECT * FROM users ORDER BY name DESC; -- Absteigend
```

**LIMIT** - Anzahl der Ergebnisse begrenzen
```sql
SELECT * FROM users LIMIT 5;
SELECT * FROM users LIMIT 5 OFFSET 10; -- Überspringe die ersten 10
```

### 4. Aggregatfunktionen

```sql
SELECT COUNT(*) FROM users;           -- Anzahl Datensätze
SELECT AVG(age) FROM users;           -- Durchschnittsalter
SELECT MIN(age), MAX(age) FROM users; -- Minimum und Maximum
SELECT SUM(age) FROM users;           -- Summe aller Alter
```

**GROUP BY** - Gruppierung mit Aggregation
```sql
SELECT age, COUNT(*) as anzahl 
FROM users 
GROUP BY age;

SELECT age, COUNT(*) as anzahl 
FROM users 
GROUP BY age 
HAVING COUNT(*) > 1; -- HAVING für Gruppenbedingungen
```

### 5. Joins - Tabellen verknüpfen

```sql
-- INNER JOIN - nur übereinstimmende Datensätze
SELECT users.name, orders.product 
FROM users 
INNER JOIN orders ON users.id = orders.user_id;

-- LEFT JOIN - alle Datensätze der linken Tabelle
SELECT users.name, orders.product 
FROM users 
LEFT JOIN orders ON users.id = orders.user_id;
```

## Wichtige Datentypen in SQLite

- **INTEGER** - Ganze Zahlen
- **REAL** - Fließkommazahlen
- **TEXT** - Textstrings
- **BLOB** - Binäre Daten
- **NULL** - Leerer Wert

## Constraints (Einschränkungen)

- **PRIMARY KEY** - Eindeutiger Schlüssel
- **UNIQUE** - Eindeutige Werte
- **NOT NULL** - Darf nicht leer sein
- **DEFAULT** - Standardwert
- **CHECK** - Bedingung prüfen
- **FOREIGN KEY** - Verweis auf andere Tabelle

## Nützliche SQLite-spezifische Befehle

```sql
.tables                 -- Zeigt alle Tabellen
.schema tablename       -- Zeigt Tabellenstruktur
.mode column           -- Spaltenformatierung
.headers on            -- Spaltennamen anzeigen
.quit                  -- SQLite beenden
```

## Tipps für Anfänger

1. **Immer Semikolon verwenden** - Jeder SQL-Befehl endet mit `;`
2. **Groß-/Kleinschreibung** - SQL-Schlüsselwörter traditionell GROSS, aber nicht zwingend
3. **Anführungszeichen** - Strings in einfache Anführungszeichen `'text'`
4. **Kommentare** - Einzeilig mit `--`, mehrzeilig mit `/* */`
5. **WHERE-Klausel bei UPDATE/DELETE** - Immer prüfen, sonst werden alle Datensätze geändert!

## Häufige Fehler vermeiden

- **Vergessene WHERE-Klausel** bei UPDATE/DELETE
- **Falsche Anführungszeichen** für Strings
- **Vergessenes Semikolon** am Ende
- **Tabellenname falsch geschrieben**
- **Spaltenname existiert nicht**
