## 🎯 Lernziel
In dieser Übung lernen Sie die LEGB-Regel (Local, Enclosing, Global, Built-in) kennen und verstehen, wie Closures funktionieren. Sie erstellen verschiedene Zähler-Funktionen, die ihren Zustand zwischen Funktionsaufrufen bewahren können - ohne globale Variablen zu verwenden.

## 📋 Problemstellung
Entwickeln Sie eine Factory-Funktion `erstelle_zaehler()`, die individuell konfigurierbare Zähler-Funktionen erstellt. Jeder Zähler soll seinen eigenen privaten Zustand haben und verschiedene Operationen unterstützen. Die Lösung soll das Konzept der Closures nutzen, um Zustandserhaltung ohne globale Variablen zu ermöglichen.

## 🔧 Anforderungen

### Basis-Zähler
Der Basis-Zähler soll folgende Funktionalitäten bieten:
- **Hochzählen**: Wert um 1 oder um angegebenen Schritt erhöhen
- **Runterzählen**: Wert um 1 oder um angegebenen Schritt verringern
- **Aktueller Wert**: Den aktuellen Zählerstand abfragen
- **Zurücksetzen**: Zähler auf Startwert zurücksetzen

### Erweiterte Zähler (Bonus)
- **Bereichs-Zähler**: Mit Minimum und Maximum-Grenzen
- **Zyklischer Zähler**: Bei Erreichen der Grenze wieder von vorn beginnen
- **Statistik-Zähler**: Zusätzlich Minimum, Maximum und Durchschnitt tracken

## 📊 Beispieldaten und erwartete Ausgabe

```python
# Basis-Zähler erstellen

print(f"Zähler 2: {zaehler2('wert')}")              # 80

print(f"Zähler 1 reset: {zaehler1('wert')}")        # 0

# Erweiterte Zähler
bereichs_zaehler = erstelle_bereichs_zaehler(start=5, minimum=0, maximum=10)
print(f"Bereichs-Zähler: {bereichs_zaehler('wert')}")    # 5

bereichs_zaehler('hoch', 8)  # Versucht +8, aber Maximum ist 10
print(f"Nach +8: {bereichs_zaehler('wert')}")            # 10 (begrenzt)

# Zyklischer Zähler
zyklus_zaehler = erstelle_zyklus_zaehler(start=8, minimum=0, maximum=9)
zyklus_zaehler('hoch', 3)    # 8+3=11, aber zyklisch → 1
print(f"Zyklischer Zähler: {zyklus_zaehler('wert')}")    # 1
```

## 💡 Lösungshinweise

### Schritt 1: Closures-Grundprinzip verstehen
```python
# Eine Closure ist eine Funktion, die:
# 1. In einer anderen Funktion definiert ist
# 2. Auf Variablen der umschließenden Funktion zugreift
# 3. Diese Variablen "einschließt" auch nach Beendigung der äußeren Funktion

def erstelle_einfachen_zaehler():
    zaehlerstand = 0  # Diese Variable wird "eingeschlossen"
    
    def zaehlen():
        nonlocal zaehlerstand  # Zugriff auf umschließende Variable
        zaehlerstand += 1
        return zaehlerstand
    
    return zaehlen  # Rückgabe der inneren Funktion
```

### Schritt 2: `nonlocal` Schlüsselwort verwenden
```python
# nonlocal ermöglicht Schreibzugriff auf Variablen im umschließenden Scope
def outer():
    x = 10
    
    def inner():
        nonlocal x  # Ohne nonlocal: UnboundLocalError
        x += 1      # Mit nonlocal: Modifikation möglich
        return x
    
    return inner
```

## 🔍 Test- und Verifikationsschritte

### Testfall 1: Unabhängige Zähler
```python
# Zwei Zähler sollten unabhängig voneinander funktionieren
zaehler_a = erstelle_zaehler(0)
zaehler_b = erstelle_zaehler(100)

zaehler_a('hoch', 5)
zaehler_b('runter', 10)

assert zaehler_a('wert') == 5
assert zaehler_b('wert') == 90
print("✅ Unabhängigkeitstest bestanden")
```

### Testfall 2: Zustandserhaltung
```python
# Zähler soll Zustand zwischen Aufrufen bewahren
zaehler = erstelle_zaehler(0)

for i in range(10):
    zaehler('hoch')

assert zaehler('wert') == 10
print("✅ Zustandserhaltung funktioniert")
```
