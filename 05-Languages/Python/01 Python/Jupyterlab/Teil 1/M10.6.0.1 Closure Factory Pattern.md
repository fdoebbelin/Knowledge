## Was ist das Closure Factory Pattern?

Das **Closure Factory Pattern** ist ein Entwurfsmuster, bei dem eine "Fabrik-Funktion" spezialisierte Funktionen erstellt, die sich an bestimmte Parameter "erinnern". Diese erstellten Funktionen sind **Closures** - sie behalten Zugriff auf Variablen aus ihrem ursprünglichen Erstellungskontext.

## Grundkonzept

```python
def factory_funktion(parameter):
    def innere_funktion(argument):
        # Kann auf 'parameter' zugreifen (Closure!)
        return parameter + argument  # Beispiel
    return innere_funktion
```
## Schritt 1: Einfache Potenz-Funktionen (Grundlagen)

**Zelle 1 - Potenz-Factory:**
```python
def erstelle_potenz_funktion(exponent):
    """
    Factory-Funktion: Erstellt eine Potenz-Funktion mit festem Exponenten.
    
    Args:
        exponent: Der feste Exponent für die Potenzierung
    
    Returns:
        Lambda-Funktion, die x^exponent berechnet
    """
    return lambda x: x ** exponent
```

**Zelle 2 - Potenz-Funktionen testen:**
```python
# Demonstration
print("=== Potenz-Funktionen Factory ===")

# Verschiedene Potenz-Funktionen erstellen
quadrat = erstelle_potenz_funktion(2)    # x²

vierte_potenz = erstelle_potenz_funktion(4)  # x⁴# Die erstellten Funktionen verwenden
test_werte = [2, 3, 4, 5]

print("Potenz-Funktionen im Einsatz:")
print("x\t| x²\t| x³\t| x⁴")
print("-" * 32)

    print(f"{x}\t| {quadrat(x)}\t| {kubik(x)}\t| {vierte_potenz(x)}")

print(f"\nDie Quadrat-Funktion 'weiß' dass ihr Exponent 2 ist")
print(f"quadrat(10) = {quadrat(10)}")
```
## Schritt 2: Polynom-Funktionen (Erweitert)

**Zelle 3 - Polynom-Factory:**
```python
def erstelle_polynom(koeffizienten):
    """
    Erstellt eine Polynomfunktion aus Koeffizienten.
    
    Polynom: a₀ + a₁x + a₂x² + a₃x³ + ...
    
    Args:
        koeffizienten: Liste [a₀, a₁, a₂, ...] der Koeffizienten
    
    Returns:
        Polynom-Funktion mit zusätzlichen Attributen
    """
    def polynom(x):
        result = 0
        for i, koeff in enumerate(koeffizienten):
            result += koeff * (x ** i)
        return result
    
    # Zusätzliche Informationen an die Funktion anhängen
    polynom.koeffizienten = koeffizienten
    polynom.grad = len(koeffizienten) - 1
    
    return polynom
```

**Zelle 4 - Polynom-Funktionen testen:**
```python
# Beispiel-Polynome erstellen
print("=== Polynom-Funktionen Factory ===")

print(f"Polynom 1 Koeffizienten: {polynom1.koeffizienten}")
```

## Schritt 3: Intervall-beschränkte Funktionen (Fortgeschritten)

**Zelle 5 - Intervall-Factory:**
```python
def erstelle_intervall_funktion(func, min_x, max_x):
    """
    Wrapper-Factory: Beschränkt eine Funktion auf ein bestimmtes Intervall.
    
    Args:
        func: Die ursprüngliche Funktion
        min_x: Minimaler x-Wert
        max_x: Maximaler x-Wert
    
    Returns:
        Wrapper-Funktion, die Intervall-Checks durchführt
    """
    def bounded_func(x):
        # Intervall-Check
        if not (min_x <= x <= max_x):
            raise ValueError(f"x={x} außerhalb des Intervalls [{min_x}, {max_x}]")
        
        # Original-Funktion aufrufen (Closure über func!)
        return func(x)
    
    # Metadaten anhängen
    bounded_func.intervall = (min_x, max_x)
    bounded_func.original = func
    
    return bounded_func

# Beispiele mit mathematischen Funktionen
import math

print("=== Intervall-beschränkte Funktionen ===")

# Sinus auf [-π, π] beschränken
sinus_eingeschränkt = erstelle_intervall_funktion(math.sin, -math.pi, math.pi)

# Quadratwurzel auf [0, 100] beschränken  
sqrt_eingeschränkt = erstelle_intervall_funktion(math.sqrt, 0, 100)

# Eigene Funktion einschränken
quadrat_0_bis_10 = erstelle_intervall_funktion(lambda x: x**2, 0, 10)

print(f"Sinus-Intervall: {sinus_eingeschränkt.intervall}")
print(f"Sqrt-Intervall: {sqrt_eingeschränkt.intervall}")
print(f"Quadrat-Intervall: {quadrat_0_bis_10.intervall}")
```

**Zelle 6 - Intervall-Funktionen testen:**
```python
# Gültige Aufrufe
print("Gültige Funktionsaufrufe:")
print(f"sin(π/2) = {sinus_eingeschränkt(math.pi/2):.3f}")
print(f"sin(-π/4) = {sinus_eingeschränkt(-math.pi/4):.3f}")
print(f"sqrt(25) = {sqrt_eingeschränkt(25)}")

# Ungültige Aufrufe (Fehlerbehandlung)
print("\nTest von Intervall-Verletzungen:")

test_cases = [
    (sinus_eingeschränkt, 2*math.pi, "sin(2π)"),
    (sqrt_eingeschränkt, -5, "sqrt(-5)"),
    (quadrat_0_bis_10, 15, "quadrat(15)")
]

for func, value, description in test_cases:
    try:
        result = func(value)
        print(f"✓ {description} = {result}")
    except ValueError as e:
        print(f"✗ {description}: {e}")
```
## Schritt 4: Vollständige Factory (Integration)

**Zelle 7 - Komplette Mathematics Factory:**
```python
def erstelle_mathematik_funktionen():
    """
    Vollständige Factory für mathematische Funktionen.
    Kombiniert alle vorherigen Konzepte in einer einzigen Factory.
    
    Returns:
        Dictionary mit verschiedenen Factory-Funktionen
    """
    
    def erstelle_potenz_funktion(exponent):
        return lambda x: x ** exponent
    
    def erstelle_polynom(koeffizienten):
        def polynom(x):
            result = 0
            for i, koeff in enumerate(koeffizienten):
                result += koeff * (x ** i)
            return result
        
        polynom.koeffizienten = koeffizienten
        polynom.grad = len(koeffizienten) - 1
        return polynom
    
    def erstelle_intervall_funktion(func, min_x, max_x):
        def bounded_func(x):
            if not (min_x <= x <= max_x):
                raise ValueError(f"x={x} außerhalb des Intervalls [{min_x}, {max_x}]")
            return func(x)
        
        bounded_func.intervall = (min_x, max_x)
        bounded_func.original = func
        return bounded_func
    
    # Factory-Interface zurückgeben
    return {
        "potenz": erstelle_potenz_funktion,
        "polynom": erstelle_polynom,
        "intervall": erstelle_intervall_funktion
    }

# Factory erstellen
math_factory = erstelle_mathematik_funktionen()

print("Verfügbare Factory-Methoden:")
for key in math_factory.keys():
    print(f"  - {key}")
```

**Zelle 8 - Integrationstest:**
```python
# Komplexes Beispiel: Kombinierte Verwendung
print("=== Integrationstest ===")

# 1. Polynom erstellen
polynom = math_factory["polynom"]([1, -2, 1])  # x² - 2x + 1 = (x-1)²

# 2. Polynom auf Intervall beschränken
polynom_beschränkt = math_factory["intervall"](polynom, -5, 5)

# 3. Potenz-Funktion für Vergleich
quadrat = math_factory["potenz"](2)

print("Vergleich: (x-1)² vs x²")
print("x\t| (x-1)²\t| x²\t| Differenz")
print("-" * 40)

for x in range(-2, 4):
    try:
        p_wert = polynom_beschränkt(x)
        q_wert = quadrat(x)
        diff = abs(p_wert - q_wert)
        print(f"{x}\t| {p_wert}\t| {q_wert}\t| {diff}")
    except ValueError as e:
        print(f"{x}\t| Fehler: {e}")

# 4. Spezialisierte Funktionen aus der Factory
kubikwurzel = math_factory["potenz"](1/3)
print(f"\nKubikwurzel von 27: {kubikwurzel(27):.3f}")
```
## Warum ist das Factory Pattern nützlich?

**Zelle 9 - Vorteile demonstrieren:**
```python
print("=== Vorteile des Closure Factory Patterns ===")

# Vorteil 1: Code-Wiederverwendung
print("1. Code-Wiederverwendung:")
factories_demo = {
    "Verschiedene Potenzen": [math_factory["potenz"](i) for i in range(2, 6)],
    "Verschiedene Polynome": [
        math_factory["polynom"]([1, 1]),      # x + 1
        math_factory["polynom"]([0, 0, 1]),   # x²
        math_factory["polynom"]([1, 0, 1])    # x² + 1
    ]
}

for category, functions in factories_demo.items():
    print(f"  {category}: {len(functions)} Funktionen erstellt")

# Vorteil 2: Konfiguration zur Laufzeit
print("\n2. Dynamische Konfiguration:")
user_configs = [
    {"exponent": 3, "beschreibung": "Kubik"},
    {"exponent": 4, "beschreibung": "Vierte Potenz"},
    {"exponent": 0.5, "beschreibung": "Quadratwurzel"}
]

runtime_functions = {}
for config in user_configs:
    func_name = config["beschreibung"].lower().replace(" ", "_")
    runtime_functions[func_name] = math_factory["potenz"](config["exponent"])

for name, func in runtime_functions.items():
    print(f"  {name}(8) = {func(8):.3f}")

# Vorteil 3: Zustandskapselung
print("\n3. Zustandskapselung:")
print("  Jede Funktion 'erinnert' sich an ihre Konfiguration")
print("  Keine globalen Variablen nötig")
print("  Funktionen sind unabhängig voneinander")
```

## Zusammenfassung

Das **Closure Factory Pattern** ermöglicht es:

1. **Spezialisierte Funktionen** zur Laufzeit zu erstellen
2. **Konfigurationen zu kapseln** ohne globale Variablen
3. **Code wiederzuverwenden** durch parametrisierte Factories
4. **Komplexe Funktionen** aus einfachen Bausteinen zu komponieren

Die Closures "erinnern" sich an die Parameter ihrer Erstellung und bieten so eine elegante Lösung für viele Programmierprobleme.
