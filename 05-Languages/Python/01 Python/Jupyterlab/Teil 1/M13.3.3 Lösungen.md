## Aufgabe 1: Persönlicher Datenreport

```python
# Zelle 1: Persönlicher Datenreport
person_daten = {
    "name": "Max Mustermann",
    "alter": 28,
    "gehalt": 3750.80,
    "arbeitszeit": 0.8,  # 80% Stelle
    "urlaub_tage": 25,
    "verbrauchte_urlaub_tage": 18
}

# Berechnungen durchführen
jahresgehalt = person_daten["gehalt"] * 12
arbeitszeit_prozent = person_daten["arbeitszeit"] * 100
verbleibende_urlaub_tage = person_daten["urlaub_tage"] - person_daten["verbrauchte_urlaub_tage"]

# Report erstellen
print("PERSONAL-DATENREPORT")
print("=" * 20)
print(f"Name: {person_daten['name']}")
print(f"Alter: {person_daten['alter']} Jahre")
print(f"Monatsgehalt: {person_daten['gehalt']:.2f} €")
print(f"Jahresgehalt: {jahresgehalt:,.2f} €")
print(f"Arbeitszeit: {arbeitszeit_prozent:.0f}%")
print(f"Urlaubstage: {verbleibende_urlaub_tage} von {person_daten['urlaub_tage']} Tagen verbleibend")

# Alternative: Kompakter mit direkten Berechnungen in f-Strings
print("\n--- Alternative Darstellung ---")
print(f"""
PERSONAL-DATENREPORT
====================
Name: {person_daten['name']}
Alter: {person_daten['alter']} Jahre
Monatsgehalt: {person_daten['gehalt']:.2f} €
Jahresgehalt: {person_daten['gehalt'] * 12:,.2f} €
Arbeitszeit: {person_daten['arbeitszeit']:.0%}
Urlaubstage: {person_daten['urlaub_tage'] - person_daten['verbrauchte_urlaub_tage']} von {person_daten['urlaub_tage']} Tagen verbleibend
""".strip())
```

**Erklärung:**
- `{betrag:.2f}` zeigt Zahlen mit genau 2 Nachkommastellen
- `{betrag:,.2f}` fügt Tausender-Kommas hinzu (im englischen Format)
- `{prozent:.0%}` wandelt Dezimalzahl in Prozent um (0.8 → 80%)
- Berechnungen können direkt in f-Strings gemacht werden
## Aufgabe 2: Kassensystem

```python
# Zelle 2: Kassensystem
artikel_liste = [
    ("Apfel", 2.5, 1.20),      # (Name, Menge, Preis pro Einheit)
    ("Brot", 1, 2.80),
    ("Milch", 3, 1.15),
    ("Käse", 0.3, 12.50),
    ("Bananen", 1.2, 2.30)
]

mehrwertsteuer = 0.19  # 19%

print("KASSENZETTEL")
print("=" * 60)
print("Artikel      Menge   Einzelpreis  Gesamtpreis")
print("-" * 60)

# Für Gesamtrechnung
zwischensumme = 0

for artikel, menge, preis_pro_einheit in artikel_liste:
    gesamtpreis_artikel = menge * preis_pro_einheit
    zwischensumme += gesamtpreis_artikel
    
    # Schön formatierte Tabellenzeile
    print(f"{artikel:<12} {menge:>5.1f}x {preis_pro_einheit:>8.2f} € {gesamtpreis_artikel:>10.2f} €")

# Abrechnung
mwst_betrag = zwischensumme * mehrwertsteuer
endsumme = zwischensumme + mwst_betrag

print("-" * 60)
print(f"Zwischensumme (netto)          {zwischensumme:>10.2f} €")
print(f"MwSt ({mehrwertsteuer:.0%})                      {mwst_betrag:>10.2f} €")
print("=" * 60)
print(f"ENDSUMME (brutto)              {endsumme:>10.2f} €")

# Zusätzliche Informationen
print(f"\nSie sparen heute: {mwst_betrag:.2f} € bei MwSt-freiem Einkauf")
print(f"Anzahl verschiedener Artikel: {len(artikel_liste)}")

# Detailanalyse
teuerster_artikel = max(artikel_liste, key=lambda x: x[1] * x[2])
print(f"Teuerster Posten: {teuerster_artikel[0]} ({teuerster_artikel[1] * teuerster_artikel[2]:.2f} €)")
```

**Erklärung:**
- `{text:<12}` richtet Text linksbündig in 12 Zeichen aus
- `{zahl:>8.2f}` richtet Zahlen rechtsbündig aus (8 Zeichen breit, 2 Nachkommastellen)
- `{prozent:.0%}` zeigt Prozent ohne Nachkommastellen (0.19 → 19%)
- `max()` mit `key=lambda` findet teuersten Artikel
## Aufgabe 3: Notenübersicht

```python
# Zelle 3: Notenübersicht
schueler_noten = [
    ("Anna Schmidt", [1.3, 2.0, 1.7, 2.3, 1.0]),
    ("Bob Mueller", [2.7, 3.0, 2.3, 2.0, 2.7]),
    ("Charlie Weber", [1.0, 1.3, 1.7, 1.3, 2.0]),
    ("Diana Fischer", [3.3, 2.7, 3.0, 2.3, 3.7])
]

def bewerte_durchschnitt(durchschnitt):
    """Wandelt Notendurchschnitt in Bewertung um"""
    if durchschnitt <= 1.5:
        return "Sehr gut"
    elif durchschnitt <= 2.5:
        return "Gut"
    elif durchschnitt <= 3.5:
        return "Befriedigend"
    else:
        return "Ausreichend"

print("NOTENÜBERSICHT")
print("=" * 70)
print("Schüler          Noten           Ø     Bewertung    Beste  Schlechteste")
print("-" * 70)

# Für Gesamtstatistik
alle_durchschnitte = []

for name, noten in schueler_noten:
    # Berechnungen
    durchschnitt = sum(noten) / len(noten)
    bewertung = bewerte_durchschnitt(durchschnitt)
    beste_note = min(noten)
    schlechteste_note = max(noten)
    
    # Noten als String formatieren
    noten_text = ", ".join(f"{note:.1f}" for note in noten)
    
    # Tabellenzeile ausgeben
    print(f"{name:<15} {noten_text:<15} {durchschnitt:>4.2f}  {bewertung:<12} {beste_note:>4.1f}   {schlechteste_note:>10.1f}")
    
    alle_durchschnitte.append(durchschnitt)

# Klassenstatistik
klassen_durchschnitt = sum(alle_durchschnitte) / len(alle_durchschnitte)
bester_schueler = min(alle_durchschnitte)
schlechtester_schueler = max(alle_durchschnitte)

print("-" * 70)
print("KLASSENSTATISTIK:")
print(f"Klassendurchschnitt: {klassen_durchschnitt:.2f} ({bewerte_durchschnitt(klassen_durchschnitt)})")
print(f"Bester Schüler: {bester_schueler:.2f}")
print(f"Schlechtester Schüler: {schlechtester_schueler:.2f}")
print(f"Notenspanne: {schlechtester_schueler - bester_schueler:.2f}")

# Zusatzanalyse: Notenverteilung
print(f"\nNotenverteilung:")
sehr_gut = sum(1 for d in alle_durchschnitte if d <= 1.5)
gut = sum(1 for d in alle_durchschnitte if 1.5 < d <= 2.5)
befriedigend = sum(1 for d in alle_durchschnitte if 2.5 < d <= 3.5)
ausreichend = sum(1 for d in alle_durchschnitte if d > 3.5)

print(f"Sehr gut:     {sehr_gut} Schüler ({sehr_gut/len(alle_durchschnitte):.0%})")
print(f"Gut:          {gut} Schüler ({gut/len(alle_durchschnitte):.0%})")
print(f"Befriedigend: {befriedigend} Schüler ({befriedigend/len(alle_durchschnitte):.0%})")
print(f"Ausreichend:  {ausreichend} Schüler ({ausreichend/len(alle_durchschnitte):.0%})")
```

**Erklärung:**
- `sum(noten) / len(noten)` berechnet den Durchschnitt
- `min(noten)` und `max(noten)` finden beste/schlechteste Note
- `", ".join(f"{note:.1f}" for note in noten)` formatiert Notenliste schön
- List Comprehensions mit Bedingungen zählen Notenverteilung
- Hilfsfunktion `bewerte_durchschnitt()` macht Code übersichtlicher
## Aufgabe 4: Fortschritts-Dashboard

```python
# Zelle 4: Fortschritts-Dashboard
projekte = [
    ("Website Redesign", 75, 100),     # (Name, Erledigt, Gesamt)
    ("Mobile App", 23, 50),
    ("Datenbank Migration", 45, 45),
    ("User Testing", 12, 30),
    ("Documentation", 8, 25)
]

def erstelle_fortschrittsbalken(erledigt, gesamt, breite=20):
    """Erstellt einen visuellen Fortschrittsbalken"""
    if gesamt == 0:
        return "░" * breite + "  0%"
    
    prozent = erledigt / gesamt
    filled_length = int(prozent * breite)
    remaining_length = breite - filled_length
    
    balken = "█" * filled_length + "░" * remaining_length
    prozent_text = f"{prozent:.0%}"
    
    return f"{balken} {prozent_text:>4}"

print("PROJEKT-DASHBOARD")
print("=" * 50)

# Für Gesamtstatistik
gesamt_erledigt = 0
gesamt_aufgaben = 0

for name, erledigt, gesamt in projekte:
    # Fortschrittsbalken erstellen
    fortschritt = erstelle_fortschrittsbalken(erledigt, gesamt)
    
    # Projekt-Status
    if erledigt >= gesamt:
        status = "✅ FERTIG"
    elif erledigt / gesamt > 0.8:
        status = "🟨 FAST FERTIG"
    elif erledigt / gesamt > 0.5:
        status = "🟧 IN ARBEIT"
    else:
        status = "🟥 BEGONNEN"
    
    print(f"{name:<20} {fortschritt} {status}")
    
    # Für Gesamtstatistik sammeln
    gesamt_erledigt += erledigt
    gesamt_aufgaben += gesamt

# Gesamtfortschritt
print("-" * 50)
gesamt_fortschritt = erstelle_fortschrittsbalken(gesamt_erledigt, gesamt_aufgaben)
print(f"{'GESAMTFORTSCHRITT':<20} {gesamt_fortschritt}")

# Zusätzliche Statistiken
fertige_projekte = sum(1 for _, erledigt, gesamt in projekte if erledigt >= gesamt)
print(f"\nProjekt-Statistiken:")
print(f"Fertige Projekte: {fertige_projekte} von {len(projekte)}")
print(f"Verbleibende Aufgaben: {gesamt_aufgaben - gesamt_erledigt}")
print(f"Durchschnittlicher Fortschritt: {gesamt_erledigt / gesamt_aufgaben:.0%}")

# Am weitesten fortgeschrittenes Projekt
if projekte:
    bestes_projekt = max(projekte, key=lambda x: x[1]/x[2] if x[2] > 0 else 0)
    print(f"Am weitesten: {bestes_projekt[0]} ({bestes_projekt[1]/bestes_projekt[2]:.0%})")
```

**Erklärung:**
- `int(prozent * breite)` berechnet wie viele Zeichen gefüllt werden sollen
- `"█" * filled_length` erstellt den gefüllten Teil des Balkens
- `"░" * remaining_length` erstellt den leeren Teil
- `{prozent_text:>4}` richtet Prozent rechtsbündig aus
- `max()` mit `key=lambda` findet das am weitesten fortgeschrittene Projekt
## Bonus-Aufgabe: Wetter-Dashboard

```python
# Bonus: Wetter-Dashboard
wetter_daten = [
    ("Montag", 22, 65, "Sonnig"),      # (Tag, Temp, Luftfeuchtigkeit, Beschreibung)
    ("Dienstag", 19, 80, "Regnerisch"),
    ("Mittwoch", 25, 45, "Sonnig"),
    ("Donnerstag", 23, 60, "Bewölkt"),
    ("Freitag", 20, 75, "Regnerisch"),
    ("Samstag", 26, 40, "Sonnig"),
    ("Sonntag", 24, 55, "Teilweise bewölkt")
]

def wetter_emoji(beschreibung):
    """Gibt passendes Emoji für Wetter zurück"""
    emoji_map = {
        "Sonnig": "☀️",
        "Regnerisch": "🌧️",
        "Bewölkt": "☁️",
        "Teilweise bewölkt": "⛅"
    }
    return emoji_map.get(beschreibung, "🌤️")

def regenwahrscheinlichkeit(luftfeuchtigkeit):
    """Berechnet Regenwahrscheinlichkeit basierend auf Luftfeuchtigkeit"""
    if luftfeuchtigkeit > 75:
        return "Hoch"
    elif luftfeuchtigkeit > 60:
        return "Mittel"
    else:
        return "Niedrig"

print("🌤️  WETTER-DASHBOARD - 7-TAGE-PROGNOSE")
print("=" * 60)
print("Tag         Temp   Feuchte  Wetter              Regen")
print("-" * 60)

# Für Statistiken sammeln
alle_temperaturen = []
regentage = 0

for tag, temp, feuchte, beschreibung in wetter_daten:
    emoji = wetter_emoji(beschreibung)
    regen_chance = regenwahrscheinlichkeit(feuchte)
    
    # Regentage zählen
    if feuchte > 70:
        regentage += 1
    
    alle_temperaturen.append(temp)
    
    # Formatierte Ausgabe
    wetter_text = f"{emoji} {beschreibung}"
    print(f"{tag:<10} {temp:>4}°C {feuchte:>6}%  {wetter_text:<18} {regen_chance}")

# Wochenstatistiken
durchschnitts_temp = sum(alle_temperaturen) / len(alle_temperaturen)
min_temp = min(alle_temperaturen)
max_temp = max(alle_temperaturen)

# Wärmster und kältester Tag finden
waermster_tag = max(wetter_daten, key=lambda x: x[1])
kaeltester_tag = min(wetter_daten, key=lambda x: x[1])

print("-" * 60)
print("WOCHENSTATISTIK:")
print(f"Durchschnittstemperatur: {durchschnitts_temp:.1f}°C")
print(f"Temperaturspanne: {min_temp}°C bis {max_temp}°C")
print(f"Wärmster Tag: {waermster_tag[0]} ({waermster_tag[1]}°C)")
print(f"Kältester Tag: {kaeltester_tag[0]} ({kaeltester_tag[1]}°C)")
print(f"Mögliche Regentage: {regentage} von {len(wetter_daten)} Tagen")

# Wettertrend
if durchschnitts_temp > 24:
    trend = "🔥 Sehr warm"
elif durchschnitts_temp > 20:
    trend = "🌡️ Angenehm warm"
elif durchschnitts_temp > 15:
    trend = "🍂 Mild"
else:
    trend = "❄️ Kühl"

print(f"Wochentrend: {trend}")

# Outfit-Empfehlung
if regentage > 3:
    outfit = "🧥 Regenjacke nicht vergessen!"
elif durchschnitts_temp > 25:
    outfit = "👕 T-Shirt und Shorts"
elif durchschnitts_temp > 18:
    outfit = "👔 Leichte Jacke empfohlen"
else:
    outfit = "🧥 Warme Kleidung anziehen"

print(f"Outfit-Tipp: {outfit}")
```

**Erklärung:**
- Dictionary `emoji_map` ordnet Wetterbeschreibungen Emojis zu
- `max()` und `min()` mit `key=lambda` finden wärmsten/kältesten Tag
- Bedingungslogik für verschiedene Empfehlungen
- Zusammenfassung der Wochendaten für Trends
## 🎓 Zusammenfassung der Lösung

### Wichtige f-String-Features verwendet:
- **Zahlenformatierung:** `{zahl:.2f}`, `{zahl:,.2f}`, `{zahl:>8.2f}`
- **Prozentformatierung:** `{anteil:.0%}`, `{anteil:.1%}`
- **Text-Ausrichtung:** `{text:<15}`, `{text:>10}`, `{text:^20}`
- **Debugging:** `{variable=}`, `{ausdruck:.2f}`
- **Mehrzeilige Strings:** Für übersichtliche Berichte

### Programmiertechniken gelernt:
- **List Comprehensions:** Für Berechnungen und Filterungen
- **Lambda-Funktionen:** Mit `max()`, `min()` für komplexe Vergleiche
- **Hilfsfunktionen:** Zur Strukturierung des Codes
- **Dictionary-Mapping:** Für Emojis und Bewertungen
- **Generator Expressions:** In `sum()` und `join()`

### Praktische Anwendungen:
- **Berichte:** Strukturierte, professionelle Ausgaben
- **Tabellen:** Ausgerichtete Spalten mit verschiedenen Datentypen
- **Dashboards:** Visuelle Fortschrittsanzeigen und Status
- **Statistiken:** Durchschnitte, Minimum/Maximum, Verteilungen
