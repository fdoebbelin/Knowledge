## 💡 Lösungshinweise

### Schritt-für-Schritt Entwicklung:

**1. Basis-Iteration (immer der erste Schritt):**
```python
# Alle Elemente durchgehen ohne Änderung
[note for note in noten]
```

**2. Filter hinzufügen (wenn nötig):**
```python
# Nur bestimmte Elemente
[note for note in noten if note <= 4]  # Nur ≤ 4
[note for note in noten if note > 4]   # Nur > 4
[note for note in noten if note <= 2]  # Nur ≤ 2
```

**3. Transformation hinzufügen (wenn nötig):**
```python
# Elemente verändern
[punkte_tabelle[note] for note in noten]        # Dictionary-Lookup
["Sehr gut!" for note in noten if note <= 2]    # Filter + Text
["Nachhilfe empfohlen" for note in noten if ...]# Filter + Text
```

### Konkrete Hilfen:

**Aufgabe 1 - Bestanden:**
- Schritt 1.1: `[note for note in noten]`
- Schritt 1.2: `[note for note in noten if note <= 4]`

**Aufgabe 2 - Punkte:**
- Schritt 2.2: `[punkte_tabelle[note] for note in beispiel_noten]`
- Schritt 2.3: `[punkte_tabelle[note] for note in noten]`

**Aufgabe 3 - Lobkärtchen:**
- Schritt 3.1: `[note for note in noten if note <= 2]`
- Schritt 3.2: `["Sehr gut!" for note in noten if note <= 2]`

**Aufgabe 4 - Nachhilfe:**
- Schritt 4.1: `[note for note in noten if note > 4]`
- Schritt 4.2: `["Nachhilfe empfohlen" for note in noten if note > 4]`
