## Was ist Scoop?

Scoop ist ein Kommandozeilen-Paketmanager für Windows, der die Installation von Software vereinfacht. Er installiert Programme in isolierten Verzeichnissen und vermeidet damit Konflikte mit dem System.

## Voraussetzungen

- Windows 10/11
- PowerShell 5.1 oder höher
- Internetverbindung
- Administratorrechte (für die erste Einrichtung)

## Schritt 1: Scoop installieren

### 1.1 PowerShell als Administrator öffnen
- Windows-Taste + X drücken
- "Windows PowerShell (Administrator)" auswählen
- Oder: Windows-Taste + R → `powershell` eingeben → Strg+Shift+Enter

### 1.2 Execution Policy anpassen
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```
Bestätigen Sie mit "Y" oder "J" (je nach Spracheinstellung).

### 1.3 Scoop herunterladen und installieren
```powershell
# Aktuelle Installationsmethode (empfohlen)
irm get.scoop.sh | iex

# Alternative Methode (falls die erste nicht funktioniert)
iwr -useb get.scoop.sh | iex
```

### 1.4 Installation prüfen
```powershell
scoop --version
```

## Schritt 2: SQLite installieren

### 2.1 SQLite Kommandozeilen-Tool installieren
```powershell
scoop install sqlite
```

### 2.2 Installation überprüfen
```powershell
sqlite3 --version
```

## Schritt 3: GUI-Tools für SQLite installieren

### Option A: DB Browser for SQLite (Empfohlen für Anfänger)
```powershell
# Extras-Bucket hinzufügen (für GUI-Anwendungen)
scoop bucket add extras

# DB Browser installieren
scoop install sqlitebrowser
```

**Vorteile:**
- Benutzerfreundliche grafische Oberfläche
- Drag & Drop für Dateien
- Visueller Query Builder
- Export-/Import-Funktionen
- Kostenlos und Open Source

### Option B: SQLiteStudio
```powershell
scoop install sqlitestudio
```

**Vorteile:**
- Sehr umfangreich
- Plugin-System
- Unterstützt mehrere Datenbank-Engines
- Erweiterte SQL-Features

### Option C: DBeaver (Universal-Tool)
```powershell
scoop install dbeaver
```

**Vorteile:**
- Unterstützt viele verschiedene Datenbanken
- Professionelle Features
- SQL-Editor mit Syntax-Highlighting
- ER-Diagramme

## Schritt 4: Programme starten

### Kommandozeile
```powershell
# SQLite-Kommandozeile starten
sqlite3

# Neue Datenbank erstellen/öffnen
sqlite3 meine_datenbank.db
```

### GUI-Programme starten
```powershell
# DB Browser starten
sqlitebrowser

# SQLiteStudio starten
sqlitestudio

# DBeaver starten
dbeaver
```

## Nützliche Scoop-Befehle

```powershell
# Alle installierten Programme anzeigen
scoop list

# Programme aktualisieren
scoop update sqlite
scoop update sqlitebrowser

# Alle Programme aktualisieren
scoop update *

# Programm deinstallieren
scoop uninstall sqlite

# Verfügbare Programme suchen
scoop search sqlite

# Programm-Informationen anzeigen
scoop info sqlite

# Cleanup (alte Versionen löschen)
scoop cleanup *
```

## Troubleshooting

### Problem: "Scoop wurde nicht gefunden"
**Lösung:** PowerShell neu starten oder Pfad prüfen:
```powershell
$env:PATH
```

### Problem: "Execution Policy" Fehler
**Lösung:** PowerShell als Administrator ausführen:
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

### Problem: GUI-Programme starten nicht
**Lösung:** 
1. Prüfen ob extras-Bucket hinzugefügt wurde
2. Programm neu installieren
3. Windows neu starten

### Problem: SQLite-Datei nicht gefunden
**Lösung:**
- Vollständigen Pfad zur .db-Datei angeben
- Arbeitsverzeichnis prüfen mit `pwd` (PowerShell) oder `.shell pwd` (SQLite)

## Python-Integration vorbereiten

SQLite ist bereits in Python integriert:
```python
import sqlite3

# Verbindung zur Datenbank
conn = sqlite3.connect('test.db')
cursor = conn.cursor()

# SQL ausführen
cursor.execute("SELECT * FROM studenten")
results = cursor.fetchall()

print(results)

# Verbindung schließen
conn.close()
```
