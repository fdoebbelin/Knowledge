## 💡 Lösungshinweise

### Dictionary Comprehensions:
```python
# Grundsyntax
{key: value for item in liste}

# Mit Tupel-Entpackung
{titel: seitenzahl for titel, autor, seitenzahl, genre in buecher}

# Mit Filter
{titel: genre for titel, autor, seitenzahl, genre in buecher if seitenzahl > 200}
```

### Set Comprehensions:
```python
# Grundsyntax
{ausdruck for item in liste}

# Automatisch eindeutig
{autor for titel, autor, seitenzahl, genre in buecher}

# Mit Filter
{titel for titel, autor, seitenzahl, genre in buecher if seitenzahl > 200}
```

### Zählung mit sum():
```python
# Anzahl zählen
sum(1 for item in liste if bedingung)

# Für Autor-Zählung
sum(1 for titel, a, seitenzahl, genre in buecher if a == autor)
```

### Tupel-Entpackung:
```python
# Jedes Tupel in seine Teile aufteilen
for titel, autor, seitenzahl, genre in buecher:
    # jetzt kann man jeden Teil einzeln verwenden
```
