## 1. Was ist Versionskontrolle?

### Problem ohne Versionskontrolle
Ohne Versionskontrolle entstehen schnell chaotische Situationen:
- Dateien wie "projekt_final_v2_wirklich_final.py"
- Verlust von funktionierendem Code durch Experimente
- Keine Nachverfolgung wer was wann geändert hat
- Schwierige Zusammenarbeit mit anderen Entwicklern
- Kein Backup der Entwicklungshistorie

### Lösung mit Git
Git löst diese Probleme systematisch:
- **Versionierung:** Jede Änderung wird dokumentiert und kann rückgängig gemacht werden
- **Historie:** Vollständige Nachverfolgung aller Änderungen mit Zeitstempel
- **Zusammenarbeit:** Mehrere Entwickler können gleichzeitig an einem Projekt arbeiten
- **Backup:** Automatische Sicherung durch verteilte Repositories
- **Branching:** Parallele Entwicklung verschiedener Features

### Was ist Git?
Git ist ein **verteiltes Versionskontrollsystem**:
- **Entwickelt von:** Linus Torvalds (Linux-Erfinder) 2005
- **Verbreitung:** Standard in der Softwareentwicklung
- **Funktionsweise:** Lokal funktionsfähig, mit Remote-Synchronisation
- **Vorteile:** Schnell, zuverlässig, kostenlos

### Repository initialisieren
```bash

!mkdir mein-erstes-projekt
!cd mein-erstes-projekt && git init
```

```bash
# Zelle 3.2: Repository-Status prüfen
!cd mein-erstes-projekt && git status
```

### Was passiert bei `git init`?
- Git erstellt versteckten `.git` Ordner
- Lokale Datenbank für Versionierung wird angelegt
- Working Directory wird Git-Repository
- Noch keine Commits oder Dateien unter Versionskontrolle

## 4. Erste Python-Datei erstellen und verwalten

```bash
# Zelle 4.1: Erste Python-Datei für Git-Repository erstellen
def erstelle_python_datei():
    """Erstellt eine einfache Python-Datei für das Git-Repository"""
    
    python_code = '''# Mein erstes Git-verwaltetes Python-Programm
def begruessung(name):
    """Einfache Begrüßungsfunktion"""
    return f"Hallo {name}, willkommen bei Git!"

def main():
    name = "Python-Entwickler"
    nachricht = begruessung(name)
    print(nachricht)

if __name__ == "__main__":
    main()
'''
    
    with open("mein-erstes-projekt/hallo_git.py", "w", encoding="utf-8") as datei:
        datei.write(python_code)
    
    return "Python-Datei 'hallo_git.py' erfolgreich erstellt"

print(erstelle_python_datei())
```

```bash
# Zelle 4.2: Aktuellen Repository-Status anzeigen
!cd mein-erstes-projekt && git status
```

## Zusammenfassung

### Wichtige Git-Konzepte:
- **Repository:** Git-Datenbank für ein Projekt (`.git` Ordner)
- **Working Directory:** Aktuelle Arbeitsversion der Dateien
- **Staging Area:** Vorbereitungsbereich für den nächsten Commit
- **Commit:** Permanente Speicherung einer Projektversion
- **Commit-Message:** Beschreibung der Änderungen

### Grundlegende Git-Befehle:
- **`git init`:** Neues Repository erstellen
- **`git status`:** Aktuellen Zustand anzeigen
- **`git add datei`:** Datei für Commit vormerken
- **`git commit -m "nachricht"`:** Änderungen dauerhaft speichern
- **`git log`:** Projekthistorie anzeigen
- **`git diff`:** Unterschiede zu letztem Commit zeigen

### Best Practices:
- Aussagekräftige Commit-Messages verwenden
- Kleine, logische Commits statt großer Änderungen
- Regelmäßig `git status` zur Orientierung nutzen
- UTF-8 Encoding für alle Textdateien verwenden

### Nächste Schritte:
- Branches für parallele Entwicklung
- Remote-Repositories für Zusammenarbeit
- Merge-Konflikte verstehen und lösen
- GitHub für Open-Source-Projekte nutzen
