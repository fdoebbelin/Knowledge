## 1. Lokale Änderung vorbereiten (NICHT committen!)

```bash
# Ändere eine Datei lokal, z.B. die gleiche Zeile
echo "Lokale Änderung in Zeile 1" >> datei.txt
# NICHT committen! Nur ändern und speichern
```

## 2. Remote auf GitHub ändern

1. Gehe auf GitHub zu derselben Datei
2. Klicke auf das Stift-Symbol zum Bearbeiten
3. Ändere **dieselbe Zeile** mit einem anderen Inhalt:
    
    ```
    Remote Änderung in Zeile 1
    ```
    
4. Commit mit Nachricht: "Remote Änderung für Konflikt-Demo"
5. Klicke "Commit changes"

## 3. Lokalen Commit machen und Push versuchen

```bash
git add datei.txt
git commit -m "Lokale Änderung für Konflikt-Demo"
git push origin main
```

## 4. Der Konflikt entsteht!

Git wird dir sagen: "Updates were rejected because the remote contains work..."

## 5. Pull und Konflikt lösen

```bash
git pull origin main
# Git zeigt dir die Konflikt-Markierungen in der Datei:
# <<<<<<< HEAD
# Lokale Änderung in Zeile 1
# =======
# Remote Änderung in Zeile 1
# >>>>>>> commit-hash
```

**Was bedeutet das?**

- `<<<<<<< HEAD`: Beginn deiner lokalen Änderungen
- `=======`: Trennung zwischen lokal und remote
- `>>>>>>> commit-hash`: Ende der Remote-Änderungen
### Option 1: Lokale Version behalten

Lösche die Markierungen und behalte nur deine Version:

```
Lokale Änderung in Zeile 1
```

### Option 2: Remote Version übernehmen

Lösche die Markierungen und behalte nur die Remote-Version:

```
Remote Änderung in Zeile 1
```

### Option 3: Beide kombinieren (meist die beste Lösung)

```
Lokale Änderung in Zeile 1
Remote Änderung in Zeile 1
```

## Konflikt abschließen

```bash
# 1. Datei speichern (nachdem du die Markierungen entfernt hast)
# 2. Zur Staging Area hinzufügen
git add datei.txt

# 3. Status checken
git status
# Zeigt: "All conflicts fixed but you are still merging"

# 4. Merge-Commit erstellen
git commit -m "Merge-Konflikt gelöst: Beide Änderungen kombiniert"

# 5. Zum Remote Repository pushen
git push origin main
```

## Hilfreiche Tools:

**Visueller Merge-Editor:**

```bash
git mergetool
```

**Konflikt-Status anzeigen:**

```bash
git status
git diff --name-only --diff-filter=U  # Nur konflikthafte Dateien
```

**Merge abbrechen (falls nötig):**

```bash
git merge --abort
```

Jetzt hast du erfolgreich einen Merge-Konflikt gelöst! Das ist eine wichtige Fähigkeit für die Teamarbeit mit Git.
