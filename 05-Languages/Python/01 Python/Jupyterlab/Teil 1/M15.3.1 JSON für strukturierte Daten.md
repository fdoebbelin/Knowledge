## 1. JSON verstehen - Was ist JSON?

### 1.1 JSON vs. Python Dictionary
```python
def zeige_json_vs_dictionary():
    """Zeigt den Unterschied zwischen JSON und Python Dictionary"""
    # Python Dictionary
    python_dict = {
        "name": "Anna", 
        "alter": 25,
        "verheiratet": False,
        "hobbys": ["Lesen", "Sport", "Musik"]
    }
    
    # JSON ist ein Text-Format (String)
    json_text = '{"name": "Anna", "alter": 25, "verheiratet": false, "hobbys": ["Lesen", "Sport", "Musik"]}'
    
    return f"Python Dict: {python_dict}\nJSON Text: {json_text}"

print(zeige_json_vs_dictionary())
```

## 2. JSON-Dateien erstellen und schreiben

### 2.1 Einfache JSON-Datei erstellen
```python
def erstelle_erste_json_datei():
    """Erstellt eine einfache JSON-Datei mit Personendaten"""
    import json
    
    # Python Dictionary mit Personendaten
    person = {
        "name": "Lisa Müller",
        "alter": 28,
        "stadt": "Berlin",
        "beruf": "Programmiererin"
    }
    
    # Dictionary als JSON-Datei speichern
    with open("person.json", "w", encoding="utf-8") as datei:
        json.dump(person, datei, indent=4, ensure_ascii=False)
    
    return f"JSON-Datei 'person.json' erstellt mit Daten: {person}"

print(erstelle_erste_json_datei())
```

## 3. JSON-Dateien lesen und verarbeiten

### 3.1 Einfache JSON-Datei lesen
```python
def lese_person_daten():
    """Liest die gespeicherten Personendaten aus JSON-Datei"""
    import json
    
    # JSON-Datei öffnen und laden
    with open("person.json", "r", encoding="utf-8") as datei:
        person = json.load(datei)
    
    # Auf einzelne Werte zugreifen
    name = person["name"]
    alter = person["alter"]
    stadt = person["stadt"]
    
    return f"Geladene Person: {name}, {alter} Jahre, wohnt in {stadt}"

print(lese_person_daten())
```

```python
def durchsuche_kontakte():
```

```python
def analysiere_firma():
    """Liest und analysiert die verschachtelten Firmendaten"""
    import json
    
    # Verschachtelte JSON-Datei laden
    with open("firma.json", "r", encoding="utf-8") as datei:
        firma = json.load(datei)
    
    # Zugriff auf verschachtelte Daten
    firmenname = firma["firmenname"]
    stadt = firma["adresse"]["stadt"]
    mitarbeiter_anzahl = len(firma["mitarbeiter"])
    
    # Mitarbeiter-Namen sammeln
    namen = [mitarbeiter["name"] for mitarbeiter in firma["mitarbeiter"]]
    
    return f"{firmenname} in {stadt} hat {mitarbeiter_anzahl} Mitarbeiter: {namen}"

print(analysiere_firma())
```

## 6. Fehlerbehandlung bei JSON

### 6.1 Sichere JSON-Operationen
```python
def sichere_json_erstellung():
    """Erstellt JSON-Datei mit Fehlerbehandlung"""
    import json
    
    daten = {
        "test": "Das ist ein Test",
        "nummer": 42
    }
    
    try:
        with open("sicher.json", "w", encoding="utf-8") as datei:
            json.dump(daten, datei, indent=4, ensure_ascii=False)
        ergebnis = "✅ JSON-Datei erfolgreich erstellt"
    except Exception as fehler:
        ergebnis = f"❌ Fehler beim Erstellen: {fehler}"
    
    return ergebnis

print(sichere_json_erstellung())
```

```python
def sichere_json_lesen():
    """Liest JSON-Datei mit Fehlerbehandlung"""
    import json
    
    try:
        with open("sicher.json", "r", encoding="utf-8") as datei:
            daten = json.load(datei)
        ergebnis = f"✅ JSON gelesen: {daten}"
    except FileNotFoundError:
        ergebnis = "❌ JSON-Datei nicht gefunden"
    except json.JSONDecodeError:
        ergebnis = "❌ Ungültiges JSON-Format"
    except Exception as fehler:
        ergebnis = f"❌ Fehler beim Lesen: {fehler}"
    
    return ergebnis

print(sichere_json_lesen())
```

```python
def demonstriere_json_parameter():

    import json
```

## Zusammenfassung

### Wichtige JSON-Operationen:
1. **`json.dump()`** - Python-Objekt in JSON-Datei schreiben
2. **`json.load()`** - JSON-Datei in Python-Objekt lesen
3. **`indent=4`** - Macht JSON-Dateien lesbar
4. **`ensure_ascii=False`** - Ermöglicht deutsche Umlaute

### JSON vs. andere Formate:
- **Textdateien:** Einfache Notizen und Listen
- **CSV-Dateien:** Tabellendaten wie Excel 
- **JSON-Dateien:** Verschachtelte, strukturierte Daten
- **Datenbanken:** Komplexe Abfragen und Beziehungen

### Wann JSON verwenden?
JSON ist ideal für:
- Verschachtelte Datenstrukturen
- Konfigurationsdateien
- Datenaustausch zwischen Anwendungen
- Listen von Objekten mit verschiedenen Eigenschaften
