## 1. Erste Datei schreiben
### Einfachen Text in Datei speichern
```python
def schreibe_erste_datei():
    """Schreibt einen einfachen Text in eine neue Datei"""
    # Text zum Speichern
    text = "Hallo Welt! Das ist mein erster Text in einer Datei."
    
    # Datei schreiben mit 'with'-Statement (automatisches Schließen)
    with open("meine_erste_datei.txt", "w", encoding="utf-8") as datei:
        datei.write(text)
    
    return "Datei 'meine_erste_datei.txt' wurde erfolgreich erstellt!"

print(schreibe_erste_datei())
```

```python
def schreibe_mehrere_zeilen():
    """Schreibt mehrere Zeilen in eine Datei"""
    zeilen = [
        "Erste Zeile",
        "Zweite Zeile", 
        "Dritte Zeile"
    ]
    
    with open("mehrere_zeilen.txt", "w", encoding="utf-8") as datei:
        for zeile in zeilen:
            datei.write(zeile + "\n")  # \n für neue Zeile hinzufügen
    
    return f"Datei mit {len(zeilen)} Zeilen erstellt!"

print(schreibe_mehrere_zeilen())
```
## 2. Dateien lesen und anzeigen
### Kompletten Dateiinhalt lesen
```python
def lese_komplette_datei():
    """Liest den kompletten Inhalt einer Textdatei"""
    with open("meine_erste_datei.txt", "r", encoding="utf-8") as datei:
        inhalt = datei.read()
    
    return f"Dateiinhalt: {inhalt}"

print(lese_komplette_datei())
```

```python
def lese_datei_zeilenweise():
    """Liest eine Datei Zeile für Zeile"""
    zeilen_liste = []
    
    with open("mehrere_zeilen.txt", "r", encoding="utf-8") as datei:
        for zeile in datei:
            # strip() entfernt Zeilenendezeichen
            saubere_zeile = zeile.strip()
            zeilen_liste.append(saubere_zeile)
    
    return f"Gelesene Zeilen: {zeilen_liste}"

print(lese_datei_zeilenweise())
```

## 4. Fehlerbehandlung bei Dateien
### Sichere Dateierstellung
```python
def sichere_dateierstellung():
    """Schreibt Datei mit Fehlerbehandlung"""
    try:
        with open("sichere_datei.txt", "w", encoding="utf-8") as datei:
            datei.write("Dieser Text wird sicher gespeichert!")
        ergebnis = "Datei erfolgreich erstellt!"
    except Exception as fehler:
        ergebnis = f"Fehler beim Schreiben: {fehler}"
    
    return ergebnis

print(sichere_dateierstellung())
```

```python
def sichere_dateilesen():
    """Liest Datei mit Fehlerbehandlung"""
    try:
        with open("sichere_datei.txt", "r", encoding="utf-8") as datei:

    except FileNotFoundError:
        ergebnis = "Datei nicht gefunden!"
    except Exception as fehler:
        ergebnis = f"Fehler beim Lesen: {fehler}"
```

## 5. Praktisches Beispiel: Einfaches Tagebuch
### Tagebuch-Eintrag speichern
```python
def schreibe_tagebuch_eintrag():
    """Schreibt einen Tagebuch-Eintrag mit aktuellem Datum"""
    from datetime import datetime
    
    # Aktuelles Datum und Zeit
    jetzt = datetime.now().strftime("%d.%m.%Y %H:%M")
    eintrag = f"{jetzt}: Heute habe ich Python-Dateien gelernt!"
    
    # Eintrag an Tagebuch-Datei anhängen
    with open("tagebuch.txt", "a", encoding="utf-8") as datei:
        datei.write(eintrag + "\n")
    
    return f"Tagebuch-Eintrag gespeichert: {eintrag}"

print(schreibe_tagebuch_eintrag())
```

```python
def lese_ganzes_tagebuch():
    """Liest alle Tagebuch-Einträge"""
    try:
        with open("tagebuch.txt", "r", encoding="utf-8") as datei:
            eintraege = datei.readlines()
        
        # Einträge bereinigen (strip() entfernt \n)
        saubere_eintraege = [eintrag.strip() for eintrag in eintraege]
        ergebnis = f"Tagebuch-Einträge ({len(saubere_eintraege)}): {saubere_eintraege}"
    except FileNotFoundError:
        ergebnis = "Tagebuch existiert noch nicht!"
    
    return ergebnis
```

```python
def lade_einkaufsliste():
```

## 7. Wichtige Datei-Modi
### Grundlegende Datei-Modi
**"r" - Lesen (read)**
- Datei wird nur zum Lesen geöffnet
- Datei muss bereits existieren
- Standard-Modus wenn nichts angegeben wird
- Cursor steht am Anfang der Datei

**"w" - Schreiben (write)**
- Datei wird zum Schreiben geöffnet
- Überschreibt den kompletten Inhalt einer bestehenden Datei
- Erstellt eine neue Datei, wenn sie nicht existiert
- Cursor steht am Anfang der Datei

**"a" - Anhängen (append)**
- Datei wird zum Anhängen geöffnet
- Fügt neuen Inhalt am Ende der Datei hinzu
- Erstellt eine neue Datei, wenn sie nicht existiert
- Cursor steht am Ende der Datei

**"r+" - Lesen und Schreiben**
- Datei kann gelesen und beschrieben werden
- Datei muss bereits existieren
- Cursor steht am Anfang der Datei
- Vorsicht: Kann bestehenden Inhalt überschreiben

### Verwendungsempfehlungen

| Modus  | Wann verwenden                                   | Beispiel            |
| ------ | ------------------------------------------------ | ------------------- |
| `"r"`  | Datei nur lesen                                  | Konfiguration laden |
| `"w"`  | Neue Datei erstellen oder komplett überschreiben | Ergebnis speichern  |
| `"a"`  | Daten zu bestehender Datei hinzufügen            | Log-Dateien         |
| `"r+"` | Datei bearbeiten ohne zu überschreiben           | Selten verwendet    |
## 8. Best Practices
### Sichere Datei-Funktionen
```python
def sichere_datei_funktion(dateiname, inhalt):
    """Universelle sichere Funktion zum Schreiben von Dateien"""
    try:
        with open(dateiname, "w", encoding="utf-8") as datei:
            datei.write(inhalt)
        return f"✅ Datei '{dateiname}' erfolgreich geschrieben!"
    except Exception as fehler:
        return f"❌ Fehler bei '{dateiname}': {fehler}"

# Test der sicheren Funktion
print(sichere_datei_funktion("test.txt", "Das ist ein Testtext!"))
```

```python
def sichere_lese_funktion(dateiname):
    """Universelle sichere Funktion zum Lesen von Dateien"""
    try:
        with open(dateiname, "r", encoding="utf-8") as datei:
            inhalt = datei.read()
        return f"✅ Inhalt von '{dateiname}': {inhalt}"
    except FileNotFoundError:
        return f"❌ Datei '{dateiname}' nicht gefunden!"
    except Exception as fehler:
        return f"❌ Fehler beim Lesen von '{dateiname}': {fehler}"

# Test der sicheren Lese-Funktion
print(sichere_lese_funktion("test.txt"))
print(sichere_lese_funktion("nicht_vorhanden.txt"))
```
## Zusammenfassung
### Wichtige Erkenntnisse:
1. **`with`-Statement verwenden**: Automatisches Schließen der Dateien
2. **Encoding angeben**: Immer `encoding="utf-8"` für deutsche Umlaute
3. **Modi richtig wählen**: `"r"` zum Lesen, `"w"` zum Schreiben, `"a"` zum Anhängen
4. **Fehlerbehandlung**: `try-except` für sichere Dateioperationen
5. **`strip()` verwenden**: Entfernt Zeilenendezeichen beim Lesen
6. **Zeilen mit `\n`**: Beim Schreiben neue Zeilen explizit hinzufügen
