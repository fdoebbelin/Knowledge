---

### Was steckt technisch dahinter?

Meistens handelt es sich bei einem Data Lab um eine angepasste Version von **Jupyter Notebooks** oder **JupyterLab**. Hier sind die wichtigsten Merkmale:

- **Browser-basiert:** Du musst keine Software (wie Python selbst oder schwere IDEs) auf deinem eigenen Rechner installieren. Du öffnest einfach den Browser und legst los.
- **Interaktive Zellen:** Du schreibst Code in kleinen Blöcken (Zellen) und siehst das Ergebnis (Tabellen, Grafiken, Berechnungen) sofort darunter.
- **Vorinstallierte Bibliotheken:** Die "Big Three" der Datenanalyse sind meist schon startklar:
	1. **Pandas** (für Tabellen/Datenrahmen)
		2. **NumPy** (für mathematische Operationen)
		3. **Matplotlib/Seaborn** (für Visualisierungen)

---

### Warum nutzt man ein Data Lab?

Gerade für Einsteiger bietet das Data Lab entscheidende Vorteile gegenüber einer lokalen Installation:

1. **Kein "Installations-Frust":** Du musst dich nicht mit Umgebungsvariablen oder zerschossenen Python-Installationen herumschlagen.
2. **Zentraler Datenzugriff:** Oft sind Beispieldatensätze (CSV-Dateien, SQL-Datenbanken) direkt im Lab verknüpft.
3. **Reproduzierbarkeit:** Der Code läuft in der Cloud exakt so wie beim Dozenten oder Kollegen, da die Umgebung identisch ist.

### Ein typischer Workflow im Data Lab:

1. **Daten laden:** Du importierst eine Datei direkt im Lab.
2. **Exploration:** Du nutzt Befehle wie `.head()` oder `.describe()`, um die Daten zu verstehen.
3. **Visualisierung:** Du erstellst direkt im Lab ein Diagramm, das dort auch gespeichert wird.
4. **Dokumentation:** Du schreibst zwischen den Code-Blöcken Text (Markdown), um deine Erkenntnisse zu erklären.
