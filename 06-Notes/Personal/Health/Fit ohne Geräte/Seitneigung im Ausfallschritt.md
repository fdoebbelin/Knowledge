# Seitneigung im Ausfallschritt

```dataview
TABLE WITHOUT ID
  typ AS Typ,
  join(fokus, " · ") AS Fokus,
  join(muskeln, " · ") AS Muskeln,
  schwierigkeit AS Niveau
WHERE file = this.file
```

![[_resources/000197.jpg]]

**Hauptfunktion:** Diese anspruchsvolle Übung stärkt den Unterkörper und dehnt gleichzeitig die Körperseiten.

## Ausführung

1.  **Startposition:** `Kniend (Ausfallschritt)`, hinteres Knie `knapp über Boden`. `Arme gestreckt` (`Streamline-Position`).
2.  **Phase 1:** `Rumpfspannung` halten. `Rumpf Rotation` (`Seitneigung`) nach links und rechts ausführen, dabei die tiefe `Kniend (Ausfallschritt)`-Position beibehalten.
3.  **Wiederholung:** Eine Seite nach der anderen trainieren.

> [!tip] Variante
> Vereinfachen Sie die Übung, indem Sie das `hintere Knie am Boden` aufstellen.
