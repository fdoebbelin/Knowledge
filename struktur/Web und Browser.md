Wie das Web funktioniert, was im Browser läuft und wohin sich das Web entwickeln soll. Der Lesepfad geht von den Grundbegriffen über den Browser als Laufzeitumgebung zu den Ideen für ein Web, in dem die Daten den Menschen gehören.

## Grundbegriffe

- [[Das Internet ist nicht das Web]] – die beiden Schichten auseinanderhalten

## Code im Browser

- [[Ein script-Tag mit src ignoriert seinen Inhalt]] – wie JavaScript in die Seite kommt und eine stille Falle dabei
- [[p5.js ist Processing für den Browser]] – Zeichnen und Animieren mit einer JavaScript-Bibliothek
- [[Python-Spiele kommen auf drei Wegen in den Browser]] – WebAssembly, Interpreter in JavaScript oder Webview
- [[Pygame läuft nicht direkt im Browser, weil es über SDL die Hardware anspricht]] – warum die Sandbox den einfachen Weg versperrt und wie Pygbag ihn öffnet

## Das nächste Web

- [[Web 3.0 und Web3 meinen zwei verschiedene Ideen]] – erst klären, welche Vision gemeint ist
- [[Solid trennt die Anwendungen von den Daten]] – Pod, WebID und Zugriffsregeln
- [[Linked Data macht Daten über gemeinsame Vokabulare maschinenlesbar]] – das Datenformat, das Anwendungen zusammenarbeiten lässt
