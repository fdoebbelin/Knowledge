Anthropics ambitionierte Vorhersage über KI-geschriebene Software ist Wirklichkeit geworden. CEO Dario Amodei bestätigte in den letzten Monaten, dass die „überwiegende Mehrheit" des Codes, der neue Claude-Modelle antreibt, mittlerweile von Claude selbst geschrieben wird – interne Schätzungen beziffern den Anteil auf über 90 %. Dieser Meilenstein markiert einen Wendepunkt in der Softwareentwicklung, da KI-Systeme zunehmend den Code generieren, der ihre eigenen Nachfolger entwickelt.

## Von der Vorhersage zur Realität

Die Bestätigung validiert eine kühne Prognose, die Amodei im März 2025 bei einer Veranstaltung des Council on Foreign Relations machte, wo er voraussagte, dass KI innerhalb von drei bis sechs Monaten „90 % des Codes schreiben" würde. Damals stieß die Behauptung bei Branchenbeobachtern auf Skepsis, die bezweifelten, ob KI mit der Komplexität produktionsreifer Software umgehen könne.[remio +3](https://www.remio.ai/post/anthropic-ceo-said-ai-would-write-90-of-code-in-3-6-months-here-s-what-the-evidence-shows)

Im Oktober 2025 teilte Amodei jedoch CEO Marc Benioff auf der Dreamforce-Konferenz mit, dass sich seine Vorhersage bewahrheitet habe. „Innerhalb von Anthropic und bei einer Reihe von Unternehmen, mit denen wir zusammenarbeiten, trifft das jetzt absolut zu", sagte er. Amodei stellte klar, dass dieser Wandel nicht bedeutet, dass weniger Ingenieure benötigt werden. „Wenn Claude 90 % des Codes schreibt, bedeutet das normalerweise, dass man genauso viele Software-Ingenieure braucht", erklärte er. „Sie können sich auf die 10 % konzentrieren, bei denen es um die Bearbeitung des Codes geht, oder auf die 10 %, die am schwierigsten sind, oder darauf, eine Gruppe von KI-Modellen zu überwachen".[businessinsider](https://www.businessinsider.com/most-anthropic-teams-coding-with-claude-ai-not-replacing-humans-2025-10)

## Claude Code schreibt seinen eigenen Code

Die rekursive Natur dieser Entwicklung wurde im Dezember 2025 noch deutlicher, als Boris Cherny, der Entwickler von Anthropics Claude Code-Tool, bekanntgab, dass 100 % seiner Code-Beiträge in diesem Monat vollständig von Claude geschrieben wurden. Laut einer in der vergangenen Woche veröffentlichten Analyse des Council on Foreign Relations signalisiert dieser Meilenstein, dass „KI-Verbesserungen sich selbst verstärken und beschleunigen".[cfr +1](https://www.cfr.org/article/how-2026-could-decide-future-artificial-intelligence)

Claude Code, Anthropics agentisches Kommandozeilen-Tool für Entwickler, hat mittlerweile etwa 90 % seiner eigenen Codebasis von KI-Modellen geschrieben. Das Tool ermöglichte die Entwicklung von Cowork, Anthropics neuem Dateiautomatisierungstool, das am 12. Januar vorgestellt wurde und Berichten zufolge in etwa zehn Tagen mithilfe von Claude Code selbst erstellt wurde.[karozieminski.substack +2](https://karozieminski.substack.com/p/claude-cowork-anthropic-product-deep-dive)


## Auswirkungen auf die Branche

Die Entwicklung hat die Debatte über die Zukunft der Softwareentwicklung verschärft. Sicherheitsforscher haben Bedenken geäußert, dass KI-generierter Code Schwachstellen in bisher ungekanntem Ausmaß einführen könnte. Währenddessen hat sich die rekursive Schleife – bei der KI-Systeme helfen, verbesserte KI-Systeme zu entwickeln – von theoretischer Spekulation zu beobachtbarer Realität entwickelt.[markets.financialcontent +1](https://markets.financialcontent.com/wral/article/tokenring-2026-1-13-90-of-claudes-code-is-now-ai-written-anthropic-ceo-confirms-historic-shift-in-software-development)

„Die Softwareentwicklung verändert sich, und wir treten in eine neue Ära der Programmiergeschichte ein", warnte Cherny. Wie Amodei ursprünglich vorhersagte, könnte die nächste Entwicklungsstufe bald erreicht sein: Bis März 2026, so seine Prognose, könnte KI „im Wesentlichen den gesamten" Code schreiben. Ob dieser Zeitplan eingehalten wird oder nicht – Anthropic scheint entschlossen, diese Prophezeiung wahr werden zu lassen.[thealgorithmicbridge +1](https://www.thealgorithmicbridge.com/p/claude-code-coded-claude-cowork)

Führungskräfte der weltweit prominentesten Unternehmen im Bereich künstliche Intelligenz trafen sich am Dienstag beim Weltwirtschaftsforum in Davos, um über die sich beschleunigenden Auswirkungen der Technologie auf die Beschäftigung und zunehmende Sicherheitsbedenken zu sprechen. Dabei warnte-CEO Dario Amodei, dass Softwareentwicklung innerhalb von 6 bis 12 Monaten „automatisierbar" werden könnte. Die Podiumsdiskussion mit dem Titel „The Day After AGI" brachte Amodei und Google DeepMind-CEO Demis Hassabis zusammen, um darüber zu debattieren, was passiert, wenn KI menschliche kognitive Fähigkeiten erreicht oder übertrifft – ein Meilenstein, von dem beide Führungskräfte glauben, dass er innerhalb des Jahrzehnts erreicht werden könnte.

## Node.js-Erfinder sagt, die Ära des menschlichen Programmierens ist vorbei

Ryan Dahl, der wegweisende Softwareentwickler, der Node.js erschaffen hat, hat sich einer wachsenden Zahl von Tech-Führungskräften angeschlossen, die das Ende der traditionellen Softwareentwicklung verkünden. In einem Beitrag auf X vom 18. Januar erklärte Dahl: „Die Ära des menschlichen Programmierens ist vorbei." Dahl, der die einflussreiche JavaScript-Laufzeitumgebung 2009 erschuf, räumte ein, dass seine Aussage für diejenigen „verstörend sein mag, die sich als Softwareentwickler identifizieren", argumentierte aber, dass sie „nicht weniger wahr" sei. Er stellte klar, dass Softwareentwickler weiterhin Arbeit haben werden, ihre Rolle sich aber vom direkten Schreiben von Syntax hin zu übergeordneten Aufgaben verschieben wird – wie der Definition von Systemarchitekturen, der Überprüfung von KI-generiertem Code und der Entscheidung darüber, was gebaut werden soll, statt wie es geschrieben wird.

Anthropics Claude Code erreicht sechs Monate nach Markteinführung 1 Milliarde Dollar Umsatz

Mehr als 150 Technologie-Experten drängten sich am Donnerstagabend bei einem Claude Code-Meetup in Seattle, um zu zeigen, wie sie Anthropics rasant wachsendes KI-Coding-Tool nutzen, um mit natürlicher Sprache und autonomen Agenten Software zu entwickeln. Das Meetup, das im ThinkSpace Seattle stattfand, nachdem die Organisatoren aufgrund des überwältigenden Interesses den Veranstaltungsort wechseln mussten, unterstreicht die Dynamik hinter Claude Code, das nur sechs Monate nach seiner öffentlichen Markteinführung bereits 1 Milliarde Dollar annualisierten Umsatz erreichte – zu diesem Zeitpunkt Berichten zufolge rund 15% des Gesamtumsatzes von Anthropic. Das im Februar 2025 veröffentlichte Tool ermöglicht es Entwicklern und Nicht-Programmierern gleichermaßen, Software zu erstellen, indem sie einfach in verständlichem Deutsch beschreiben, was sie möchten.

Anthropic stellt Cowork vor: KI-Automatisierung für Nicht-Programmierer

Anthropic hat am Montag Cowork vorgestellt, eine neue Funktion, die die beliebten Automatisierungsfähigkeiten von Claude Code auch für nicht-technische Nutzer zugänglich macht – ein wichtiger Schritt des KI-Unternehmens in den umkämpften Markt für allgemeine Produktivitätsagenten. Das Tool, das exklusiv über die Claude-Desktop-App für macOS verfügbar ist, ermöglicht es Nutzern, dem KI-Assistenten Zugriff auf bestimmte Ordner auf ihren Computern zu gewähren, sodass Claude Dateien selbstständig lesen, bearbeiten und erstellen kann. Cowork stellt eine Abkehr von der traditionellen chatbasierten KI-Interaktion dar und geht in Richtung dessen, was Anthropic als Zusammenarbeit mit Claude beschreibt – „wie das Hinterlassen von Nachrichten für einen Arbeitskollegen".
