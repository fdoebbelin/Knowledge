## Strukturierungstipps für verschiedene Projekttypen

### IT-Projekte

- **Phasenorientiert:** Analyse → Design → Entwicklung → Test → Deployment
- **Komponenten-orientiert:** Frontend, Backend, Datenbank, Integration
- **Berücksichtigen:** Dokumentation, Testing, Security

### Marketing-Projekte

- **Strategieorientiert:** Analyse → Strategie → Kreation → Umsetzung → Erfolgsmessung
- **Kanalbasiert:** Online, Print, Events, PR
- **Berücksichtigen:** Compliance, Budget-Kontrolle, Timing

### Bau-Projekte

- **Gewerkeorientiert:** Rohbau, Elektro, Sanitär, Ausbau
- **Phasenorientiert:** Planung → Genehmigung → Ausführung → Abnahme
- **Berücksichtigen:** Sicherheit, Genehmigungen, Witterung

### Organisations-Projekte

- **Prozessorientiert:** Analyse → Konzeption → Change → Implementierung
- **Stakeholder-orientiert:** Management, Mitarbeiter, IT, Externe
- **Berücksichtigen:** Change Management, Schulung, Kommunikation

### Bildungs-Projekte

- **Didaktorientiert:** Analyse → Konzeption → Erstellung → Durchführung
- **Zielgruppenorientiert:** Führungskräfte, Fachkräfte, Auszubildende
- **Berücksichtigen:** Lernerfolgskontrolle, Nachhaltigkeit, Methoden-Mix
