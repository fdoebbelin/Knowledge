# Knowledge – Wissensbasis für Linux & Softwareentwicklung

Diese Sammlung ist mein persönlicher Obsidian-Vault, den ich öffentlich zugänglich mache.
Sie bündelt Wissen, das in vielen Jahren als IT-Trainer entstanden ist: Kursmaterialien,
technische Notizen, Anleitungen und Erfahrungen aus eigenen Projekten.

## Für wen?

Für alle, die sich für IT interessieren – besonders für
- **Linux** und Serveradministration
- **Softwareentwicklung** (u. a. Python, SQL, Desktop-Apps)
- **Virtualisierung und Container** (KVM, Podman, Incus, bootc)
- Auszubildende zum **Fachinformatiker** (FISI/FIAE) und alle, die sie begleiten

## Aufbau

| Ordner          | Inhalt                                              |
|-----------------|-----------------------------------------------------|
| `00-Inbox`      | Neue, noch unsortierte Notizen                      |
| `01-Courses`    | Kurs- und Schulungsmaterialien                      |
| `02-Tech`       | Technisches Wissen, Anleitungen, Referenzen         |
| `03-Projects`   | Projektdokumentationen und Erfahrungsberichte       |
| `04-Languages`  | Programmier- und Skriptsprachen                     |
| `05-Notes`      | Allgemeine Notizen                                  |
| `_resources`    | Bilder und Anhänge                                  |

Eine ausführlichere Übersicht steht in [Struktur-Übersicht.md](Struktur-Übersicht.md).

## Nutzung

- **Im Browser:** Einfach durch die Ordner klicken – GitHub zeigt die Markdown-Dateien direkt an.
- **In Obsidian:** Repository klonen und den Ordner als Vault öffnen.
  Dann funktionieren auch Verlinkungen (`[[...]]`) und die Graph-Ansicht.

```bash
  git clone https://github.com/fdoebbelin/Knowledge.git
```

## Hinweise

Die Wissensbasis ist ein lebendes Dokument: Inhalte wachsen, ändern sich und sind
nicht immer fertig. Fehler gefunden oder eine Anregung? Gern über
[Issues](https://github.com/fdoebbelin/Knowledge/issues) melden.
